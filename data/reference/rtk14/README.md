# RTK14 무장 항목 참고 원장

`officer-catalog-v1.json`은 삼국지 14 무장 항목의 **이름과 분류**만 정리한 참고 자료다. 휘하 규칙이나 플레이어에게 공개된 선택 목록을 자동으로 늘리지 않는다. `availabilityState=REFERENCE_ONLY`인 행은 효과·장착·배정이 없다. `CREATION_DISPLAY_ONLY`는 현재 장수 생성 계약의 주의 6종과 개성 6종을 가리키며 효과는 없다.

## 대조 범위

| 종류 | 수 | 근거 |
| --- | ---: | --- |
| 주의 | 6 | Koei 한국어·일본어 공식 매뉴얼 |
| 개성 | 158 | 나무위키 한국어 비협업 표와 wikiwiki 일본어 고유·범용·PK 표 대조 |
| 정책 | 33 | 양쪽 정책 표의 **고유 이름** 대조. 37행 중 4행은 같은 정책의 세부행 |
| 전법 | 135 | 양쪽 일반 26·고유/PK 109개 이름 대조 |
| 진형 | 15 | 양쪽 이름 대조. 13개 전투 진형과 수송 편제 2개 구분 |

개성의 wikiwiki `護衛` 추가 중복행, 협업 캐릭터, CE 전용 별도 후보, 진형의 판본별 수치 변형과 `四夷`는 이 원장에 없다. Koei 홍보 페이지는 13개 전투 진형을 설명하고 `蜂矢`라고 쓰지만 두 대조 표는 `鋒矢`라고 쓴다. 이 표기 차이를 봉시 행에 기록했다. 나무위키의 `단기`는 현재 휘하 창작 장수 계약에서 공식 일본어 `一騎`에 따라 `일기`로 표시하므로 소스 이름과 휘하 표시명을 분리했다.

`TWO_SOURCE_NAME`은 두 출처의 이름을 유니코드 한자 한국어 독음과 일본 신자체/구자체 대응으로 연결한 행이다. `TWO_SOURCE_LOCALIZED`는 번역 이름이 달라 같은 종류의 행 순서·문맥을 대조한 행이다. `OFFICIAL` 접두사가 붙은 행은 Koei 공식 페이지에도 이름이나 종류가 나온다. 이 검증은 **이름의 대응**에 한정되며 원작 효과의 정확성이나 휘하 구현을 뜻하지 않는다.

안정 ID는 이 원장에서 할당한 코드다. 원작 내부 ID가 아니며 이름이나 표시 번역을 바꿀 때 재할당하지 않는다. 새 후보는 기존 숫자 ID를 다시 매기지 않고 추가한다. `sourceRefs`는 상단 URL 사전의 키이며 원문 HTML·추출 JSON·효과 수치·무장별 원본 배정은 Git에 넣지 않는다. wikiwiki 캐시의 경계는 `tools/rtk14/README.md`, 190 시드 능력의 경계는 `docs/data/scenario-3190-source-boundary.md`를 따른다.

정적 구조 검증: `python3 tools/rtk14/validate_officer_catalog.py`.
