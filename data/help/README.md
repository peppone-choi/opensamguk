# 도움말 저장소

`topics.json`은 입력 원장의 `helpTopicId`마다 하나의 주제를 둔다. `failure-reasons.json`은 원장의 모든 `failureReasons` 코드에 설명과 회복 조언을 둔다. 여러 입력에서 뜻이 달라지는 사유는 `byInputId`에 해당 입력의 문구를 추가한다.

각 주제와 실패 사유의 사람 글은 검수 전 `reviewState=DRAFT`(초안)로 기록한다. API도 이 값을 반환하므로 화면에서 초안임을 표시할 수 있다. 사용자 검수를 마친 행만 별도 변경에서 `APPROVED`로 올린다. `DRAFT`는 입력의 실행 준비 상태나 실패 판정과 무관하다.

주제의 `sections`에는 설명, 예시, 성공 예, 실패 예, 회복 조언을 쓴다. 비용·권한·대상·시기 같은 기계 판정과 수치는 `data/commands/input-catalog.json`이 정본이며 이 글에 복제하지 않는다. 문맥 도움말 API가 원장의 현재 필드를 함께 반환한다. 아직 제공되지 않은 입력은 주제를 읽을 수 있어도 실행 가능하다고 쓰지 않는다.

역사적 맥락을 주장할 때는 `sources`에 사료의 책·권을 적는다. 정사 `CHRONICLE`과 연의 `ROMANCE`를 구분하고, 출처 없는 역사 서술은 추가하지 않는다. 현재 초안은 게임 규칙 설명만 담아 역사적 주장을 쓰지 않는다.

`HelpStoreTest`는 모든 원장 ID 연결, 고아·중복 주제, 모든 실패 사유 설명, 숫자 규칙 복제 금지를 검사한다. 새 입력이나 사유가 생기면 저장소 문구를 같은 PR에서 추가해야 한다. 사용자에게 보이는 최종 문구는 별도 검수를 거친다.
