# 아이소메트릭 PNG 에셋

정본: opensamguk-images, 태그 `v2026.09.10-iso2d-v2`.
이 디렉터리는 sprite-gen의 curated 출력에서 복사한 배포본이다. 직접 수정하지 않는다.

`manifest.json`이 파일·해시·앵커·도시 등급·병종·높이 조합을 정의한다.
육지 90, 수면 3, 건물 4, 부대 6, 프롭 3, 절벽 옆면 2 = PNG 108개.

육지는 공유 N/E/S/W 꼭짓점의 상대 높이(0/1)를 비트마스크로 선택한다.
한 단계는 화면 32px, mask 15는 mask 0 + baseHeight 1로 정규화한다.
평지 발자국 256×128, 패딩 셀 256×160, 앵커 (128,96)이다.
오브젝트 셀은 256×256, 바닥 앵커 (128,240)이다.

물은 수평이며, 재질 경계는 같은 경사 모양의 레이어를 월드 좌표에서 섞는다.
단차가 있는 경계에만 별도 옆면을 쌓는다. 오브젝트와 국가색/UI는 렌더러에서 처리한다.

이 파일들의 추가는 게임 렌더러 활성화나 지도 고도 데이터 구축을 의미하지 않는다.
한 타일 안의 2단 급경사·오버행·기울어진 절벽 연결부는 현재 제공하지 않는다.
원본·생성 프롬프트·추출 도구·조립 검증 이미지는 정본 저장소에만 보관한다.
