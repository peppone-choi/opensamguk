# 봉신 계약 순수 규칙

군주와 봉신은 같은 세력의 별도 주공이다. 봉신은 군주의 사람 휘하 카드가 아니며, 봉신 아래 다시 봉신을 둘 수 없다. 봉신의 휘하 사람·카드는 봉신의 트리를 따른다. `VassalContracts.validate`는 사건으로 얻은 주공 지위, 세력 소속, 휘하 트리의 최상위, R1 縣 소유를 입력으로 받아 이 불변식을 검사한다. 관직 또는 縣 소유만으로 주공 지위를 추론하지 않는다.

계약은 봉토 縣 집합, 상납률, 원군 병력, 자치 항목, 외교권, 위반 조건, 충성, 체결·종료 순을 가진다. 숫자와 목록은 [`vassal-rules.json`](../../data/curated/han/vassal-rules.json)에 `GAME_TERM`으로 둔다. 상납률 기본 20%(범위 0–50%), 원군 기본 100명, 응답 2순, 축소 이행 최소 50%, 연속 2개월 미납 시 위반, 위반 충성 −5는 구현 에이전트가 정한 값이다.

`VassalTribute.settle`은 월수입이 창고에 들어온 뒤 이번 달 봉토 수입만을 기준으로 상납을 계산한다. 봉토 창고와 군주 창고가 같은 보급망 조각에 있을 때만 이동한다. 원격 조각은 미납으로 남기고, 모든 창고 자원의 전후 합은 같다. `VassalReinforcement.assess`는 수락·기한 내 지연·축소·거절과 무응답 만료를 판정한다. 수락·지연으로 답하면서 의무 병력보다 적게 제시하면 예외로 턴을 중단하지 않고 위반으로 판정한다. 위반은 충성을 바꾸지만 독립은 별도의 정치 사건이다.

`VassalFounding.assess`는 군주가 같은 세력의 직속 휘하 장수를 봉신 주공으로 세우는 제안을 검증한다. 봉토가 해당 세력의 R1 縣이고 기존 봉신과 겹치지 않아야 한다. 사람 장수라면 별도 동의가 필요하다. `plan`은 휘하 해제·주공 지위 사건·계약 쓰기를 한 턴의 원자 적용 대상으로 돌려준다. 실제 2자 응답, 신분 사건, 저장은 1층 정치 동의 경로와 S5-3b handler가 배선한다.

`VassalStateCodec`은 version 1 meta JSON에 계약과 월별 상납 영수증을 함께 저장하고 손상·중복·고아 영수증을 거절한다. 이 슬라이스는 순수 모델·codec·읽기 투영이며 실제 조정 입력, 월 경계 배선, 세력 작전·외교 응답·승계, NPC, 화면은 통합 슬라이스에서 연결한다.
