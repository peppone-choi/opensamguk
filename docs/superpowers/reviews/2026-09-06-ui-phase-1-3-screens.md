## Phase 3 · 운영 콘솔 · 게임 관리 허브 (`A1-*.png`, `A2-*.png`)
- 로컬 테스트 계정을 DB 에서 ADMIN 으로 올려 찍었다(로컬 DB 한정).
- 운영 콘솔 `/admin`: 좌 레일(개요 조회 · 회원 관리 · 게시판 관리 · 서버 제어 · 게임 환경 · 공지, 위험 등급 표기) + 우 섹션. 회원 관리는 캡처 시점(3.5s)에 목록 조회 중(스피너), 공지는 작성 폼 + 목록 0건.
- 게임 관리 허브 `/game/{server}/admin`: 「관리」 적갈 칩이 부서 나브 우측에 뜨고, 7탭(게임 설정·장수 조치·일제정보·로그정보·외교정보·토너먼트 관리·서버 상태). 서버 상태 탭은 현재 OPEN 배지 + 바꿀 상태 + 「상태 변경」(접수 ≠ 반영 표기). 게임 설정 탭은 캡처 시점에 로딩 중.
- 모바일: 레일이 위로 접히고 탭이 줄바꿈된다.
