# OPENSAM-179 [H3] P-15d 소유 + OPENSAM-180 [H4] V2-4A 처분 — 자체 리뷰

Scope: docs .ai/decisions.md ADR-LITE-035 신규 항목과 Jira OPENSAM-24·OPENSAM-57·OPENSAM-159 본문 편집. 코드 변경 없음.
Verdict: cleared

## 1. 무엇을 결정했나

두 티켓은 같은 레인의 앞뒤(누가 게이트를 갖나 / 그 레인 티켓을 어떻게 정리하나)라 한 ADR로 묶었다.

- **H3** — `P-15d`를 이름으로 명시한 수용 기준은 **OPENSAM-57 하나**가 갖는다. BATTLE-F3(OPENSAM-159)는
  **작전층 단일 다이제스트 파생 훅**만 제공한다(범위 1항 + 수용 기준 3번).
- **H4** — OPENSAM-24(에픽)는 `operationId` ↔ `battle_id` **경계·스코프만** 소유하고, 중복이던
  4A-a~j 구현 목록은 자식 OPENSAM-57 단독 소유로 남긴다.

## 2. 티켓 수용 기준 대조

- 179 AC1 "`P-15d`를 이름으로 명시한 수용 기준을 가진 티켓이 정확히 1개" — **충족**. OPENSAM-57에만
  넣었다. OPENSAM-24는 "P-15d 게이트의 수용 기준도 OPENSAM-57이 가진다"는 **위임 서술**이고 자기
  수용 기준이 아니다. F3에는 의도적으로 `P-15d` 토큰을 넣지 않았다 — 넣으면 두 티켓이 된다.
- 179 AC2 "(1)안 채택 시 F3 범위에 파생 훅이 들어간다" — **충족**. F3 범위 5번째 항목 + 수용 기준 3번.
- 180 AC1 "24 본문이 `operationId`/`battle_id` 경계를 명시하고 07-30 세션 계약을 재구현하지 않음을
  밝힌다" — **충족**. 재스코프 절 첫 두 불릿 + 굵은 문장.
- 180 AC2 "같은 산출물을 소유한 티켓이 1개만 남는다" — **충족**. 24에서 4A-a~j 목록을 제거하고
  57에 "단독 소유" 절을 넣었다. 24와 57은 부모-자식이므로 티켓을 닫지 않고 층을 나눠 해소했다.

## 3. 왜 다른 안이 아닌가

- **H3 (2) P-15d를 checkpoint-hash로 개정해 F12 귀속** — product-spec 본문 개정이고, 그 개정 **권한
  규칙 자체가 아직 없다**(H6 = OPENSAM-182 미결). 권한이 정해지기 전에 정본을 고치는 것이 이번
  사고(ADR-LITE-025 시점의 침묵)의 재발이다. 그래서 이번 커밋은 product-spec을 한 글자도 안 고쳤다.
- **H3 (3) 신규 게이트 티켓** — 57이 이미 4A-g(replay body hash)·4A-i(replay gate)를 갖고 있어
  소유 중복을 새로 만든다.
- **H4 (2) 종료** — 병존 비준(ADR-LITE-032)으로 작전층 계약이 살아 있는데 소유 티켓을 없애면 P-15d가
  다시 고아가 된다. **(3) 현행 유지** — 24와 57의 중복 선언이 곧 AC2 위반이다.

## 4. 스스로 공격해 본 것

- **"정확히 1개"를 정말 지켰나?** 편집한 세 티켓 중 `P-15d` 문자열이 수용 기준 자리에 있는 것은 57뿐이다.
  24는 위임 문장, 159는 토큰 자체를 회피했다. 회피가 의도적임을 ADR Decision에 적어 두었다 —
  나중에 누군가 "F3에도 P-15d를 적자"고 하면 이 문장이 막는다.
- **파생 훅을 정의하지 않고 요구만 한 것 아닌가?** 맞다. 체인 → 단일 다이제스트 축약 알고리즘은
  UNKNOWN이며 F3 구현 시 결정한다. 지어내지 않고 ADR Consequences에 명시했다. 지금 고정한 것은
  "결정적일 것"과 "wall-clock 제외" 두 가지뿐이며, 둘 다 기존 정본(P-4c, 4A-g)에서 온 요구다.
- **F3 범위를 부풀렸나?** 훅 하나 + 결정성 테스트 하나. 전투 규칙·렌더러는 비범위 그대로다.
- **상태 전이를 몰래 했나?** 하지 않았다. 24·57·159 모두 `할 일` 유지(180 비범위 준수).
- **오타가 남았나?** 첫 편집에서 "파생 훈"/"훅을 둘다"가 있었고 재편집으로 고쳤다(24·159 현재 본문 확인).
