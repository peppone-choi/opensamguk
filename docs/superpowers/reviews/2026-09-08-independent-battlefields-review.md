# 독립 역사 전장 리뷰

기준: d802c4fa02a95f0ffcb60b64e751c929e2b8e59c 이후 작업 변경.
범위: 장판·관도 육상 전장 이동, 적대 조우, 패퇴·귀환, 저장, 지도 예약.

## 수정한 중요 발견

- 전장 주둔자의 국가 예약·즉시 명령이 도시 행동 검사를 우회함: 두 경로에 주둔 검사 추가.
- 위치 DELETE 뒤 재진입 시 revision 재사용: 일반 장수 메타에 마지막 위치 버전을 기록하고,
  재진입 버전을 그보다 크게 할당. 강제 이동 시 이미 만들어진 장수 객체에도 해당 값을 보존.
  recorder 및 flush payload, 재로드 후 이전 귀환 요청 거부를 검증.
- 익명 사용자가 장수 ID로 전장 이동 또는 큐 반복·밀기를 요청할 수 있음:
  모든 command POST 인증 및 장수 소유권 검사. 단일·일괄·국가·반복·밀기 회귀 검증.
- 추가 수송 경로 점검에서 즉시 V2 도시 수송·징병 경로의 주둔 검사 누락을 확인했다.
  직접 핸들러·공용 디스패처·API 사전검사 및 미리보기에 차단을 추가했다.
  원장·경로·자원 접근 전 거부와 정상 terminal 결과를 검증했으며 관련66개 테스트가 통과했다.

## 최종 검토

엔진/인프라는 해당 변경을 작성하지 않은 담당자가 V59의 부분 값 거부, world/topology/revision CAS,
삭제·재진입 병합, 재시작 검증, 도시 수비·내정·국가 명령 제외, 강제 이동 및 전투 정산을 읽기 검토했다.
API 인증과 전장 카탈로그·지도 UI는 별도 담당자가 교차 검토했다. 즉시 V2 경로의 추가 수정도 작성자 외 담당자가 검토했다. 남은 출시 차단 문제를 찾지 못했다.
전체 회귀 테스트의 최종 결과는 작업 report에 기록한다.

이는 적벽 수전·백제성·호뢰관 구현 완료 판정이 아니다. 좌표는 대략적 현대 비정이다.
활성 전장 위치가 생긴 뒤 카탈로그를 바꾸거나 이전 엔진으로 되돌릴 때에는 데이터와 동작 호환성을
따로 검토해야 한다. API와 엔진은 같은 카탈로그 및 V59를 사용해야 한다.
