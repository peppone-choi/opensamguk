## 스펙 대조 메모
- 결과 라벨 `retreat`(퇴각): 수비자 = 비공성 성(재정비 페이즈) 이었고 계획 정지(probe)가 참 → `!fell && stop` 경로로 퇴각 비용(`addLose`·`tryWound`)을 치른 M1 케이스가 실서버에서 그대로 관측됐다.
- 계획 없는 출병(첫 시도, 교전 아님으로 실패)은 리플레이를 남기지 않았다(계획이 봉인된 전투만 기록).
- 봉인 카운트다운 원천은 `/api/reserved-commands.turnTime`(장수 다음 턴 시각, 로컬 시각 문자열) — 정확히 맞았다.
- e2e 1건(봉인→해결→리플레이)은 위 실측이 대신한다 — 스크립트로 재현 가능하되 턴 시각을 SQL 로 당겨야 해서 CI e2e 로는 두지 않는다(spec §10 UNKNOWN 유지).
