## 2. 세력별 판정

### 2.1 조조 — CONFIRMED (병가 + 법가 둘 다)

> 評曰：漢末，天下大亂，雄豪並起… 太祖運籌演謀，鞭撻宇內，**擥申、商之法術，該韓、白之奇策**，官方授材，各因其器，矯情任筭，不念舊惡…
> — `data/corpus/sgz-01.txt:264` (『三國志』卷01 武帝紀 評)

**요청하신 grep 이 실패한 이유:** 표기가 `攬`이 아니라 **`擥`** 이다.

- 申(申不害)·商(商鞅) 之法術 → **법가** 확정. 게임 효과(금수입↑ 치안↑ / 인구↓ 민심↓)와도 맞는다:
  屯田으로 국고를 세웠고(卷01 여러 조), 徐州 대학살·「唯才是舉」(`sgz-01.txt:158`)처럼 민심보다 실효를 택했다.
- 韓(韓信)·白(白起) 之奇策 → **병가** 확정. 기술↑(발석거·屯田器械)·수성↑ 모두 맞는다.

⇒ 1021 = 법가, 나머지 10개 = 병가. **둘 다 사료 근거 있는 갈림.** 잡음 아님.

### 2.2 손권 — MISMATCH (현재 덕가 → 법가 제안)

> 評曰：「孫權**屈身忍辱，任才尚計**，有勾踐之奇，英人之傑矣。故能自擅江表，成鼎峙之業。**然性多嫌忌，果於殺戮**，暨臻末年，彌以滋甚。至於讒說殄行，胤嗣廢斃…其後葉陵遲，遂致覆國，未必不由此也。」
> — `data/corpus/sgz-47.txt:140` (『三國志』卷47 吳主傳 評)

덕가 = 치안↑ **인구↑ 민심↑** / 쌀수입↓ 수성↓. 네 항목 중 세 개가 사료와 충돌한다.

- 民心↑ ↔ 「性多嫌忌，果於殺戮」 · 二宮之爭으로 「胤嗣廢斃」 — 민심 붕괴가 국망 원인으로 명시됐다.
- 수성↓ ↔ 손권 정권의 정체성은 **長江 방어선**이다. 濡須塢 축조, 合肥 공세는 전부 실패하고 방어만 성공했다. 수성↓는 사실과 정반대.
- 쌀수입↓ ↔ 江東 屯田(毗陵·江陵)은 오의 재정 기반이었다.

**대안 우선순위:**
1. **법가** — 금수입↑ 치안↑ / 인구↓ 민심↓. 「果於殺戮」과 「任才尚計」(실적주의 인사)에 가장 정확히 대응한다.
2. **종횡가** — 전략↑ 수성↑ / 금수입↓ 농상↓. 「屈身忍辱」(魏에 稱臣하고 吳王 받음) + 蜀과 동맹·파기 반복은 문자 그대로 縱橫術이다. 수성↑도 맞다.

덕가는 어느 쪽으로도 방어되지 않는다. 6개 시나리오 전부 해당.

### 2.3 유표 — CONFIRMED (유가)

> 表招誘有方，威懷兼洽… 關西、兗﹑豫學士歸者蓋有千數，表安慰賑贍，皆得資全。**遂起立學校，博求儒術，綦母闓、宋忠等撰立五經章句，謂之後定。愛民養士，從容自保。**
> — `data/corpus/hhs-074B.txt:112` (『後漢書』卷74下 劉表傳)

> 劉表**愛民養士，從容自保**，境內無事，關西、兗、豫學士歸之者以千數。表乃**起立學校，講明經術**…
> — `data/corpus/zztj-062.txt:83` (『資治通鑑』卷62)

유가 = 농상↑ 민심↑ / 쌀수입↓. 「愛民養士」「從容自保」로 형주를 「地方數千里，帶甲十餘萬」(`sgz-06.txt:80`)까지 키운 기록과 정확히 맞는다. 학교·五經章句는 儒術 그 자체다. **9개 시나리오 전부 일치, 갈림 없음.** CONFIRMED.

### 2.4 유장 — WEAK (유가)

> 《英雄記》曰：先是，南陽、三輔人流入益州數万家，收以為兵，名曰東州兵。**璋性寬柔，無威略**，東州人侵暴舊民，璋不能禁，**政令多闕，益州頗怨**。
> — `data/corpus/sgz-31.txt:25`

- 「無威略」 → 유가가 치안·수성 보너스를 안 주는 것과 **일치**.
- 益州의 농업 생산력(沃野)은 유가 농상↑과 **일치**.
- 그러나 「益州頗怨」은 유가의 **민심↑과 정면 충돌**한다. 조위(趙韙)의 반란이 民怨을 타고 일어났다고 같은 조가 명시한다.

라벨 자체가 틀렸다고 할 근거는 없으나(유가는 조조·동탁과 대비되는 무위 통치를 잘 표현한다) **민심↑는 사료가 지지하지 않는다.** ⇒ WEAK. 7개 시나리오 전부 유가로 일관되므로 갈림 문제는 없다.

### 2.5 동탁 — 법가 우세, 명가는 MISMATCH

요청하신 「卓性殘忍不仁，遂以嚴刑脅衆」 구절은 **이 코퍼스에서 검색되지 않았다**(`hhs-072.txt`·`sgz-06.txt` 전수 grep: `殘忍不仁`/`嚴刑脅衆` 0건). 대신 확인된 원문:

> 又姦亂公主，妻略宮人，**虐刑濫罰，睚眦必死，群僚內外莫能自固**。卓嘗遣軍至陽城，時人會於社下，悉令就斬之…又**壞五銖錢，更鑄小錢**，悉取洛陽及長安銅人、鐘虡、飛廉、銅馬之屬，以充鑄焉。
> — `data/corpus/hhs-072.txt:35` (『後漢書』卷72 董卓傳)

> 評曰：**董卓狼戾賊忍，暴虐不仁**，自書契以來，殆未之有也。
> — `data/corpus/sgz-06.txt:92`

> **董卓性殘忍**，一旦專政，據有國家甲兵、珍寶，威震天下，所願無極
> — `data/corpus/zztj-059.txt:128`

- **법가(1020·1120) = CONFIRMED.** 虐刑濫罰 → 치안↑(공포치안), 「壞五銖錢，更鑄小錢」로 화폐를 찍어 국고를 채운 것 → 금수입↑, 洛陽 소각·백성 강제 이주 → 인구↓ 민심↓. 네 항목 전부 맞는다.
- **명가(1021) = MISMATCH.** 명가는 기술↑ 인구↑ / 쌀수입↓ 수성↓. 「인구↑」는 董卓의 洛陽 파괴·강제 천도와 정반대고, 小錢 남발로 물가가 폭등해 「穀一斛至數十萬」에 이르렀다는 기록은 오히려 쌀·기술 붕괴를 가리킨다. → **법가로 통일할 것**을 권고. (다만 1021 이 어떤 특수 시나리오인지 별도 확인 필요 — §4 참조.)
- **중립(9200)** — 9200 은 전 세력이 중립인 특수/테스트 시나리오로 보인다(원소도 중립). 성향 판정 대상 아님. UNKNOWN.

### 2.6 장로 — CONFIRMED (오두미도)

> 魯遂據漢中，**以鬼道教民，自號「師君」**… 諸祭酒**皆作義舍**，如今之亭傳。**又置義米肉，縣於義舍，行路者量腹取足**… **不置長吏**，皆以祭酒為治，民夷便樂之。雄據巴、漢垂三十年。
> — `data/corpus/sgz-08.txt:89` (『三國志』卷08 張魯傳)

오두미도 = 쌀수입↑ 인구↑ / 기술↓ 수성↓ 농상↓. **義米(義舍의 무상 쌀·고기)**가 쌀수입↑에, 「民夷便樂之」+關西 수만 가 유입(`sgz-08.txt:91` 「韓遂、馬超之亂，關西民從子午谷奔之者數万家」)이 인구↑에, 「不置長吏」(관료제 부재)가 기술↓·수성↓에 그대로 대응한다. 11개 시나리오 전부 일치. CONFIRMED.

### 2.7 황건적(장각) — CONFIRMED (태평도)

> 初，鉅鹿張角自稱「大賢良師」，**奉事黃老道**，畜養弟子，跪拜首過，**符水呪說以療病，病者頗愈，百姓信向之**。角因遣弟子八人使於四方，**以善道教化天下**，轉相誑惑。十餘年閒，**衆徒數十萬**，連結郡國…
> — `data/corpus/hhs-071.txt:13` (『後漢書』卷71 皇甫嵩傳)

태평도 = 인구↑ 민심↑ / 기술↓ 수성↓. 「衆徒數十萬」 대중 포교 = 인구↑, 「百姓信向之」 = 민심↑, 병기·성곽 없이 黃巾만 두르고 봉기해 관군에 격파된 것 = 기술↓ 수성↓. 완전 일치. CONFIRMED.

### 2.8 유우 — CONFIRMED (유가)

> 虞**務存寬政，勸督農植，開上谷胡巿之利，通漁陽鹽鐵之饒，民悅年登，谷石三十**。青、徐士庶避黃巾之難歸虞者百餘萬口，皆收視溫恤，為安立生業…
> — `data/corpus/hhs-073.txt:21`

> 論曰：… **劉虞守道慕名，以忠厚自牧**。美哉乎，季漢之名宗子也！
> — `data/corpus/hhs-073.txt:168`

「勸督農植」+「胡市/鹽鐵의 利」 = 농상↑, 「民悅年登」+백만 유민 흡수 = 민심↑. 유가와 정확히 맞는다. 3개 시나리오 전부 유가. CONFIRMED.
(참고: 인구↑도 강력하므로 덕가도 방어 가능하나, 「農植·市·鹽鐵」이라는 **경제 진흥** 축이 명시적이라 유가가 더 정확하다. 변경 권고 안 함.)

### 2.9 여포 — CONFIRMED (병가)

> 評曰：**呂布有虓虎之勇，而無英奇之略**，輕狡反覆，唯利是視。
> — `data/corpus/sgz-07.txt:59`

병가 = 기술↑ 수성↑ / 인구↓ 민심↓. 下邳 농성이 수성↑에, 「輕狡反覆」로 兗州·徐州 民望을 잃은 것이 민심↓에 대응. 4개 시나리오 전부 병가. CONFIRMED.

> — `data/corpus/zztj-061.txt:172`

## 3. 시나리오마다 성향이 갈리는 15세력

정리 기준: **사료상 근거 있는 변화**(시기별 국가 성격 변화가 실제로 있었나) vs **잡음**(같은 시점·같은 인물인데 값만 다름).

| 세력 | 값 분포 | 판정 |
|---|---|---|
| 조조 | 병가×10 / 법가(1021) | **근거 있음** — §3.1 |
| 원소 | 법가×5 / 병가×3 / 중립(9200) | **부분 근거** — §3.2 |
| 공손도 | 도적×6 / 덕가×3 | **잡음 + 양쪽 다 오류** — §3.4 |
| 원술 | 병가×4 / 도가×2 | **잡음** — §3.3 |
| 장양 | 묵가×4 / 병가×2 | **잡음** — §3.5 |
| 장연 | 도가×4 / 도적(1031) / 유가(1041) | **잡음, 유가는 오류** — §3.6 |
| 동탁 | 법가×2 / 명가(1021) / 중립(9200) | **명가는 오류** — §2.5 |
| 공융 | 덕가×2 / 유가×2 | **양쪽 다 방어 가능** — §3.7 |
| 공주(孔伷) | 도가×3 / 유가(1021) | **UNKNOWN** — §3.8 |
| 이각 | 병가×2 / 명가(1031) / 도적(1041) | **명가는 오류** — §3.9 |
| 엄백호 | 묵가(1030) / 병가(1031) / 도적(1041) | **도적이 정답** — §3.10 |
| 한복 | 도가(1020) / 병가(1021) | **둘 다 오류 의심** — §3.11 |
| 유대 | 유가(1020) / 병가(1021) | **병가가 오류** — §3.12 |
| 유요 | 묵가(1030) / 유가(1031) | **묵가가 오류** — §3.13 |
| 왕랑 | 덕가(1030) / 유가(1031) | **유가 우세, 덕가도 방어 가능** — §3.14 |

**주목할 패턴:** 갈리는 15세력 중 **9개**에서 `10x0` 계열과 `10x1` 계열이 서로 다른 값을 갖는다
(조조 1020/1021, 원소 1020·1030·1040/1021·1031·1041, 공손도 동일, 원술 1031, 장양 동일, 동탁 1020/1021,
공융 동일, 공주 동일, 한복·유대 1020/1021, 유요·왕랑 1030/1031).
즉 **갈림의 축은 "시기"가 아니라 "시나리오 계열"이다.** 같은 연도의 같은 인물인데 계열만 다르면 값이 달라진다
— 이는 사료 반영이 아니라 **계열별로 다른 사람이/다른 시점에 입력한 편차**임을 강하게 시사한다.
조조(§3.1)처럼 우연히 둘 다 근거가 서는 경우도 있지만, 대부분은 잡음이다.

### 3.1 조조 — 근거 있는 갈림

§2.1 참조. 「擥申、商之法術」(법가) + 「該韓、白之奇策」(병가)가 **한 문장 안에** 있다. 1021 의 법가도, 나머지의 병가도 각각 정사 評의 절반씩을 정확히 집는다. 잡음이 아니라 같은 인물의 두 축을 나눠 표현한 것으로 볼 수 있다. **현행 유지.**

### 3.2 원소 — 부분 근거

> 紹有姿皃威容，**能折節下士，士多附之**
> — `data/corpus/sgz-06.txt:41`

> 紹有姿貌威容，**愛士養名**… 加傾心折節，莫不爭赴其庭，**士無貴賤，與之抗禮**
> — `data/corpus/hhs-074A.txt:8`

> **紹外寬雅有局度**，憂喜不形於色，**而性矜愎自高，短於從善**，故至於敗。
> — `data/corpus/hhs-074A.txt:378`

> 評曰：… 紹鷹揚河朔，然皆**外寬內忌，好謀無決，有才而不能用**…
> — `data/corpus/sgz-06.txt:92`

- **법가**(금수입↑ 치안↑ / 인구↓ 민심↓): 하북 4주를 실효 지배하며 「彊盛莫敵」(sgz-01.txt:264)한 재정·행정력은 맞으나, 「愛士養名」·「士多附之」는 **민심↓와 어긋난다**. 다만 田豐을 죽인 「外寬內忌」는 법가적이다.
- **병가**(기술↑ 수성↑ / 인구↓ 민심↓): 官渡에서 「鷹揚河朔」의 대군을 동원한 것은 맞으나, 원소는 **수성이 아니라 공세로 망했다**(田豐이 「以久持之」 지구전을 권했는데 紹不從 — `sgz-06.txt:58`). 수성↑는 사실과 반대다.
- **중립(9200)**: 특수 시나리오. 판정 대상 아님.

⇒ **법가가 병가보다 낫다.** 병가 3건(1021·1031·1041)은 근거가 약하나, 「사료가 다른 성향을 명확히 가리킨다」 수준은 아니어서 **MISMATCH 로 올리지 않고 WEAK 로 둔다.** 변경 강제 권고는 안 함.

### 3.3 원술 — 잡음 (병가 vs 도가)

> 南陽戶口數百萬，而**術奢淫肆欲，徵斂無度，百姓苦之**。
> — `data/corpus/sgz-06.txt:71`

> 評曰：… **袁術奢淫放肆，榮不終己，自取之也**。
> — `data/corpus/sgz-06.txt:92`

> 裴注: **袁術無毫芒之功，纖介之善，而猖狂于時，妄自尊立**…
> — `data/corpus/sgz-06.txt:92`

- **도가(1030·1040)** = 인구↑ / 기술↓ 치안↓. 「南陽戶口數百萬」은 인구↑에 걸치지만 그건 그가 만든 게 아니라 물려받은 것이고, 「徵斂無度，百姓苦之」로 **탕진**했다. 도가를 지지할 근거 없음.
- **병가(1020·1021·1031·1120)** = 기술↑ 수성↑ / 인구↓ 민심↓. 민심↓·인구↓는 「百姓苦之」와 정확히 맞다. 기술↑·수성↑는 근거 없음(원술은 성 하나 제대로 못 지켰다).

⇒ **병가가 도가보다 훨씬 낫다.** 도가 2건은 사료 근거 없는 **잡음**. 다만 원술의 실상(수탈형 무능)에 정확히 맞는 성향은 목록에 없다 — 굳이 고르면 **법가**(금수입↑ / 인구↓ 민심↓)의 전반부만 뺀 형태다. 강한 변경 권고는 하지 않는다.

### 3.4 공손도 — 잡음 + 양쪽 다 오류 → 법가

> 先時，屬國公孫昭守襄平令，召度子康為伍長。度到官，收昭，**笞殺於襄平市**。**郡中名豪大姓田韶等宿遇無恩，皆以法誅，所夷滅百餘家，郡中震栗**。東伐高句驪，西擊烏丸，**威行海外**。
> — `data/corpus/sgz-08.txt:45`

> 評曰：… **度殘暴而不節**，淵仍業以載兇，秪足覆其族也。
> — `data/corpus/sgz-08.txt:104`

- **도적(6건)** = 계략↑ / 금수입↓ 치안↓ 민심↓. 공손도는 도적이 아니라 요동을 **국가로 세운** 지배자다(자립하여 遼東侯·平州牧 칭호). 「郡中震栗」은 치안↓가 아니라 **치안↑**(공포 치안)이다. 계략↑ 근거 전무.
- **덕가(3건)** = 치안↑ 인구↑ 민심↑ / 쌀수입↓ 수성↓. 「殘暴而不節」·「夷滅百餘家」와 **정면 충돌**. 민심↑는 불가능.
- **법가** = 금수입↑ **치안↑** / 인구↓ 민심↓. 「**皆以法誅**」라는 원문 표현 그대로다. 호족 100여 가 멸족(인구↓·민심↓), 郡中震栗(치안↑), 요동 자립 경제(금수입↑).

⇒ **9개 시나리오 전부 법가로 통일 권고.** 도적↔덕가 갈림은 사료와 무관한 순수 잡음이다.

### 3.5 장양 — 잡음 (묵가 vs 병가), 둘 다 근거 없음

> 《英雄記》曰：**楊性仁和，無威刑**。下人謀反，發覺，對之涕泣，輒原不問。
> — `data/corpus/sgz-08.txt:42`

> 楊當捍外難，何事京都？… 評曰：… **張楊授首於臣下**…
> — `data/corpus/sgz-08.txt:42`, `sgz-08.txt:104`

- **묵가(4건)** = 수성↑ / 기술↓. 「無威刑」에 부하 반란도 용서한 인물이 부하(楊醜)에게 살해당했다 — **수성 능력의 정반대 사례**다.
- **병가(2건)** = 기술↑ 수성↑ / 인구↓ 민심↓. 「性仁和」와 민심↓가 정면 충돌.

⇒ 둘 다 어긋난다. 「仁和·無威刑」에 맞는 것은 **덕가**(민심↑) 또는 **불가**(민심↑ 수성↑ / 금수입↓)다. 다만 그의 통치 실적 자체가 기록에 없어(하내태수, 야왕 주둔이 전부) 확정 근거가 부족하다. **WEAK — 변경 권고는 하지 않되, 묵가/병가 갈림은 잡음으로 기록.**

### 3.6 장연 — 유가(1041)는 명백한 오류

> 張燕，常山真定人也，本姓褚。黃巾起，**燕合聚少年為群盜，在山澤間轉攻**… 燕**剽捍捷速過人**，故軍中號曰飛燕。其後人眾寢廣，常山、趙郡、中山、上黨、河內諸山谷皆相通… **眾至百萬，號曰黑山**。靈帝不能征，**河北諸郡被其害**。
> — `data/corpus/sgz-08.txt:81`

- **도적(1020·1030·1040·1120, 4건)** = 계략↑ / 금수입↓ 치안↓ 민심↓. 「群盜」·「河北諸郡被其害」와 정확히 일치. **CONFIRMED.**
- **도적(1031)** — 위와 동일. 문제 없음. (표 상 1031 이 도적, 1041 이 유가다.)
- **유가(1041)** = 농상↑ 민심↑ / 쌀수입↓. **명백한 오류.** 산곡의 도적 연맹에 농상↑·민심↑는 근거가 없다. → **도적으로 정정 권고.**

### 3.7 공융 — 덕가/유가 양쪽 다 방어 가능

> 融到郡，收合士民，起兵講武… 稍復鳩集吏民爲黃巾所誤者男女四萬餘人，更置城邑，**立學校，表顯儒術，薦舉賢良鄭玄、彭璆、邴原等**… **郡人無後及四方游士有死亡者，皆爲棺具而斂葬之**。
> — `data/corpus/hhs-070.txt:57`

> 慮舉笏曰：「融昔宰北海，**政散民流**，其權安在也！」
> — `data/corpus/sgz-01.txt:172` (裴注 引 江表傳, 郗慮의 논박)

- **유가(1021·1031)**: 「立學校，表顯儒術」 — 직접 근거. **CONFIRMED.**
- **덕가(1020·1030)** = 치안↑ 인구↑ 민심↑: 유민 4만 재정착·무연고자 매장은 덕가의 인구↑·민심↑에 대응한다. 다만 **치안↑는 「政散民流」와 충돌**하고, 실제로 管亥에게 포위돼 유비에게 구원을 청했다(수성↓는 오히려 덕가와 맞다).

⇒ 갈림이 잡음이긴 하나 **양쪽 다 원문 근거가 있다**. 유가가 「儒術」이라는 직접 표현을 갖는 만큼 우세하지만, 강제 변경은 권고하지 않는다. **WEAK(덕가) / CONFIRMED(유가).**

### 3.8 공주(孔伷) — UNKNOWN

> 《英雄記》曰：伷字公緒，陳留人。張璠《漢紀》，載鄭泰說卓云：「**孔公緒能清談高論，噓枯吹生**。」
> — `data/corpus/sgz-01.txt:20`

이것이 孔伷에 대해 남은 **유일한 인물평**이다. 그리고 이 구절의 문맥은 鄭泰가 董卓에게 「관동 연합군은 말만 잘하지 싸울 줄 모른다」고 설득하는 대목 — 즉 **부정적 평가**다.

- **도가(1020·1030·1120)**: 「清談」을 玄學/道家로 읽으면 도가지만, 後漢代 「清談」은 **清議**(인물 품평·관리 비판)로 儒家的 淸流 활동을 뜻하는 것이 통설이며, 위진 玄學的 의미는 후대의 것이다. 도가의 게임 효과(인구↑/기술↓치안↓)를 지지하는 통치 기록은 **전무**하다.
- **유가(1021)**: 淸議 해석을 따르면 유가지만, 역시 「農桑↑·民心↑」를 지지할 통치 기록이 없다.

⇒ 이 인물은 **재임 중 통치 기록이 존재하지 않는다**(예주자사로 부임해 潁川에 주둔했다가 곧 죽음 — `hhs-074A.txt:34`, `sgz-38.txt:12` 「伷卒」). **추측하지 않는다. UNKNOWN.**

### 3.9 이각 — 명가(1031)는 오류

> 傕、汜等以王允、呂布殺董卓，故忿怒并州人，**并州人其在軍者男女數百人，皆誅殺也**。
> — `data/corpus/hhs-072.txt:62`

> 亂兵入殿，掠宮人什物，傕又徙御府金帛乘輿器服，而**放火燒宮殿官府居人悉盡**。
> — `data/corpus/hhs-072.txt:72`

> 承、奉軍敗，百官士卒死者不可勝數… 裴注 引 獻帝傳:「**掠婦女衣被，遲違不時解，即斫刺之**… 凍死及嬰兒隨流而浮者塞水。」
> — `data/corpus/hhs-072.txt:78`

- **명가(1031)** = **기술↑ 인구↑** / 쌀수입↓ 수성↓. 궁전·관부·민가를 전소시키고 부녀자를 학살한 정권에 **인구↑·기술↑는 정반대다. MISMATCH.**
- **도적(1041)** = 계략↑ / 금수입↓ 치안↓ 민심↓. 「掠宮人什物」·「掠婦女衣被」— 문자 그대로 약탈 집단이다. 賈詡의 계책으로 장안을 친 것(hhs-072.txt:62)은 계략↑에도 맞는다. **가장 정확하다.**
- **병가(1030·1040)** = 기술↑ 수성↑ / 인구↓ 민심↓. 인구↓·민심↓는 맞고, 涼州 정예를 지휘한 무장이라는 점에서 방어 가능. 기술↑·수성↑는 근거 없음.

⇒ **명가(1031)는 도적 또는 병가로 정정 권고.** 병가↔도적 갈림 자체는 양쪽 다 절반씩 맞아 잡음 수준.

### 3.10 엄백호 — 도적이 정답, 묵가/병가는 오류

정사에서 嚴白虎는 **독립 열전이 없고**, 손책전 裴注에 「**嚴白虎餘黨**」으로만 등장한다.

> 策前西征，登陰復遣間使，以印綬與**嚴白虎餘黨**，圖爲後害
> — `data/corpus/sgz-46.txt:49` (裴注 引 江表傳)

『三國志』本文의 표현은 「吳郡의 賊帥」(嚴白虎等衆各萬餘, 處處屯聚)로, 오군의 산월계 도적 집단 수괴다.

- **도적(1041)** — 賊帥. **CONFIRMED.**
- **묵가(1030)** = 수성↑ / 기술↓ — 손책에게 단기간에 소탕당했다. 수성↑ 근거 없음. **MISMATCH.**
- **병가(1031)** = 기술↑ 수성↑ — 동일한 이유로 근거 없음. **MISMATCH.**

⇒ **1030·1031 을 도적으로 통일 권고.** (본 보고서 §1 고칠 값 목록에는 근거 강도가 「餘黨」 한 줄에 의존하므로 넣지 않았다 — 판정만 기록한다.)

### 3.11 한복 — 둘 다 근거 없음

> 《英雄記》曰：馥字文節，潁川人。爲御史中丞。董卓舉爲冀州牧。于時冀州民人殷盛，兵糧優足… 馥得移，請諸從事問曰：「今當助袁氏邪，助董卓邪？」治中從事劉子惠曰：「今興兵爲國，何謂袁、董！」**馥自知言短而有慙色**。
> — `data/corpus/sgz-01.txt:20`

- **병가(1021)** = 기술↑ 수성↑ / 인구↓ 민심↓. 韓馥은 원소에게 **싸우지도 않고 기주를 넘겼다**. 수성↑는 정반대. **MISMATCH 급.**
- **도가(1020)** = 인구↑ / 기술↓ 치안↓. 「冀州民人殷盛，兵糧優足」은 인구↑에 걸치지만, 그건 그가 만든 게 아니라 기주의 원래 상태다. 근거 약함.

⇒ 「자기 판단이 없고 남에게 밀린다」는 인물상에 대응하는 성향이 목록에 없다. **도가가 병가보다 덜 틀리다.** 강한 변경 권고는 하지 않으나, **병가(1021)는 근거 없음**을 기록한다. WEAK/MISMATCH 경계.

### 3.12 유대 — 병가(1021)는 오류 → 유가

> 續漢書曰：繇父輿，一名方，山陽太守。岱、繇皆有雋才。《英雄記》稱**岱孝悌仁恕，以虛己受人**。
> — `data/corpus/sgz-49.txt:11` (裴注)

- **유가(1020)** = 농상↑ 민심↑. 「孝悌仁恕」·「虛己受人」과 일치. **CONFIRMED.**
- **병가(1021)** = 기술↑ 수성↑ / **인구↓ 민심↓**. 「仁恕」와 정면 충돌. 게다가 劉岱는 鮑信의 만류를 무시하고 황건적과 무모하게 싸우다 전사했다 — 병가의 군사적 유능함을 지지하는 근거도 없다. **MISMATCH → 유가로 정정 권고.**

### 3.13 유요 — 묵가(1030)는 오류 → 유가

> 評曰：**劉繇藻厲名行，好尚臧否**。至於擾攘之時，據萬里之土，非其長也。
> — `data/corpus/sgz-49.txt:52`

> 繇奏免之(탐관 중상시의 아들)… 平原陶丘洪薦繇，欲令舉茂才… **孫策東渡，破英、能等。繇奔丹徒**，遂泝江南保豫章… **繇進討融，為融所破**
> — `data/corpus/sgz-49.txt:13`

- **묵가(1030)** = **수성↑** / 기술↓. 유요는 손책에게 **한 번에 무너져 도망쳤고**, 이후 笮融에게도 패했다. 「據萬里之土，非其長也」— 사료가 명시적으로 그의 방어·경영 무능을 지적한다. **수성↑는 정반대. MISMATCH.**
- **유가(1031)** = 농상↑ 민심↑ / 쌀수입↓. 「藻厲名行，好尚臧否」(名節을 닦고 인물 품평을 즐김) = 전형적 淸流 儒者. 백부 劉寵이 「取一錢太守」로 불린 청렴 유가 가문이기도 하다(`sgz-49.txt:11`). **CONFIRMED.**

⇒ **1030 을 유가로 정정 권고.**

### 3.14 왕랑 — 유가 우세, 덕가도 방어 가능

> 王朗字景興，東海郡人也。**以通經**，拜郎中… 「**春秋之義，求諸侯莫如勤王**」… 《朗家傳》曰：會稽舊祀秦始皇… 朗到官，**以爲無德之君不應見祀，於是除之。居郡四年，惠愛在民**。… 策以**朗儒雅**，詰讓而不害。
> — `data/corpus/sgz-13.txt:43`

- **유가(1031)** = 농상↑ 민심↑. 「以通經」·「儒雅」·『春秋』 인용 — 직접 근거. **CONFIRMED.**
- **덕가(1030)** = 치안↑ 인구↑ 민심↑ / 쌀수입↓ **수성↓**. 「惠愛在民」은 민심↑에 맞고, 손책에게 회계를 지키려다 패해 바다로 달아난 것(「朗自以身爲漢吏，宜保城邑，遂舉兵與策戰，敗績」)은 **수성↓와도 맞는다.** 방어 가능.

⇒ 「以通經」이라는 명시적 儒 표기가 있으므로 유가가 우세하나, 덕가도 사료와 충돌하지 않는다. 갈림은 잡음이지만 **오류는 아니다.** 변경 권고 없음.

### 3.15 (참고) 유비 1100 = 유가

사전 확정 판정은 덕가이고 시나리오 1020~1090 은 모두 덕가인데, **1100 만 유가**다. 사료 재판정 없이도 **내부 불일치**다(같은 인물·같은 정권). 같은 1100 계열에 조비=병가, 맹획=도적이 있고 1110 에 유선=유가가 있는 것으로 보아, **후기 시나리오 계열의 입력 편차**로 보인다. §1 고칠 값 목록에 포함.

## 4. 검증하지 못한 것 (정직하게)

1. **「卓性殘忍不仁，遂以嚴刑脅衆」 구절을 코퍼스에서 찾지 못했다.** `data/corpus/hhs-072.txt`·`sgz-06.txt` 전수 grep 결과 `殘忍不仁`·`嚴刑脅衆` 모두 0건. 동탁 판정은 실제로 찾은 다른 구절(`hhs-072.txt:35` 「虐刑濫罰，睚眦必死」, `sgz-06.txt:92` 評 「狼戾賊忍，暴虐不仁」, `zztj-059.txt:128` 「董卓性殘忍」)로 대체했다. 원 구절이 다른 사서(『後漢書』 다른 판본, 『三國志』 裴注 引 英雄記 등)에 있을 수 있으나 **이 저장소 코퍼스에는 없다.**
2. **유언(劉焉)의 통치 기록을 확정하지 못했다.** 익주 호족 숙청(王咸·李權 등)·乘輿車具 참람 제작 대목의 원문을 `sgz-31.txt` 에서 grep 으로 잡지 못했다(권 앞부분만 확인). 유언 = 유가 판정은 따라서 **WEAK 로만 남긴다.** 재검하면 법가로 바뀔 가능성이 있다.
3. **시나리오 코드의 의미를 확인하지 않았다.** `1020` vs `1021`, `1030` vs `1031` 이 각각 무엇인지(연도 동일·설정 변형? 다른 출전?) 확인하지 않았다. §3 의 「계열별 편차」 패턴 진단은 값 분포에서 관찰한 것이지, 시나리오 정의를 읽고 내린 결론이 아니다. `9200`(전 세력 중립)과 `1120`의 성격도 미확인.
4. **조비·조예·유선의 통치 성향을 검증하지 않았다.** 위·촉 후계 정권 3건은 원문 조사를 하지 않고 WEAK 로 처리했다.
5. **1070 형남 4군 태수(한현·조범·유도·금선)는 사료가 존재하지 않아 검증 불가**다. 넷의 서로 다른 성향(묵가/도가/덕가/도가)은 『三國演義』에서도 통치 서술이 없어 어떤 출전으로도 가를 수 없다.
6. **「중」(1041, 병가)의 정체를 확정하지 못했다.** 원술의 참칭 국호 「仲家」로 추정하나 시나리오 데이터에서 확인하지 않았다.
7. **유총(劉寵)의 동일인 판정을 못 했다.** 최소 3명의 劉寵이 사료에 있고 어느 쪽인지 데이터만으로 알 수 없다.
8. **웹 보충 검색은 하지 않았다.** 저장소 코퍼스(sgz/hhs/zztj/hyg)만으로 판정했다. 위 미검증 항목은 웹 원문 대조로 닫을 수 있다.
