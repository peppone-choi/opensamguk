## P2 Goal

P2 widens the proven P1 vertical slice into the full **non-combat command surface** of the devsam-core grand truth: the ~36 non-combat General/Nation commands (내정 개발, 군사/이동, 인사, 건국/거병, 자원교역), the full ~71-class constraint library, the real (non-identity) 9-source stat stack, the ~8 내정특기 + 12 성격 + 15 국가타입 + declarative item modules that feed it, the satellite write-set (rank_data / general_record / LastTurn term-stack / cooldown KV), and the two-tier log-golden gate.

P2 **extends, never reshapes, the P1 framework**. P1 already proved, byte-faithfully:

- `CommerceInvestment.kt` — the parameterized 내정 develop algorithm (RNG draw order, front-debuff, log strings, meta writes).
- `GeneralActionPipeline` / `GeneralActionModule` — the stat-stack fold, shipped as an **empty identity module list**.
- `GetStatValue.kt` — the layered stat calc (injury → cross-stat → double-clamp → fold → truncate), shipped **cache-free**.
- `EvaluateConstraints` + `Presets.kt` (7 presets) + `ConstraintContext FULL/PRECHECK` + `StateView/MemoryStateView`.
- `DomesticHelpers.kt` (criticalRatioDomestic / criticalScoreEx / getDomesticExpLevelBonus / updateMaxDomesticCritical).
- `JdbcFlushExecutor` (10-step ordered contract; steps 8/10 reserved-but-unimplemented), `ChangeRecorder`, `ReservedTurnHandler`.
- `phpRound` / `clamp` / `valueFit` / `numberFormat` — PHP-faithful half-away-from-zero rounding.
- `tools/php-golden` capture harness + the six-component `simpleSerialize` RNG seed discipline.

Every P2 unit below is framed as a **delta against these P1 artifacts**: what it extends, the pinned port_notes (byte-match hazards), gaps/open-questions, and suggested P2 plan areas.

## Cross-cutting prerequisites (recur in nearly every unit)

These appear independently across most units and should be treated as **shared P2 foundation work**, scheduled ahead of the per-command resolvers:

1. **Domain entity expansion** (`logic/domain/LogicEntities.kt`): the P1 `General`/`City`/`Nation` are minimal. P2 needs `General += crew/train/atmos/crewTypeId/troop/horse/weapon/book/item/npcType/leadership_exp/strength_exp/dedlevel`; `City += tech/security/defense/wall/pop/(+each _max)/trade`; `Nation += name/color/typeCode/gold/rice/tech/gennum/capset/aux + meta(rate/bill/surlimit/secretlimit/strategic_cmd_limit)`; plus new `Diplomacy` + `NationTurn` entities. Thread through StateView/MemoryStateView, JPA read repos, and JDBC row mappers (no `NationRowMapper`/`DiplomacyRowMapper`/`NationTurnRowMapper` exist yet).
2. **Action substrate widening** (`GeneralActionDefinition` / `GeneralActionResolveContext` / `GeneralActionDraft`): add `buildMinConstraints` (min-vs-full split), `parseArgs/argsSchema` (reqArg commands), an optional `destGeneral`/`destCity`/`destNation` in the draft (인사/등용/증여), created-set + cascade collections (건국/거병/방랑), and the `LastTurn` 4-field value object + capset-seq term-stack helper.
3. **Pipeline interface widening** (`ActionPipeline.kt`): the P1 `GeneralActionModule` has only `onCalcStat` + `onCalcDomestic`. P2 must add `onCalcStrategic` + `onCalcNationalIncome` (+`onCalcOpposeStat` stub) + an `aux` param, keeping identity defaults, then populate the module list in the canonical `getActionList()` order.
4. **`RequirementKey` extension** (`ConstraintTypes.kt`): add `DestGeneral`/`DestCity`/`DestNation`/`NationList`/`GeneralList`/`Diplomacy` kinds for dest-* and DB-backed constraints.
5. **The unique-item lottery RNG seam** (`genGenericUniqueRNGFromGeneral` + `tryUniqueItemLottery`): a separate `LiteHashDRBG` seeded by `(hiddenSeed,'unique',year,month,generalID,actionName)`, fired at the end of nearly every command, human-only (NPCType>=2 short-circuits with no draw). Should be a foundation task ahead of any per-command resolver so RNG-consumption order matches.

### Summary
The 내정 개발 family has THREE behavioral shapes, all sharing the same RNG draw order (base-score rng → pick rng → crit-score rng) and the same `onCalcDomestic` accumulation hook:

- **Group A — CommerceInvestment base.** `che_상업투자` is the literal PHP base; 5 others extend it by overriding only static props: `che_농지개간` (DONE in P1), `che_성벽보수`, `che_수비강화`, `che_치안강화`, and `che_기술연구` (a sibling shape — overrides `init()` to drop RemainCityCapacity and `run()` to drop front-debuff, applies `TechLimit /4`, writes `nation.tech += score/genCount`).
