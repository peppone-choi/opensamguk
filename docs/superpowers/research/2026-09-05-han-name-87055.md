# NAME-87055 남련현(南䜌县) 교정 근거와 불변성 증명

Date: 2026-09-05
Scope: B2a의 physical place ID `87055` 이름만 교정
Decision: `남?현` / `南?县` → `남련현` / `南䜌县`

## 사료 근거

메타 저장소의 비공개·ignored 사료 코퍼스는 읽기 전용으로 확인했으며 이 변경에 포함하지 않았다.

- `references/sources/shiliao/corpus/hhs-001A.txt:44`: `光武逆戰於南䜌`이라고 쓰고 주석에서 `䜌音力全反`이라 한다.
- `references/sources/shiliao/corpus/hhs-110.txt:304`: 군국 목록에 `南〈糸言糸〉`가 있다. 합성 표기는 `䜌`의 자형을 풀어 쓴 것이다.
- `references/sources/shiliao/corpus/hs-015.txt:489`: `南䜌侯佗`와 `䜌音力專反`이 함께 나온다.
- [Wiktionary 䜌](https://en.wiktionary.org/wiki/䜌)의 Korean Hanja 항목은 `련 > 연`을 제시한다. 이 작업의 승인된 literal 표기는 `남련현`이다.

세 자료가 결손자 `?`의 본자를 `䜌`으로 독립적으로 뒷받침한다. 사료 문맥에는 巨鹿 소속이 나오지만 이름 판정과 현행 지도 소속 판정은 별개다. 따라서 현행 `PARENT-0017`(安平國)과 모든 parent/owner 값은 그대로 두었다.

## 구현 결정

`CANONICAL_PLACE_NAME_NORMALIZATIONS`에 ID `87055`의 정확한 source pair와 canonical pair 한 건만 추가했다. 정규화는 다음 네 materialized view를 같은 literal로 바꾸며, 입력 객체 비변형·멱등성과 source-pair drift 거부를 테스트한다.

- `cities[].name/nameCh`
- `provinceRecords[].displayName/nameCh`
- `jurisdictionRecords[].displayName/nameCh`
- `legacyGameplay.cities[].name/nameCh`

원본 타일 격자는 재생성하지 않았다. 커밋된 `han-tiles.json`에 기존의 좁은 이름 materializer만 적용했다. physical ID `87055`는 runtime city catalog에 원래 없고 새 runtime city도 만들지 않았다.
