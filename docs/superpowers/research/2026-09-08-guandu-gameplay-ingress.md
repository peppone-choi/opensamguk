# 관도 전장 접근 검토

관도는 공급된 나무위키 원문의 독립 지명 좌표 `34.75145, 114.05092`를 APPROXIMATE 대표점으로 사용한다. 사료상 사건 정체성과 현대 대표점은 `data/curated/han/historical-battlefields-v1.json`에서 별도로 기록한다. 사건 연도 200년은 건설 연도가 아니다.

현대 좌표 출처는 공급된 사례교위부 문서 SHA-256 `547b51d1dc251c680550a02184f0b4156115dd5bbafca06a76abd9186952704f`, 198행 `관도(官渡): 《34.75145, 114.05092》`다. 새 웹 열람으로 검증한 좌표라는 주장은 하지 않는다.

## 재구성된 게임 접근

현재 지도에서 원무(runtime city 51, `chgis:v6:cnty:82531`, routeNodeKey `fc9fb827-d963-4e41-818e-6cdf8e18a4fd`)를 진입 도시로 사용한다. 이는 현재 게임 격자 위 같은 영토 내 배치이며 고대 도로 복원이나 관도의 역사적 원무현 소속 판정이 아니다.

검토한 `data/map/han-tiles.json` SHA-256은 `5feffb4a8a1af8a58203f62fa1497c2d82ea5903c21f4f175411d9dff56afcfb`다. 저장된 projection으로 관도는 `(403.400596444, 233.243181422)`에 투영되고 floor cell `(403,233)`의 owner index 592는 stable province `82531`이다.

실제 도시 표시 anchor `(404,231)`에서 `(403,231) → (403,232) → (403,233)`으로 이어지는 4방향 격자 경로를 확인했다. 모든 칸은 owner `82531`, terrain `1`(평지)이며 물이나 하천 칸을 통과하지 않는다. 현재 `water-topology-adjudications-v1.json`의 barrierAdjudications는 빈 배열이다. 새 그래프 간선이나 보급 간선을 만들지 않는다.

## 원본 좌표와 표시 위치의 차이

원무 행에 남은 원본 좌표 `35.05195, 113.96297`는 관도에서 직선 약 34.363 km 떨어지고 현재 투영 시 `(401,226)`, owner `82523`에 놓인다. 게임에 적용된 표시 anchor `(404,231)`는 이 원본 투영과 다르다. 표시 칸 중심은 `34.833222135, 114.110471055`로 관도에서 직선 약 10.595 km다.

따라서 위 접근 증거는 **게임에 적용된 anchor에서의 경로**에만 해당한다. 고대 원무 현치에서 관도까지의 도로, 하천 경계, 전장 범위는 확정하지 않는다. 장판과 동일한 이동·조우 규칙을 재사용하며 지명에서 능력 보너스를 추론하지 않는다.

## 구현 검증

원무 진입 binding과 실제 순수 진입 평가, 원무·당양별 API 가능 여부 및 각 진입 도시 이름 안내를 회귀 테스트로 확인했다. `HistoricalBattlefieldCatalogTest` 3건과 `BattlefieldControllerTest` 4건이 통과했다. 지도/UI의 전장 ID는 도시 ID와 분리되어 있으며 전투 규칙을 새로 추가하지 않는다.
