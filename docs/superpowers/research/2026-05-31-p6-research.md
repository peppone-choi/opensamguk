## 0. The cross-cutting verdict (read this first)

P6 is **mostly an RNG-free, delta-plumbing phase**. The entire domain has only **three** real RNG sites that the daemon replays:

1. `registerAuction` (monthly tick) — 2 `nextBool` + up-to-4 `nextRangeInt` on the **shared monthly RNG** (draw-ORDER parity, after `triggerTournament`).
2. `Auction::genObfuscatedName` — **ONE** Fisher-Yates `shuffle` of the 6525-element name pool, on a **dedicated** `RandUtil(LiteHashDrbg(simpleSerialize(hiddenSeed,'obfuscatedNamePool')))`, **once per game, KV-cached**.
3. `startBetting` (tournament-betting open) — **one `choice()` per eligible NPC** on a **fresh self-seeded** `RandUtil(simpleSerialize(hiddenSeed,'OpenBettingTournament',bettingID))`.

Plus three **api-side ephemeral** RNG sites (replayable from a pinned seed, NOT the turn stream): `ResetTurnTime` (1× `nextFloat1`), `ResetStat`-no-bonus (`nextRangeInt(3,5)` + N× `choiceUsingWeight`), and the `worldCommand`/pool/builder/vote-lottery draws (`che_인재탐색`, `RandomNameGeneral`, `GeneralBuilder`, `voteReward`). **Tournament `fight()` runs on PHP global `rand()` and is UN-REPLAYABLE → quarantined; the daemon consumes the computed match result, never the fight RNG.**

Everything else — every diplomacy/accept command, every betting payout, every inheritance fold, every auction bid/finish — is **deterministic** (`NoRNG` or no draw at all). Confirming the **absence** of draws is itself a parity assertion.

The real work is **delta channels** the Kotlin daemon does not yet have:
- `ChangeRecorder` has `diffGeneral/diffCity/diffNation` + `recordRankIncrease/Set` but **NO** `diffDiplomacy` (UPDATE), **NO** `recordKv`, **NO** message/auction/betting/inheritance channels (verified).
- `DirtyState.kvDirty` exists but is **always `emptyMap()`** — nothing populates it, and **neither** `DatabaseHooks.toFlushPayload` **nor** `TurnRunService.buildFlushPayload` maps `kvDirty → kvWrites` (verified).
- `KvWrite.namespace` is `Int` (nation-id) only — `game_env`/`betting`/`inheritance_{id}` (string namespaces) have no home (verified).
- `FlushPayload` has `createdDiplomacy` + `kvWrites` but **NO** `updatedDiplomacy`, **NO** `createdMessages`, **NO** auction/betting channels (verified).
- `TruncateContract.SURVIVE` already lists `inheritance_*` (good) but `auction`/`auction_bid` are in `TRUNCATED`, and there is **no `message`/`ng_betting` table** in V1–V6 (verified).
- `TurnRunService.buildFlushPayload` flushes ONLY general+city dirty rows — it **drops** `nationPatches`/`rankPatches`/`kvDirty`/diplomacy/deleted-nation deltas. `DatabaseHooks.toFlushPayload` is the more-complete path. **#1 round-trip risk: converge the two flush builders first.**

## 8. FULL RNG DRAW CATALOG (ordered, every site the daemon or api replays)

> **THE THREE DAEMON-STREAM SITES + THE EPHEMERAL API SITES. Draw ORDER + COUNT + method-args are all parity targets.**

### 8a. Monthly tick — `registerAuction` (shared monthly RNG, after `triggerTournament`, before SetNationFront)
PHP `func_auction.php:7-59`. Threaded on the SAME `monthlyRng` passed to `postUpdateMonthly` — **NOT a fresh seed**.
```
ORDER (BuyRice block first, then SellRice block):
  1. nextBool(1.0/(neutralBuyRiceCnt+5))          # prob always <1, never 0.5 → routes to nextFloat1()<prob (NOT nextBit)
     if true:
  2.   nextRangeInt(1,5)   = mul                   # = nextInt(4)+1
  3.   nextRangeInt(3,12)  = term                  # = nextInt(9)+3
  4. nextBool(1.0/(neutralSellRiceCnt+5))          # ALWAYS drawn, independent of BuyRice
     if true:
  5.   nextRangeInt(1,5)   = mul
  6.   nextRangeInt(3,12)  = term
```
amount/cost/topv via `Util::round(-1)` (half-away nearest-10). Total = **2 bools + up-to-4 ints**, conditional.

### 8b. One-time-per-game — `Auction::genObfuscatedName` (dedicated DRBG, KV-cached)
