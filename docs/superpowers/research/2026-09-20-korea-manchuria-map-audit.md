## 해결한 항목

- **NORTHERN-MANCHURIA / OUTSIDE_GRID**: 북쪽 174행·동쪽 96열을 확장하여 864×843 격자와 북위 53.855도까지 포함. Natural Earth 지형과 NOAA ETOPO1 표고를 추가하고 원래 셀의 지리 좌표를 보존했다. 송화강·흑룡강·우수리강 취락권은 게임 지리 구획이다.
- **BUYEO / SPARSE**: 길림 대표점과 돈화·이통하·농안의 현대 지역 대용점, 총 4개 거점을 유지한다. 자동 배치한 15곳은 사용자 지적으로 제거했다. 사출도 방향을 임의의 소국명으로 만들지 않는다.
- **YILOU / PARENT_ABSTRACTION**: 읍루 상위 구획 분리와 목단강 지역 대용점은 유지한다. 자동 배치한 15곳을 제거하여 현재 2개 거점이다. 개별 취락 근거 없이 밀도를 맞추지 않는다.
- **MAHAN / SPARSE**: 마한 26개 거점. 한강 취락 271·272를 제거했다. 비정 근거가 있는 소국명과 현대 지역 대용점을 구분하며 문헌상 54국 전체의 위치를 확정하지 않는다.
- **MAHAN / DISPUTED_LOCATION**: 목지국은 익산설을 게임 배치로 채택·유지했다. 직산·성환·아산만 경쟁설을 위치 메타데이터에 보존하고 건마를 같은 지점에 중복 생성하지 않았다.
- **YE / SPARSE**: 예·불내·화려·맥 4개 거점을 유지한다. 자동 배치한 동예 해안 취락 2곳을 제거했다. 북명은 기존 강릉 예 거점의 전승명에 연결한다.
- **GOGURYEO / IMPROVED_NOT_EQUALIZED**: 고구려권은 비류·조나·주나·개마·구다·행인·양맥·소수맥 및 지리 대용점을 포함해 12개 거점이다. 자동 배치한 17곳을 제거했다. 평균 430.1칸/도시로 마한과 동일 밀도는 아니며, 밀도만을 이유로 도시를 발명하지 않는다.
- **JINHAN / INCOMPLETE_ROSTER**: 골벌·이서·감문·우유·근기·우시산 등을 포함해 진한권 11개 거점으로 보강했다. 병합 전 소국명과 220년 독립국 지위를 구별했다.
- **BYEONHAN / LATE_NAMES**: 변한권 9개 거점으로 보강하고 대가야→반로, 성산가야→성주 취락, 고령가야→함창 취락으로 운영 표기를 수정했다. 후대 명칭은 별칭과 비정 이력에 남겼다.

## 사료와 경제

『삼국지』 위서 동이전의 지역 단위 호수·생산 기록을 경제 근거로 보존했다. 부여 8만 호, 고구려 3만 호, 동옥저 5천 호, 예 2만 호, 마한 10만여 호, 진·변한 4–5만 호는 개별 도시 인구로 복제하지 않는다. 농업·어염·철·가축·직물 등은 해당 원문 구절과 지역 범위로 연결했다. 사료에 없는 도시별 수치는 게임 기획이다. 새 도시의 인구·농업·상업 초기값과 최대값은 기존 후원 관할의 총량을 정수 분배하여 보존했다. 한 군현 호수 예산을 나눈 경우에도 실제 지방 호적이라는 뜻이 아님을 표시했다.

출처와 인용은 `korea-economic-evidence-v1.json`의 9개 근거군, 21개 원문 인용에 기록했다. 현대 좌표는 비정 또는 배치 대용점이며, 고대 유적 실측 좌표로 표시하지 않는다. `GAME_DESIGN_FARTHEST_LAND_CELL` 방식으로 만든 147곳은 활성 데이터에서 모두 제거했다. 거점 밀도 차이를 허용하며 공간 구획만 나누는 것은 도시 추가로 보지 않는다.

## 지형·운영 호환

864×843 격자의 북쪽 한계는 북위 53.855도이다. 기존 768×669 셀은 174행 아래에 그대로 보존되며, 물리 좌표는 바뀌지 않는다. 추가 지형은 Natural Earth 공개 자료, 표고는 NOAA ETOPO1이다. 기존 저장 지도는 기존 표고 파일을 계속 선택한다. 1,133·1,141·1,341 동결 묶음을 덮어쓰지 않고 1,194 묶음을 별도로 생성했다.
