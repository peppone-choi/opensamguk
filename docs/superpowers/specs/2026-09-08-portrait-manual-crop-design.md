# 전콘 3종 수동 편집

2026-09-08 사용자 승인: 원본 하나에서 히어로·카드·아이콘 구도를 각각 드래그와 확대·축소로 조절하고, 세 결과를 함께 미리 본 뒤 저장한다. 원본을 보존한다. 확정 Concept A의 색·각진 프레임·비율을 따른다. 얼굴 자동 인식은 이번 범위에 포함하지 않는다.

- 히어로 633×900, 카드 148×210, 아이콘 96×96. 각 편집 상태 독립, 원본 범위 밖으로 나가지 않는다.
- 키보드로 조절 가능한 확대·수평·수직 슬라이더, 포인터 드래그, 휠 및 핀치 확대, 선택 구도 초기화.
- 세 구도를 확정해야 한 번 저장하며, 실패하면 기존 전콘 및 편집 상태를 유지한다. 기존 하루 한 번 변경 제한은 그대로다.
- 원본 파일과 정규화 좌표 세트, 서버가 생성한 세 JPEG를 단일 관리 archive에 저장해 기존 journal/reconcile의 원자성을 유지한다. 원본은 본인 인증 경로로만 제공하며 다시 편집할 수 있다.
- 기존 단일 이미지 전콘과 공유 초상은 계속 표시된다. 신규 archive 파일은 공개 직접 다운로드 대상이 아니다. 공개 경로는 검증된 세 변형만 제공한다.
- 원본 최대 8MiB, 한 변8192px 이하 및24MP 이하. 서버에서 실제 디코딩/경계/프레임 수/좌표를 검증한다. EXIF 방향을 편집 화면과 일치시킨다.
- 누락 NPC 인터넷 이미지 탐색은 별도 opensamguk-images 작업으로 수행한다.
