# 극현 첫 국소 프로빈스 이설

후한 지도 계획 §7과 ADR-LITE-051에서 승인한 지도 정확도 개선 중 극현 한 곳을 구현한다.
행정 보급선은 별도 정책이며 이동 간선을 합성하지 않는다.

- 입력: han-tiles SHA256 `237b8f1d8a8228a89fa251b4020ef254c2176aedd4ba3133c4996a630bd07a63`.
- 극현: place/province `85272`, cityIndex162, provinceIndex703, runtime city347. 영구 ID와 배열 순서를 보존한다.
- 근거: `namu-place-locations-v1.json` 北海國/劇, lat36.65675/lon118.77496, sourceUrl `https://namu.wiki/w/삼국지/지명/청주`. 기존 타일 경위도와 일치하는 저장된 근거이며 새 수확을 주장하지 않는다.
- 저장된 Proj.to_cell 투영은 (490.6136007662378,192.62685699826318), 포함 셀(490,192). 군치 juns38은 이미 그 셀이다. 기존 도시 라벨(462,179)을 목표 셀로 옮긴다.
- 목적지는 安丘 `85325`/province709 기존82셀 안이다. 극현의 투영점과 안구 기존 라벨 셀 중심(497.5,198.5)의 두 점 Voronoi를 기존 안구 마스크 안에서만 수행한다. 극현36셀/안구46셀이 된다.
- 극현 옛25셀은 접경 owner에서 시작한 4방향 flood fill로 메운다. 거리 동률은 영구 province ID 순서. 알려진 오배치 동안평85217은 수혜 대상에서 제외한다. 결과 delta61셀을 장부로 고정한다.
- 다른 owner셀, terrain, seatOwner, juns, 모든 ID와 부모 할당은 불변. parentOwner와 인접은 owner에서 다시 유도한다. 극현/안구는 단일성분, 좌석 포함, 최소8셀. 보호 도시305/548의 영역과 공급 정책을 보존한다.
- 새 경계는 출처 좌표에 맞춘 국소 적응이며 역사적 경계의 정밀 복원이 아니다.
- 기존 fragment 장부를 수정해 허용하지 않는다. 후속 이설 장부가 exact reverse delta로 이전 상태를 복구한 뒤 기존 fragment materializer 전체를 통과하고, 이설을 다시 적용해 현재 산출물과 일치시킨다.
- 직접 핀과 종속 생성물을 의미 검증 후 재생성한다. 기존 판정·보호행을 삭제하거나 LAND 인접 검사를 완화하지 않는다. 예상하지 못한 판정 충돌은 기록·보고 후 별도 판정한다.
