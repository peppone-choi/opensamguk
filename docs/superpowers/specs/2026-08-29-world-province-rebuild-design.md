# 220년 세계 프로빈스 재구축 설계

## 목표

현재 `han` 지도의 전역 육지 프로빈스를 역사 자료 우선, 현대 행정 경계 차선,
지형 보정 최후 순서로 다시 만들고 새 산출물로 현재 맵을 대체한다. 중국 내부의
군현제와 중국 외부 정치체의 명칭 체계를 분리하며, 과대·장형·격자형·분리형
프로빈스를 생성 단계에서 차단한다.

## 범위

- 기준 연도는 220년이다.
- 중국, 한반도, 만주, 몽골, 일본, 베트남 및 현재 `han` 프레임의 모든 육지를
  같은 생성 계약으로 처리한다.
- 기존 220년 역사 행정 단위, 안정 ID, 부모 관계, 치소 및 런타임 도시 호환성은
  보존한다.
- 역사 자료로 확인되는 외부 정치체와 소국은 새 프로빈스 중심 후보로 추가할 수
  있다.
- 현대 경계와 현대 지명은 역사적 사실로 승격하지 않는다. 현대 지명은 경계
  출처와 검토 메타데이터에만 보존한다.
- 기존 `han-780-v1`은 복구용 불변 산출물로 남기고, 새 버전의 맵을 생성해 활성
  맵 포인터를 전환한다. 과거 월드 스냅샷은 기존 버전을 계속 읽을 수 있어야 한다.

## 자료 우선순위

각 프로빈스와 경계 조각은 다음 중 하나의 `geometryBasis`를 갖는다.

1. `HISTORICAL_BOUNDARY`: 220년 전후의 검토된 행정·정치 경계.
2. `HISTORICAL_SEAT_ADAPTED`: 검토된 역사 치소·중심점과 현대 경계의 합성.
3. `MODERN_ADMIN_FALLBACK`: 현대 하위 행정 경계를 병합 또는 분할한 차선 형상.
4. `TERRAIN_DERIVED`: 산맥·강·분수령과 통행비용으로 남은 틈을 보정한 형상.

낮은 우선순위 자료는 높은 우선순위 경계를 덮지 않는다. 모든 입력은 버전,
체크섬, 라이선스, 취득일, 적용 범위와 함께 빌드 계약에 고정한다. 라이선스가
배포를 허용하지 않는 입력은 원본을 저장소에 넣지 않고, 제한 입력 역할과
체크섬만 재현성 계약에 기록한다.

## 프로빈스 모델

`province`는 지도·게임의 공통 공간 단위이며 `city`나 한나라의 `縣`과 동의어가
아니다. 기존 `owner`의 도시 배열 인덱스 결합을 제거하고 안정 `provinceId`를
독립적으로 부여한다.

프로빈스는 다음 정보를 가진다.

- 안정 `provinceId`
- 표시명과 원문명
- `administrativeSystem`
- 상위 `parentRegionId`
- 선택적 역사 치소·정치 중심점
- `geometryBasis`, 신뢰도, 출처 목록
- 220년 유효 구간
- 플레이 가능 도시 또는 중립 직접영역 연결

한 역사 치소나 외부 소국 중심점은 원칙적으로 하나의 프로빈스를 확보한다.
역사 중심점이 없는 현대 경계는 독립된 가상 군현을 만들지 않는다. 목표 면적을
넘지 않으면 인접 역사 프로빈스와 병합하고, 반드시 분할해야 하는 넓은 공백은
`DIRECT_TERRITORY`로 두어 상위 정치체가 직접 소유하게 한다. 이 경우 표시명은
검토된 역사 지리명만 사용하며 현대 행정 명칭이나 가공의 군·현 명칭을 노출하지
않는다.

## 행정체계별 표시

- `HAN_COMMANDERY`: `{군·국·윤} {현·후국}`
- `SAMHAN_POLITY`: `{마한·진한·변한} · {소국}`
- `KINGDOM`: `{국가} · {성·지역}`
- `TRIBAL_REGION`: `{집단} · {읍락·지역}`
- `DIRECT_TERRITORY`: `{상위 정치체} · {검토된 역사 지리명}`

낙랑·대방처럼 한나라가 설치한 군현은 위치가 중국 밖이어도 군현제로 표시한다.
마한·진한·변한, 고구려, 부여, 옥저, 예, 왜 등에는 가공의 군·현 접미를 붙이지
않는다.

## 경계 생성 파이프라인

1. 220년 역사 단위·부모 관계·치소와 외부 정치체 후보를 안정 ID로 정규화한다.
2. 검토된 역사 경계가 있으면 먼저 래스터에 고정한다.
3. 나머지 육지를 현대 하위 행정 폴리곤 조각으로 나눈다.
4. 폴리곤 안에 역사 중심점이 하나면 해당 프로빈스에 배정한다.
5. 중심점이 여러 개면 폴리곤 내부에서 지형 가중 분할을 수행한다.
6. 중심점이 없으면 같은 상위 권역의 인접 프로빈스와 병합한다.
7. 병합 결과가 권역별 목표 면적 상한을 넘으면 `DIRECT_TERRITORY`로 유지한다.
8. 산맥·강·분수령과 연결성을 기준으로 경계를 보정한다.
9. 섬과 고립 육지는 역사적 소속, 같은 상위 권역, 접근비용 순으로 귀속한다.
10. 모든 검증을 통과한 뒤 `owner`, 상위 권역 격자, 인접 그래프와 프로빈스 ID
    이미지를 함께 생성한다.

기존의 전역 무제한 다중출발 다익스트라는 단계 5와 8의 제한된 내부 분할에만
사용한다. 상위 권역이나 현대 경계 골격을 넘어 확장할 수 없다.

## 상위 권역과 런타임 호환

현재 `seatOwner`와 PNG의 `commandery` 필드는 범용 `parentRegion` 의미로
일반화한다. 바이너리 비트 배치는 기존 클라이언트와 호환되도록 유지할 수 있지만,
새 코드와 메타데이터에서는 역사 용어 `commandery`를 범용 의미로 사용하지 않는다.

기존 역사 도시 ID와 프로빈스 ID는 새 안정 ID 레지스트리에 연결한다. 새 외부
정치체와 직접영역 ID는 기존 ID 뒤에만 추가하며 재정렬하지 않는다. 활성 맵 전환은
새 버전 리소스, 서버 시드, 프로빈스 PNG, 웹 타일을 하나의 원자적 릴리스로 묶는다.

## 형태 품질 계약

빌드는 다음 조건을 모두 만족해야 한다.

- 바다·호수를 제외한 모든 육지 셀은 정확히 한 프로빈스에 속한다.
- 모든 역사 중심점은 자기 프로빈스 안에 있다.
- 프로빈스는 원칙적으로 하나의 4방향 연결 성분이다.
- 본토에서 떨어진 부속 섬은 명시적인 예외 목록으로만 허용한다.
- 폭 1~2셀의 긴 회랑과 단일 셀 목을 허용하지 않는다.
- 권역별 면적 중앙값, 가로세로비, 둘레 대비 면적, 경계 상자 충전율을 계측한다.
- 통계 임계값을 넘는 이상치는 검토 기록 없이는 빌드를 실패시킨다.
- 중심점이 조밀한 지역과 희박한 지역에는 서로 다른 권역별 면적 기준을 사용한다.
- 생성 결과는 입력 순서와 무관하게 결정적이며 동일 입력에서 동일 체크섬을 낸다.

화면용 경계는 논리 소유 격자에서 별도로 유도한다. 계단 현상을 줄이기 위한 윤곽
단순화와 완화는 프로빈스 소유 셀이나 hover 판정을 변경하지 않아야 한다.

## 오류 처리와 감사 정보

- 중복 중심점, 자기 권역 밖 중심점, 출처 없는 역사 경계는 즉시 실패한다.
- 현대 폴리곤이 겹치거나 빈틈을 만들면 국가·자료셋별 진단 보고서를 남긴다.
- 자동 병합·분할은 입력 조각, 선택된 중심점, 비용과 결과 ID를 감사 원장에 쓴다.
- 품질 예외는 프로빈스 ID, 사유, 승인 근거와 유효 버전을 명시해야 한다.
- 생성기는 기존 보호 오케스트레이터의 입력 역할·체크섬·산출 요약 계약에 새
  경계 입력과 품질 보고서를 포함한다.

## 검증

- 단위 테스트: 우선순위 합성, 병합, 분할, 섬 귀속, 안정 ID, 표시 템플릿.
- 속성 테스트: 전 육지 완전 피복, 중복 소유 금지, 연결성, 중심점 포함.
- 회귀 테스트: 기존 역사 단위·부모 관계·활성 220년 도시 ID 보존.
- 형태 테스트: 과대·장형·사각형·회랑·분리형 인공 사례가 실패하는지 확인.
- 산출물 테스트: `owner`, `parentRegion`, 인접 그래프, PNG가 서로 동일한 경계를
  표현하는지 역검증.
- 웹 테스트: 중국 군현과 외부 정치체 툴팁 형식, 모든 육지 hover, 경계 렌더링.
- 배포 테스트: 새 맵 버전 시드, 과거 맵 로딩, 서버 초기화 후 새 맵 활성화.

## 수용 기준

- 현재 `han` 화면이 새 전역 프로빈스 산출물을 사용한다.
- 중국 내부는 역사 군현 경계를 최우선으로 사용한다.
- 역사 경계가 없는 전역 육지는 현대 하위 행정 경계 골격과 지형 보정을 사용한다.
- 중국 외부에는 가공의 군·현 표기가 나타나지 않는다.
- 빈 육지, 투명 정치색, 비정상적으로 큰 장형 프로빈스, 분리된 본토 조각이 없다.
- 기존 220년 역사 데이터와 과거 월드 맵 버전은 손상되지 않는다.
- 생성 입력, 자동 판정, 품질 지표와 최종 산출물 체크섬을 재현할 수 있다.
