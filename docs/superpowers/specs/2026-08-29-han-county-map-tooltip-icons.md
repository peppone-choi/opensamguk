# 한나라 현 지도 툴팁·마커 설계

## 목표

한나라 지도의 모든 육지 현 폴리곤을 공백 없이 현재 세력으로 표시하고, 현 단위 hover 툴팁과 실제 캔버스에 사용되는 정식 위치 마커를 제공한다.

## 표시 계약

- hover 히트 단위는 도시 마커가 아니라 `owner` 격자의 현 폴리곤이다.
- 툴팁 첫 줄은 `【사예 | 경】 경조윤 장안현` 형식이다. 상위 행정구역은 데이터의 `군·국·윤` 접미를 그대로 쓴다.
- 둘째 줄에는 현재 소속 세력명을 표시한다. 중립은 기존 정책대로 세력명을 숨긴다.
- `사예·예주` 등 지역명은 legacy 도시 ID 표가 아니라 활성 `han.json` 메타데이터에서 가져온다. 현 이름은 `meta.seat`(군 치소)가 아니라 hover된 `han-tiles.cities[owner]`에서 가져온다.
- 바다·강 등 `owner == -1` 셀은 툴팁과 정치색을 표시하지 않는다.

## 소유권 바인딩

- runtime 도시를 격자에 투영해 직접 소유 현과 소속 군을 알아낸다.
- 현 안에 runtime 도시가 하나면 그 도시 세력을 쓴다. 같은 현에 여러 도시가 들어오면 현 중심과 가장 가까운 도시를 결정적으로 선택한다.
- runtime 도시가 없는 현은 같은 `seatOwner` 군 안의 가장 가까운 runtime 도시 세력을 상속한다. 이로써 부모 군에 플레이 도시가 있는 모든 육지 현은 색을 갖는다.
- 동거리면 runtime 도시 ID가 작은 쪽을 선택해 재현성을 보장한다.

## 마커

- 기존 `HanMapCanvas` 사각 성 임시 도형은 PNG 로딩 전·실패 시에만 fallback으로 남기고, 정상 경로에서는 표시하지 않는다.
- 실제 지도 마커는 일반 현, 군치, 수도 세 계층으로 구분한다. 소속 세력 깃발·상태·선택 표시는 기존 상호작용을 유지한다.
- 아이콘 원본·생성기·미리보기는 `opensamguk-images`가 정본이고, `opensamguk`에는 웹 배포용 export만 둔다.
- 아이콘 시안은 `sprite-gen` 단독 큐레이션 뷰에서 실제 크기와 확대본을 나란히 검수한다.

## 수용 기준

- 임의의 육지 셀 hover가 현·상위 군·지역을 반환한다.
- 로비와 인게임의 툴팁 문구가 같다.
- 소유 충돌이나 runtime 도시 미배치 때문에 육지 현이 투명해지지 않는다.
- 마커 클릭·터치·키보드 활성화는 기존 도시 ID를 그대로 전달한다.
- 새 아이콘은 투명 배경, 고정 anchor, 실제 마커 크기 판독성, export 드리프 검사를 통과한다.
