# 프로빈스 전선과 현치 함락 설계

상태: 2026-09-06 게임 규칙 사용자 승인. 후속 대화에서 장수 위치·커맨드 공통 기준·지속 명령·거리 기반 턴 비용까지 승인했다.
아래 내용은 목표 설계이며 현재 기능 설명이 아니다. 이동량·지형 계수·업무 결합 비용의 구체 수치는 밸런스 검증 후 확정한다.
`2026-09-02-administrative-spatial-hierarchy-design.md`의 소유권·명령 단위에 관해서 이 문서가 우선한다.
기하·안정 ID·행정 소속 관계와 별도 수역 설계는 유지한다.

## 1. 단위와 정본

| 대상 | 단위 | 의미 |
| --- | --- | --- |
| 부대 위치·육상 이동 | 공간 프로빈스 | 부대가 실제로 있는 한 조각과 그 공유 변 이웃 |
| 군사 점유·전선·보급 | 공간 프로빈스 | 현재 점유 세력과 실제 통행 가능 간선 |
| 내정·징세·인사 | 현급 관할 | 현치에 연결된 행정권과 관할 |
| 군국 지배 표시 | 소속 현 집계 | 대표 통제 표시이며 하위 점유를 덮어쓰지 않음 |

`provinceRecordId: String`은 영속 위치·점유의 키다. 배열 인덱스, 런타임 `cityId`, 현의 `jurisdictionId`를 대신 쓰지 않는다.
프로빈스의 행정 소속은 정적 관계이고 군사 점유는 동적 상태다. 현의 행정권과 소속 프로빈스의 점유 세력은 달라도 된다.
같은 현 안에서 점유 세력이 갈리면 실제 분쟁·잔존 거점으로 표시한다. 시나리오 시작 당시의 색이 남아 있는 상태와 구별한다.

## 2. 이동과 전선

- 육상 부대는 현재 위치 프로빈스 하나를 가진다. 같은 현 내부에서도 프로빈스 경계를 순서대로 통과하지만 경계 통과 한 번이 한 턴은 아니다.
- 각 육상 경로 단계는 현재 위치와 **변을 공유하는** 프로빈스로만 이어진다. 관계는 무방향이며 부대의 방위를 요구하지 않는다.
  한 턴에 진행할 수 있는 경로 길이는 프로빈스 개수가 아니라 거리·지형에 따른 이동 비용과 턴당 이동량으로 정한다.
- 모서리 접촉, 거리상 근접, 같은 현·군국 소속, 그 현의 다른 조각이 접한다는 사실은 이동 근거가 아니다.
- 강행 등 다단계 이동도 같은 그래프의 경유지를 기록하고 순서대로 판정한다. 지도 미리보기·API 사전검사·실제 실행은 같은 경로 규칙을 사용한다.
- 인접 판정과 턴 비용을 분리한다. 동일한 물리 경로의 프로빈스를 분할해도 거리·지형·방어 상태가 같으면 비용과 소요 턴은 달라지지 않아야 한다.
- 강·수역 횡단은 기존 승인된 타입 간선과 통행 조건을 추가로 만족해야 한다. 단순 기하 접촉이 도하·해로 허가는 아니다.
- 서로 다른 세력이 점유한 프로빈스의 공유 경계가 군사 점유 경계다. 외교상 적대 여부는 별도로 표시하며, 같은 현 안에도 전선이 생길 수 있다.
- 현치가 없는 프로빈스도 위치·이동·점령 대상이다. 목적지에 `cityId`가 없다는 이유로 건너뛰는 가상 간선을 만들지 않는다.

이동과 점령은 별도 판정이다. 아군 영역 이동이나 군사력이 없는 장수의 통과로 소유권을 바꾸지 않는다.
적 점유지의 점령은 기존 적대·공격 가능 조건을 만족한 부대의 군사 행동으로 처리한다. 방어 전력이 있으면 전투 결과로,
없으면 무저항 점령 결과로 해당 프로빈스를 변경한다. 이동 선택만으로 자동 선전포고하지 않는다.

## 3. 현치 함락

현치 함락 확정 이벤트는 다음을 같은 턴 변경 묶음으로 처리한다.

1. 현치 프로빈스의 점유와 해당 현의 행정권을 승리 세력으로 변경한다.
2. 같은 현의 다른 프로빈스 중 패배 세력이 점유하고, 방어 전력과 진행 중인 저항 전투가 없는 곳을 함께 인계한다.
3. 적 부대·수비대가 방어 중인 프로빈스는 기존 점유를 유지한다. 방어 여부는 현 전체가 아니라 해당 프로빈스에서 판정한다.
4. 제3세력 점유지는 그곳이 비어 있어도 인계 대상이 아니다. 이미 승리 세력이 가진 곳도 변경하지 않는다.
5. 군국 대표 통제와 현 분쟁 표시는 결과를 집계해 갱신한다. 군치 함락은 그 군치가 있는 현에만 이 규칙을 적용한다.

‘무주둔·무저항’은 점령 확정 시점에 판정한다. 병력이 없는 장수의 존재만으로 현 전체 인계를 막지 않는다.
패배 세력은 이벤트 직전 현치 프로빈스의 점유 세력이다. 기존 현 행정권과 다르더라도 이 점유 세력만 인계 대상의 소유자로 비교한다.
방어 전력은 해당 프로빈스에 실제 위치한, 병력이 0보다 많고 기존 전투 참가 조건상 점령자에 대항해 방어할 수 있는 부대·수비대다.
소유 세력의 병력뿐 아니라 기존 참전 규칙에 따라 방어하는 동맹·제3세력 병력도 포함한다. 다른 프로빈스의 수비대는 포함하지 않는다.
이 방어 전력이 있거나 해당 프로빈스에서 점령자에 대한 저항 전투가 진행 중이면 자동 인계하지 않는다.
전투로 패배한 현치 방어군의 전투 전 상태를 사용해 인계를 되돌려서는 안 된다.

현의 분리된 조각에도 위 인계 조건을 적용하지만 이는 행정적 항복이지 부대 이동·보급 연결이 아니다.
인계받은 고립지는 실제 경로가 없으면 보급되지 않는다.
보존된 적 점유지에서 나중에 수비대가 떠나더라도 현치 소유자를 매 턴 복사해 점유를 바꾸지 않는다.
후속 점령·항복·중립화 이벤트가 있어야 바뀐다. 재점령에도 같은 규칙을 적용한다.

중립화는 현치 함락에 따른 항복 인계와 다른 이벤트다. 일반 프로빈스 중립화는 대상 프로빈스 하나만 변경한다.
현치 프로빈스를 중립화하면 그 프로빈스와 현 행정권만 중립으로 바꾸고 다른 프로빈스는 유지한다.
현치의 기존 점유가 중립일 때 무저항 점령하더라도 다른 중립 프로빈스를 패배 세력의 항복 영역으로 간주하지 않는다.
세력 멸망 등 여러 대상을 바꾸는 기존 이벤트는 대상 집합을 명시적으로 전달해야 하며 현치 중립화로부터 범위를 추론하지 않는다.

예: 한 현의 A(현치), B(패배 세력의 빈 지역), C(패배 세력 수비대), D(제3세력)를 생각하면,
A 함락 직후 A·B만 승리 세력으로 바뀐다. C·D는 남고 그 사이 프로빈스 경계가 실제 점유 경계가 된다.

## 4. 저장·실행 설계

- 월드별 프로빈스 점유 상태를 영속 저장한다. 키는 월드와 안정 프로빈스 ID, 값은 현재 점유 세력이다. 중립은 명시적 값이며 누락과 같지 않다.
- 현 행정권과 부대의 실제 전략 위치도 영속 상태다. 기존 `General.cityId`는 행정·호환 문맥과 분리하고 비현치 위치를 현치로 반올림하지 않는다.
- `InMemoryTurnWorld`가 실행 정본이며 변경은 `ChangeRecorder`의 델타를 통해 `JdbcFlushExecutor`로만 저장한다.
  점유 변경, 현 행정권, 전투 후 위치, 로그는 동일한 원자적 턴 반영 경계를 사용한다.
- 현치 함락의 자동 인계는 점령 이벤트 실행 시 한 번 계산한다. API 조회나 월별 보급 계산 중 소유권을 생성·추측하지 않는다.
- 지도 API·명령 검사·전선·보급은 동일한 월드의 점유 상태를 사용한다. API는 완료된 턴의 저장 상태를 읽고 엔진은 실행 중 메모리 상태를 읽는다.
- `MapAdministrativeOwnership`의 시나리오 기반 비현치 색 고정과 `HanSpatialSupplyProvider`의 현치 전용 덮어쓰기를 함께 대체한다.
- 현 분쟁 여부는 현 행정권과 다른 세력이 점유한 소속 프로빈스의 존재로 산출한다. 군국 대표색을 아래로 역전파하지 않는다.
- 대상을 안정 ID로 정렬하고 기존 턴 실행 순서를 유지한다. 같은 입력·상태·실행 순서는 같은 인계·전투·로그를 만든다.

## 5. 전환과 호환성

1. 신규 월드는 시나리오 직접 assignment로 **모든** 플레이 가능 프로빈스를 한 번 시드한다. 정상 플레이 중 시나리오 값을 덮어씌우지 않는다.
2. 기존 월드의 비현치 과거 전투는 현재 city 소유권만으로 복원할 수 없다. 기존 투영 결과를 명시적 전환 스냅샷으로 보존하고,
   실제 위치는 검증된 기존 도시→현치 프로빈스 매핑으로 시작한다. 과거 현치 함락을 추측해 소급 인계하지 않는다.
3. 위치를 매핑할 수 없는 기존 도시·부대는 전환 사전검사를 실패시킨다. 임의 이웃이나 같은 군국 현치로 옮기지 않는다.
4. 새 상태의 시드·델타·flush·재시작, 비현치 명령 대상, 방어 전력 위치, API·보급 소비가 모두 연결된 뒤 새 규칙을 활성화한다.
   지속 점유가 없는 현재 전환기의 보급 보호 정책을 앞서 제거하지 않는다.
5. 기존 `han.json`과 동결 회귀 입력을 변경하지 않는다. 현재 목표는 `han-world-v3`이며 기존 월드 전환은 별도 검증·운영 승인 후 적용한다.

## 6. 수용 기준

- 일반 육상 인접 후보는 변 접촉일 때만 인정하고, 모서리 접촉·비접촉은 불가하다. 이 기하 인접 관계는 양방향에서 같다.
  실제 이동 허가는 지형·수역·외교·부대 상태 조건까지 만족해야 하며 타입 간선의 방향 제약을 없애지 않는다.
- A와 C가 같은 현이어도 현재 A가 B와 접하지 않으면 C–B 접촉을 이용해 A→B로 이동할 수 없다.
- 현 내부에서도 실제 경유 프로빈스 순서가 보존되고, 현치 없는 프로빈스에서 명령을 실행할 수 있다. 경로 단계 수를 소요 턴 수로 사용하지 않는다.
- 같은 물리 경로를 프로빈스 둘 또는 여러 개로 나눈 입력에서 거리·지형·방어 상태가 같다면 이동 비용과 도착 턴이 같다.
- 충분한 이동량이 있으면 가까운 여러 프로빈스를 같은 턴에 통과한다. 중간 방어군·통행 불가 경계는 생략하지 않는다.
- 군사 행동 조건을 만족한 비현치 점령이 저장되고 지도·전선·보급에 반영된다. 평범한 아군 이동은 점유를 바꾸지 않는다.
- 현치 함락 시 빈 패배 세력 영역만 인계되고, 방어 중인 영역·제3세력 영역·다른 현은 유지된다.
- 인계된 고립지에는 가상 보급 간선이 생기지 않는다. 남은 적 점유지의 후속 철수만으로 자동 인계되지 않는다.
- 현치 재점령·중립화와 일반 프로빈스 중립화가 서로 다른 범위를 가지며 군국 전체에 점유를 복사하지 않는다.
- API 사전검사와 실제 실행이 위치·경로·거절 사유에서 일치한다. 같은 턴 완료 후 지도·보급의 점유 배열도 일치한다.
- flush 실패는 부분 인계를 노출하지 않으며 재시작 후 위치·점유·현 행정권이 같고 동일 이벤트가 중복 적용되지 않는다.
- 누락된 프로빈스 점유와 명시적 중립을 구별하고, 미매핑 기존 위치가 있는 월드는 활성화하지 않는다.

## 7. 현재 구현에서 확인한 간극

기준 커밋: `b961866a3de99de3a7d60db5180db5e68bbf2ba0`.

- `ConquerCity`는 `City.nationId`를 변경한다. `MapAdministrativeOwnership.project`와 `HanSpatialSupplyProvider.network`는
  그 결과를 현치 프로빈스에만 적용하며 나머지는 초기 assignment를 사용한다. 비현치 점유 변경의 지속 write 경로가 없다.
- `General`·`TurnGeneral`의 위치와 `CheIdong`의 일반 이동은 현재 `cityId` 중심이다. ‘프로빈스 이동’으로 이름만 바꿔 해결할 수 없다.
- 최신 V3 이동 간선 1,603개를 실제 owner raster 공유 변과 독립 대조했을 때 비접촉 간선은 0개였다.
  구버전 `han.json`에서 찾은 비접촉 간선 수치를 현재 V3 오류 근거로 사용하지 않는다.
- 프로빈스 1,524개, 관할 1,020개 중 다중 프로빈스 관할은 139개다. 런타임 도시는 781개이고
  프로빈스를 통해 대응되는 관할은 773개다. 미대응 관할 247개와 프로빈스 매핑 없는 런타임 도시 8개의 전환을 별도로 검증해야 한다.

## 8. 장수 위치와 명령 계약

모든 장수의 실제 위치는 프로빈스다. 소속 국가·관직·임지와 실제 위치를 분리한다.
표시명은 `현명 · 현치` 또는 `현명 · 구역 03` 형식으로 하고, 고유지명 부여는 후속 작업으로 미룬다.
구역번호는 고정하며 내부 안정 ID와 별개다. 이름을 바꿔도 위치·경로·예약 명령의 대상은 바뀌지 않는다.
위치 선택 시 지도에서 현재 프로빈스와 장수 표식을 강조하고, 현 행정권과 현지 점유가 다르면 구분해서 표시한다.

모든 명령은 실행 주체·실행 위치 조건·대상·실제 영향 범위·비용·실행 시점을 명시한다.
장수의 현장 행동과 국가·직책의 지휘 권한을 구분한다.

| 계열 | 공간·권한 기준 |
| --- | --- |
| 이동·강행·귀환·접경귀환 | 실제 경로와 이동 비용 적용. 귀환도 순간이동하지 않음 |
| 출병 | 현재 위치에서 이어지는 실제 경로상 공격. 점령 확정 후 해당 프로빈스 진입 |
| 집합·부대 편성·탈퇴 지시 | 편성·집결 목표 변경과 실제 장수 이동을 분리 |
| 훈련·사기·전투태세·숙련전환 | 현재 위치의 자기 병력에 적용하고 병력·물자 조건 검사 |
| 농지개간·상업투자·치안·정착장려 | 아군 현치에서 해당 현의 행정 업무 수행 |
| 성벽보수·수비강화 | 해당 시설이 있는 프로빈스에서 수행. 현 전체에 성벽 효과를 복사하지 않음 |
| 징병·모병·물자조달·군량매매·장비매매 | 우선 아군 현치에서 해당 현의 인구·재고·시설 사용 |
| 첩보·화계·파괴·선동·탈취 | 프로빈스·시설·현 중 대상을 명시하고 접근 범위와 효과 범위 구분 |
| 단련·요양·견문·인재탐색 | 장수 또는 현재 지역을 대상으로 명령별 현지 조건 검사 |
| 등용·임관·하야·발령·건국·선양 | 장수·직책·국가를 대상으로 하며 소속 변경이 위치 변경을 암시하지 않음 |
| 포상·국가 연구·천도·선전포고·종전 | 국가·직책 권한 사용. 군주의 현장 도착을 기본 조건으로 요구하지 않음 |
| 원조·인구이동·초토화·수몰 | 출발지·목적지 또는 영향 지역 명시. 수송·통행·지형 조건 유지 |

현 행정권만으로 적 점유 구역의 인구·물자를 이용할 수 없다. 현 단위 자원 이용은 실제 통제·보급으로 제한한다.
일괄 선택은 개별 대상 명령을 묶는 편의 기능이지 권한·비용·공간 조건을 생략하는 광역 효과가 아니다.
국가 명령도 개인 턴·국가 명령 예산·즉시 설정 중 어느 실행 시점을 쓰는지 명시한다.
즉시 설정으로 이동·전투·생산을 무료 실행할 수 없으며, 이번 설계가 모든 국가 명령을 즉시 실행으로 바꾸는 것은 아니다.

예약은 안정 ID 대상을 보존하고 실행 직전에 위치·소유·외교·자원 조건을 재검사한다.
조건 불충족이면 해당 턴은 휴식 처리하고 행동 비용을 차감하지 않으며 이유를 남긴다.
이미 수행한 이동·전투·공작의 비용은 이후 실패했다는 이유로 환불하지 않는다.
실행 도중 중단된 복합 명령은 완료한 경로·비용·효과를 보존하고 미수행 부분은 실행하지 않는다.
화면의 불가 사유·API 사전검사·엔진 거절 사유가 같은 계약을 사용한다.

## 9. 목표 중심 지속 명령

프로빈스는 내부 판정 단위이며 기본 사용자 조작 단위가 아니다. 기본 입력은 장수·부대·업무 묶음의 목표와 방침이다.
직접 프로빈스를 지정하는 명령도 전술 개입용으로 유지하며, 같은 권한·이동·비용 규칙을 적용한다.

| 지속 명령 | 자동 수행 범위 |
| --- | --- |
| 이 현을 공격하라 | 지정 현까지 이동, 승인된 적의 경로상 프로빈스 공격, 현치 공성 |
| 이 현을 방어하라 | 지정 영역과 방침 안에서 방어 배치·대응 |
| 이 현에서 내정하라 | 현치로 이동한 뒤 선택한 업무를 반복 |
| 병력을 정비하라 | 모집 가능한 거점까지 이동한 뒤 지정 병력·훈련 목표까지 정비 |

지속 명령은 최종 목표, 허용 행동·적대 대상, 예산, 병력 하한, 중단 조건을 보존한다.
통상 실행은 계속하되 제3국 공격이 필요하거나 보급이 끊기거나 설정한 병력 하한에 도달하면 중단·보고한다.
현재 지시의 허용 범위 안에서만 경로를 다시 구할 수 있고 승인되지 않은 대상·지역·전쟁으로 목표를 바꾸지 않는다.
목표 현을 함락한 뒤 다음 현으로 침공하거나, 예산을 초과해 내정을 이어가지 않는다.
수동 개입은 기존 지속 명령을 명시적으로 일시정지 또는 교체해 같은 턴에 두 명령이 중복 실행되지 않도록 한다.
표시는 `허현 공략 중`, `병력 정비 중`, `판단 필요 · 보급로 단절`처럼 목표·진행·개입 필요 여부 중심으로 한다.

## 10. 턴 비용과 플레이 템포

앞선 대화의 ‘한 프로빈스 이동 또는 점령마다 한 턴’ 규칙은 폐기한다.
이동·진군은 실제 경로의 거리·지형 비용을 턴당 이동량에서 차감한다. 단계별로 비용을 턴 단위 올림하지 않는다.
원시 프로빈스 개수나 경계 개수를 비용으로 삼지 않으며 분할 전후 동일 경로의 비용 불변을 검증한다.
큰 프로빈스의 긴 이동도 진행할 수 있도록 턴을 넘는 이동 진행을 보존해야 한다. 한 경로 단계 비용이 턴당 이동량보다 크다고 영구 정지해서는 안 된다.
이동 진행은 별도 경로 상태이며 해당 프로빈스 진입·점령 완료를 선행 선언하지 않는다.

출병도 충분한 이동량이 있으면 가까운 무저항 프로빈스를 순서대로 점령·통과할 수 있다.
방어군·성을 만나면 그 지점의 전투를 판정하고, 전투 후에는 그 턴에 다른 지점까지 연속 공격·진군하지 않는다.
점령 실패·공성 미완료이면 목표 점유는 유지하고 공격 부대는 진입하지 않는다. 전멸·강제퇴각은 해당 전투 결과를 적용한다.
예를 들어 `현재지 → 빈 외곽 → 적 현치`가 이동량 안이면 한 출병 턴에 외곽을 거쳐 현치를 공격할 수 있지만,
외곽에 방어군이 있으면 현치로 건너뛰지 않고 외곽 전투에서 그 턴의 공격 진행을 끝낸다.

가까운 현내 이동은 현치 업무와 같은 턴에 결합할 수 있다. 실제 현치 도착과 업무 비용 조건을 만족해야 하며 원격 내정이 아니다.
멀리 떨어진 장수의 이동 시간은 생략하지 않는다. 한 턴에 이동과 업무를 각각 무제한 수행하는 것도 허용하지 않는다.

시뮬레이션으로 확정할 수치 항목은 턴당 이동량, 지형별 비용, 강행의 추가 이동량·부담, 이동 후 전투·업무 결합 한도다.
같은 물리 거리의 분할 불변, 가까운 외곽→현치의 한 턴 행동, 먼 원정의 거리 비용 보존을 함께 검증하고 활성화 전에 수치를 고정한다.
이번 설계 승인만으로 현재 이동 속도나 명령 비용을 임의 숫자로 변경하지 않는다.
