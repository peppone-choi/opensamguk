# 후한 지도 전면 재검토·재구축 계획 (2026-09-07)

> 지시: 「지도를 다 재검토해」 / 「모든 군국현을 다 확인해야지」 / 「나무위키의 데이터와 지금
> 가지고 있는 데이터로 맵을 새로 만들어. 프로빈스를 다시 구워도 돼」 / 격자는 픽셀이 아니라
> 실제 게임 같은 아이소메트릭 격자.

## 0. 왜 지금인가 — 라이브 게임이 이것 때문에 깨지고 있다

프로덕션 `pep`(scenario_1020)에서 공융이 개시 몇 달 만에 사라진다. 경로는 전부 실측됐다.

1. 北海國 16城 중 **14城이 개시 시점부터 보급 절단**(도시 인접 그래프·spatial 프로빈스 망 양쪽 모두).
2. 절단 城은 매턴 10% 쇠퇴 → 민심 30 미만 → 중립화.
3. 중립화된 城의 관직자는 `officer_level=1` 로 강등되는데 이 강등에 `officer_level<12` 가드가 없다
   (`logic/.../UpdateCitySupply.kt:277`, 주석이 UNCONDITIONAL 이라고 명시).
4. 군주가 강등되면 군주 없는 국가가 되고, 그것이 PR #660 이 「유래 UNKNOWN」이라 적은 그 상태다.

근본 원인은 **좌표 결함**이다(§2.1).

## 1. 확정된 실측

### 1.1 정본 대조 (續漢書 郡國志 = `data/curated/han/administrative-units.json`)

| | 값 |
|---|---|
| 정본 | 105郡國 / 1,180縣 |
| 지도 `han-world-v3.json` | 100郡國 / 781城 |
| 郡 범위 안에서 정본에 있는데 지도에 없는 縣 | **400** |
| 지도에 있는데 그 郡 정본에 없는 城 | **1** (上郡 龜茲 — 龜茲屬國 표기 차이) |
| 결손 0인 郡國 | 12개뿐 |
| 지도에 아예 없는 郡國 | **5** — 西河郡(13縣)·朔方郡(6)·定襄郡(5)·張掖屬國(5)·廣漢屬國(3) |

즉 지도는 정본의 **깨끗한 부분집합**이다(오배치 1건). 문제는 커버리지다.

대조 방법 주의: 이름만으로 맞추면 동명이지가 겹쳐 788/1180 이 나온다(정본 縣이 남의 郡 城에
붙는다). **반드시 (郡, 縣) 쌍**으로 맞춰야 400 이라는 정직한 수가 나온다.

繁簡 처리: 타일은 简体(`剧县`), 정본은 繁體(`劇`)다. CHGIS 원본·코퍼스가 로컬에 없으므로
`physicalPlaceRef` **id 조인**으로 (繁,簡) 이름쌍 781건을 얻어 글자표(598자)를 만들었다 —
이름 매칭이 아니라 id 조인이라 순환이 아니다.

### 1.2 좌표 보유 현황

| | 縣 수 |
|---|---|
| 지도(781城)에 배치됨 | 788 pair-match 전 / 781 실제 |
| 타일 원장에만 좌표 있음 | 24 |
| **좌표가 어디에도 없음** | **368** |

368縣은 나무위키 현대 비정 위치 → 지오코딩으로만 좌표를 얻을 수 있다. 교주·유주·병주·청주는
이미 수확했다(§3).

## 2. 결함 목록

### 2.1 [치명] 극현·동안평현 좌표가 약 29열 서쪽으로 밀렸다

산둥 권역 132개 타일로 `col ~ lon` 회귀(잔차 sd 5.02열):

| 縣 | 잔차 |
|---|---|
| 극현(劇縣) | **−29.7열 (−5.9σ)** |
| 동안평현(東安平縣) | **−29.0열 (−5.8σ)** |
| 3위 주허현 | −5.9열 (−1.2σ) |

극현은 경도 118.775인데 격자 이웃이 경도 116.3~117.7이다. 있어야 할 자리는 col 486~492
(주허 118.783→486, 익도 118.736→488, 수광 118.863→492). 나무위키도 극현=산둥성 웨이팡시
**창러현**으로, 평수·영릉과 같은 곳이라 지도와 어긋난다.

두 縣이 **같은 크기로 함께** 밀렸다 = 한 쌍이 같이 잘못 심겼다.

### 2.2 [치명] 개시 시점 보급 도달성 게이트가 없다

CI 의 유일한 보급 게이트 `audit_han_supply_disagreements.py` 는 **두 모델의 불일치**만 본다.
둘 다 「끊겼다」에 동의하면 `BOTH_UNSUPPLIED` 로 무료 통과다. 그래서 시나리오 1020 이 41城
절단 상태로 초록이다. 「수도에서 도달 가능한가」라는 **절대 축**이 없다.

시나리오 1020 개시 절단 城 (양 모델 합의):

| 세력 | 절단 / 소유 |
|---|---|
| **공융** | **14 / 16 (87%)** |
| 동탁 | 10 / 59 |
| 유대 | 5 / 12 |
| 유우 | 4 / 21 |
| 그 외 6세력 | 각 1~2 |

### 2.3 [높음] 군주 강등에 가드가 없다

`UpdateCitySupply` 4a 의 관직 초기화가 무조건이다. PHP 동결 기준선에 충실한 포팅이지만,
군주가 강등되면 국가가 군주를 잃는다. **결정: 가드를 넣는다**(사용자 확정).

### 2.4 [중간] 7城의 표시명이 縣이 아니라 郡 이름이다

낙랑군·현도군·요동군·요동속국·구진군·교지군·일남군 — `nameCh` 는 실제 治所(朝鮮·高句驪·
襄平·昌遼·胥浦·龍編·西卷)로 올바른데 한글 표시명만 郡 이름이다. **가짜 縣이 아니라 표시명
오류다**(초기 진단을 정정한다).

### 2.5 [중간] `meta.nameCh` 표기가 繁簡 혼재다

繁體여야 할 자리에 简体가 섞여 있다(`临`이 城마다 다르다 등, 최소 32자 충돌).

## 4. 실행 순서

1. **긴급 지혈** — 극현·동안평현 좌표 교정 + 개시 도달성 게이트(적색 프로브) + 군주 강등 가드.
2. **수확** — 나머지 10州 나무위키 縣 목록·현대 위치.
3. **지오코딩** — 368縣 현대 지명 → lon/lat.
4. **재구축** — 1,180縣 원장으로 타일·프로빈스 재생성.
5. **아이소메트릭 격자** — 픽셀 아트가 아닌 실제 게임 타일 격자(ADR-LITE-049 개정 필요).
6. **시나리오 재검증** — 15개 시나리오 전부 개시 도달성 통과.

## 5. 열려 있는 위험

- `han-tiles.json` 생성 입력(`terrain-grid`·`han-places`·`readings`·`junguozhi`)이 gitignored 이고
  **로컬에 없다**. 재생성 경로가 막혀 있다(이슈 #536). 좌표 교정은 adjudication 장부로 가야 한다.
- ADR-LITE-049 는 「롤러코스터 타이쿤풍 픽셀 UI」를 폐기했다. 이번 지시는 픽셀 아트가 아니라
  아이소메트릭 격자라 취지가 다르지만, ADR 개정으로 명시해야 한다.
- 동명이지(僑置)를 이름으로 병합하면 郡이 조용히 사라진다. 모든 대조는 (郡, 縣) 쌍으로.
