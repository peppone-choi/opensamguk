# Private Message Recipient Selection Implementation Plan

**Goal:** 개인 서신을 현재 장수의 자기 메일함으로 보내지 않고, 연락처에서 명시적으로 검색·선택한 실제 장수에게만 발송한다.

## 계약

- 개인함 탭은 읽기 범위일 뿐 발송 대상이 아니다.
- 개인 발송은 연락처의 구체적인 장수 ID와 이름을 선택해야 한다.
- 수신자 미선택, 자기 자신, 존재하지 않는 장수는 화면과 엔진에서 모두 거부한다.
- 공개(9999), 국가/외교(9000+국가 ID) 주소는 개인 수신자 상태와 분리한다.
- 성공 결과와 저장 메시지에는 엔진이 확정한 수신자 ID·이름을 남겨 UI 확인 이름과 대조할 수 있게 한다.

## 구현 순서

1. `MailboxPage.command.test.tsx`에 검색, 명시 선택, 미선택/자기 자신 차단, 발송 전후 이름 확인 회귀 테스트를 먼저 추가한다.
2. `MessageHandlerTest.kt`와 `CommandWireMapperTest.kt`에 자기 자신/없는 장수/누락 mailbox 거부 및 저장 대상 ID·이름 테스트를 먼저 추가한다.
3. 메일함 발송 폼을 범위별 대상 선택기로 분리하고 개인 범위에는 검색 가능한 연락처 선택 UI를 구현한다.
4. wire mapper가 누락 mailbox를 0으로 fail-closed 처리하고, 엔진이 자기 자신과 유효하지 않은 개인 수신자를 부수 효과 전에 거부하도록 구현한다.
5. `SendMessageResult`에 확정 수신자 ID·이름을 포함하고 성공 UI에 표시한다.
6. 관련 단위 테스트, 타입 검사, 전체 JVM 테스트, 생산 빌드와 명령 결과 lifecycle 테스트를 실행한다.
7. 작은 PR로 리뷰·CI·병합·배포·운영 브라우저 스모크를 마친 뒤 report를 기록한다.
