> 작성일: 2026-09-17
> 상태: 현행 포트폴리오. [2026-08-27 공개 알파 포트폴리오 계획](./2026-08-27-public-alpha-roadmap-and-issue-plan.md)과 [명령 기반 계획](./2026-08-27-command-foundation.md)을 대체한다.
> 설계: [장수·휘하 캠페인 재설계](../specs/2026-09-17-general-and-retinue-campaign-redesign.md) · 결정: `.ai/decisions.md` ADR-LITE-057 · 단계: [로드맵](../../design/roadmap.md)

## 1. 목표

삼모 명령 체계를 장수·휘하 캠페인으로 교체하는 작업을 로드맵 0–10단계에 맞춰 이슈 단위로 배치한다. 공개 알파는 1·2·3층을 모두 완성한 뒤 연다(재설계 §15). GitHub 이슈와 Jira 티켓은 같은 항목의 미러다(제목 `[OPENSAM-###]`, 라벨 `jira-mirror`). 진실 순서는 코드 > PR > GitHub > Jira 다.

## 2. 전역 제약

- 게임 수치는 게이트 임계값이 아니다. 실측 기준선과 사용자가 승인한 목표 템포 표(S2)로만 정한다.
- 기존 삼모 명령과 동결 골든은 회귀 기준선이다. 새 입력 체계가 활성화되기 전까지 라이브 코드를 지우지 않는다.
- 결정론·단일 쓰기 경로(ADR-LITE-042)를 지킨다.
- 도움말·튜토리얼은 각 입력의 완료 조건이다(로드맵 입력 완결 규칙).
- 라이브 서버 pep 은 3단계 통과 직후 새 규칙 시험 서버로 전환한다(재설계 §15.2).
- 이슈 선택은 로드맵 「다음 구현 이슈 선택 규칙」을 따른다: 앞선 단계 → critical-path → 긴급도 → 중요도.
