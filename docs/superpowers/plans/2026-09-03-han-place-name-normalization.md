# Han 지명 정규화 계획

## 목표

CHGIS의 부수 풀이·이체자 메모가 제품 현명으로 노출된 5건을 안정 물리 ID로 정규화하고, 새 오염 표기가 재유입되면 테스트가 실패하게 한다. 기하·관할·소유권·시나리오는 변경하지 않는다.

## 근거가 확정된 정규화

- `82175`: `[阝焉]县` → `鄢县`, `언현`
- `85202`: `灵县（零县）` → `灵县`, `영현`
- `85376`: `[巾弓玄]（忄弓玄，扌弓玄）侯国` → `㡉侯国`, `견후국`
- `85377`: `[巾弓玄]县` → `㡉县`, `견현`
- `85448`: `曲成（城）县` → `曲成县`, `곡성현`

`後漢書 郡國志`의 東萊郡 본문·교감은 `曲成`과 巾변 `㡉`을 확인한다. 永昌郡 `哀牢縣`과 이민족 권역 `哀牢`는 동음이지만 서로 다른 안정 ID·계층이므로 이 PR에서 합치거나 대체하지 않는다.

## 구현

1. 정규화 원장은 안정 물리 ID, 기대 원문, 정규 한자, 한글 표시명을 모두 고정한다.
2. 원문이 기대와 다르면 조용히 치환하지 않고 실패한다.
3. 정상 풀 생성과 현재 추적 정본에 같은 함수를 적용한다.
4. `cities`, `provinceRecords`, `jurisdictionRecords`, `legacyGameplay.cities`의 동일 ID 표기가 일치하는지 검증한다.
5. 괄호·대괄호·IDS 부수 메모가 현급 표시명에 남으면 계약 검사를 실패시킨다.
6. 780개 route-node 승인 원장은 현재 774개 제품 입력을 거짓으로 가리키지 않고, 실제 재현 가능한 `han-780-v1` 동결 스냅샷을 입력으로 고정한다.
7. 이름을 키로 쓰는 기존 런타임 연결 그래프에서는 동명 충돌을 피하도록 `청하국 영`, `동래군 곡성`으로 한정하고, 지도 현 레이어의 정식 표시는 `영현`, `곡성현`으로 유지한다.

## 검증

- 집중 Python 테스트 및 전체 `tools/map/tests`.
- `han-tiles.json` 계층·프로빈스·인접·면적 계약.
- 15개 시나리오 소유권 감사와 렌더 산출.
- JVM 전체 테스트, web 타입 검사·전체 테스트·생산 빌드.
- 운영 브라우저에서 정규화된 현명을 확인한다.
