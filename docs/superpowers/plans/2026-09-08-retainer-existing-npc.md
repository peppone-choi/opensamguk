# 기존 NPC 가신 구현 계획

1. 이름 생성 차단 테스트를 적색으로 확인하고, 기존 섭외 회귀를 승인된 NPC 대상 계약으로 옮긴다. 다른 부곡/정산 기대값은 보존한다.
2. 순수 후보 규칙, 와이어 선택/추첨 입력, 엔진 재검증과 seed, DB 단일 주인 제약을 구현한다.
3. read 후보/정체성 DTO, 빙의 후보와 daemon 거부, 선택 UI와 실제 초상을 연결한다.
4. 정체성/결정성/동일 틱 경합/사망/이전 행/DB/API/UI 회귀를 실행한다.
5. 사용자 도움말과 증거를 정리하고 독립 검토 후 통합 담당에게 넘긴다. 작업자는 commit/push/merge하지 않는다.
