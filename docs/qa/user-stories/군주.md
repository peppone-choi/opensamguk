## 역할 정의

- 군주는 **세력의 정점에 선 주공**이다(휘하 재설계 spec §2.2). 서버 판정은 세력 안에서 `officerLevel == 12`이고 `meta.lord == true`인 장수 한 명이다(`logic/src/main/kotlin/opensamguk/logic/domestic/DomesticRules.kt` 260–264행). 화면은 `front-info`의 `general.officerLevel === 12`로 군주를 구분한다(`web/game/app/game/(campaign)/court/diplomacy/page.tsx`).
- 군주도 장수다. 명령 목록 12순의 장수 행동(견문·이동 등)은 [1차부하.md](1차부하.md)의 `US-SUB1-02`·`US-SUB1-03`과 같은 절차로 확인한다. 이 파일은 군주만 하는 **조정 결정**과 군주가 시작하는 교차 역할 흐름을 다룬다.
- 조정 결정은 명령 목록 12순을 쓰지 않는다. 접수하면 군주 장수의 `meta.queuedCourt`에 한 건 대기하고, **군주의 다음 개인 턴**에 규칙을 다시 확인한 뒤 실행한다(`app/game-engine/.../campaign/CourtHandler.kt` 193–205·228–238·292–313행). 대기 중 두 번째 조정 결정은 `ALREADY_QUEUED`로 거절된다(같은 파일 199행).
