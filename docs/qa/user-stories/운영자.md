## 역할 정의

- 인증 역할은 **USER와 ADMIN 둘뿐**이다. 권한 이름은 `ROLE_${user.role}`이다(`app/gateway-api/.../security/CustomUserDetails.kt` 21행). 옛 등급 5/6은 ADMIN 하나로 줄였다(`AdminMemberService.kt` 37행).
- ADMIN은 부팅 때 `AdminSeeder`가 환경변수 계정으로 만드는 경로 하나뿐이다(`app/gateway-api/src/main/kotlin/opensamguk/gateway/config/AdminSeeder.kt` 26–27·46–49행). QA에서는 `qa160admin`이다(`docker-compose.qa.yml` 170–171행). 화면에서 ADMIN을 늘릴 수 없고(`set_userlevel`은 6 이상 거부, 역할 불변, `AdminMemberService.kt` 240–242행), 일반 USER를 SQL로 ADMIN으로 바꾸지 않는다(`docs/admin/local-qa.md` 235행).
- 이 파일은 운영자 권한을 둘로 나눈다.
  - **게임 운영 권한:** 회원·게시판·신고·공지·턴 데몬·게임 관리 허브. 브라우저 스토리 대상이다(qa160 안에서만).
  - **인프라 권한:** 배포, 서버 생성·리셋·삭제, 환경 설정 편집, 게임 서버 업데이트·승격·초기화, GCP 전원. **브라우저 스토리에서 실행하지 않는다.** 아래 「범위 밖」 표에 위치만 남긴다.
- 브라우저 탭은 편의 기능이고 권한은 API가 강제한다(`docs/admin/README.md` 16–17행). 확인 대화는 최종 안전 경계가 아니다(같은 파일 36–37행).

- **상태:** 서버만. `POST /api/admin/general-moderation`은 있으나(`AdminWriteController.kt` 53행) 화면 버튼은 모두 비활성이다(`AdminPeople.tsx` 100·116행). 서버 기능은 다른 장수의 하야·해산·강제 사망 예약 등을 할 수 있고(`AdminGeneralModerationService.kt` 30–64행), 운영자 본인 장수가 있어야 한다(21행)
- **사용자 가치:** 아직 검증하지 않은 강한 운영 기능이 화면에서 실수로 실행되지 않는다.
- **계정:** qa160admin

**조작과 기대**

1. 인물 탭에서 장수 조치 버튼을 본다.
2. Then 버튼이 비활성(`aria-disabled` 또는 `disabled`)이고 눌러도 요청이 0건이다.
3. 서버 API를 직접 부르지 않는다. 이 스토리는 버튼이 꺼져 있음만 확인한다.

**결과:** NOT_RUN

## US-OPS-09 서버 공개 상태 바꾸기

- **상태:** 구현됨. `POST /api/admin/server-status` {`OPEN`|`PRE_OPEN`|`CLOSED`} → 202(`AdminWriteController.kt` 37행, `AdminServerStatus.tsx` 58행). 202는 접수이며 반영이 아니다
- **사용자 가치:** 운영자는 점검 때 서버를 닫고 다시 연다.
- **주의:** qa160 플레이어 전원이 영향을 받는다. **모든 플레이어 스토리를 마친 뒤 마지막에** 실행하고, 끝나면 원래 상태로 되돌린 뒤 USER 로그인·입장을 다시 확인한다.
- **계정:** qa160admin, 확인용 A-general1

**조작**

1. 게임 관리 허브 「상태」 탭에서 현재 상태를 기록한다.
2. `CLOSED`로 바꾸고 안내 「바꾸기를 접수했습니다」를 확인한다.
3. 반영될 때까지 상태를 다시 읽는다.
4. A-general1로 로비·게임 입장을 시도한다.
5. 원래 상태로 되돌리고 4를 다시 한다.

**Given / When / Then**

- Given 서버가 열려 있다,
- When 운영자가 `CLOSED`로 바꾸면,
- Then 202 뒤 상태 재조회가 `CLOSED`가 되고, USER의 입장이 막힌다(막히는 화면·code를 그대로 기록. `front-info`는 `SERVER_NOT_PUBLIC` 등 admission code를 쓸 수 있다, `docs/admin/local-qa.md` 76–79행).
- When 되돌리면, Then USER가 다시 입장한다.

**검증:** 권한(USER 403), 영속성(재조회), 재접속(USER), 중복실행(같은 값 재접수 결과 기록). 비용·턴 N/A.
**증거:** 상태 탭 전·후, USER 입장 화면.
**결과:** NOT_RUN

## 범위 밖: 인프라 권한과 데이터 삭제
