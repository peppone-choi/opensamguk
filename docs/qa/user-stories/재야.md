## 역할 정의

- **재야는 세력에 속하지 않은 장수**(`nationId == 0`)다. 새 플레이어는 장수로 시작해 재야로 떠돌거나 주공에게 출사한다(spec §2.1). 성장 경로는 「재야 → 출사 → 縣令·부장 → … → 군주」다(spec §2.5).
- 재야는 견문·이동·인재탐색·등용 같은 개인 행동을 하고, 출사로 세력에 들거나 거병으로 스스로 주공이 된다.
- 현재 main에는 **재야 장수의 실제 턴을 실행한 자동 시험이 없다.** `qa160-live.spec.ts`의 턴 시험은 세력 장수(`general1`)로 돈다(176행). 재야 진입 화면 시험은 모두 mock 응답이다(`web/game/e2e/smoke/entry-*.spec.ts`).
