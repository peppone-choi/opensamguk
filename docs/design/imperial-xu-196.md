# 196 許 재현의 사료 경계

`data/curated/han/imperial-xu-196-sources.json`은 네 사건 근거를 별도 행으로 둔다. 『後漢書』 卷009의 許 천도, 『三國志』 卷10의 황제에 의한 曹操 大將軍 임명은 정사 사건이다. 『三國演義』 卷014의 두려운 동의와 曹操의 大將軍 武平侯 자봉은 연의 사건이다. 두 관직 기록은 서로 다른 `scenarioEventKey`를 가진다. 역사 재현 기본 흐름은 사용자 결정대로 연의를 택하되, 정사 기록을 같은 전이로 덮어쓰지 않는다.

현재 `han-world-v3` 지도에서 洛陽은 城 46, 許縣은 城 130이다. 지도 연결만으로 구한 최단 경로는 46→57→134→122→136→130이다. 관문·시야·호송·보급 판정이 끝나지 않았으므로 그 경로를 플레이 가능한 이동으로 단정하지 않는다. 현재 시나리오에는 황실 시드가 없어 인물 ID와 초기 보관자·인장 위치를 임의로 넣지 않는다.

후속 fixture는 황제·상서·경비·인장·군량·두 보호 제안, 조서와 추천, 자칭과 추인, 밀지, 냉시작 재생을 각각 상태·사건으로 표현해야 한다. 城 점령만으로 보호국이 바뀌거나, 조서 거부가 실제 영토를 자동 이전하지 않도록 검증한다.
