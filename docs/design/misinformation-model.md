# 역정보의 서버 기록과 시야 투영

상태: S5-6a 순수 규칙. 실제 첩보 저장소, 계책 엔진, API, SSE, 지난 순 기록은 아직 연결되지 않았다.

`FalseSighting`은 시전자·피해자·거짓 군단·유효기간을 서버에만 보관한다. 피해자 첩보 스냅숏은 `victimReport`가 기존 `ScoutReport`에 거짓 목격을 합쳐 만든다. 반환형에는 시전자, 역정보 행 ID, 오염 표식이 없다. 다시 첩보하면 해당 피해자·郡國의 오염을 지운다. 매 순 발각은 월드·순·오염 행별 독립 시드로 판정하고, 유효기간이 끝난 행은 투영에서 제거한다.

가짜 군단은 `CorpsSighting` 읽기 결과로만 만든다. 피해자의 FULL/INTEL 시야에 표시하고 FOG에서는 숨긴다. 실제 출전 명령·군단 배치·병력·보급 저장소에는 삽입하지 않는다. 거짓 省이 주장하는 郡國과 맞지 않거나 실제 군단의 불투명 키와 충돌하면 실패한다. 따라서 후속 통합에서는 이 투영 결과만 API/SSE/지난 순 공개 읽기 경계에 전달하고, 조우·보급 계산에는 전달하지 않아야 한다.

`data/curated/han/misinformation-values.json`의 수치는 모두 게임 기획값이다. 지속 6순, 매 순 발각 100/1000, 반간·의병 비용 각각 전 100을 `CONFIRMED`로 기록했다. 비용은 현재 기본 계책값과 같게 정했지만 실제 차감은 S5-6b 카드 등록에서 연결한다. 오염 표식 누출의 실제 HTTP/SSE 적색 프로브와 군단 조우·보급 IT도 S5-6b의 게이트다.
