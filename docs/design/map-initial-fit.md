# 지도 초기 fit 계약

## 목표

게임 지도와 게이트웨이 지도 프리뷰가 동일한 공유 계약으로 실제 맵 컨테이너의 CSS 너비와 높이를 사용한다. 첫 화면에서는 768×669 전체 격자가 잘리지 않는 최대 배율로 가운데 정렬되어야 한다.

## 동작 계약

- 초기 view는 특정 군국을 확대하지 않고 전체 격자의 아이소메트릭 경계를 컨테이너 안에 맞춘다.
- 캔버스 backing store는 `CSS size × effective DPR`이며 DPR 1, 1.5, 2, 3에서 같은 CSS 구도를 유지한다.
- 맵 컴포넌트는 부모가 정한 실제 CSS 너비와 높이를 모두 사용한다. 높이를 너비의 고정 비율로 다시 계산하지 않는다.
- 사용자가 아직 pan/zoom하지 않았다면 컨테이너 resize 때 전체 지도를 다시 fit한다.
- 사용자가 pan/zoom한 뒤에는 resize와 DPR 변경 시 중심 셀과 사용자 확대 상태를 보존하되, 전체 지도 fit보다 작아지지는 않는다.
- game과 gateway는 별도 계산을 두지 않고 `HanMapCanvas`의 같은 계약을 소비한다.
- wheel, pinch, 키보드/버튼 확대, hitbox 좌표 변환과 픽셀 선명도 계약은 유지한다.

## 완료 조건

- 순수 계산 테스트에서 가로 제한·세로 제한 컨테이너 모두 전체 격자가 경계 안에 들어간다.
- 상호작용 테스트에서 실제 `clientWidth/clientHeight`, resize, DPR 1/1.5/2/3, 사용자 zoom 보존을 검증한다.
- game·gateway 소비자 테스트, 타입 검사, 생산 빌드가 통과한다.
- PEP 승격 후 공개 game route와 로그인 지도 프리뷰를 실제 브라우저에서 확인한다.
