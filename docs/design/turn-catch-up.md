# 밀린 턴 따라잡기

서버 중단 뒤 남은 턴을 복구할 때 플레이어가 기다릴 시간을 알 수 있고 예약 명령의 순서가 유지되어야 한다.

## 시작과 종료

- 다음 세계 턴 시각이 현재 시각보다 `2 × tickSeconds`를 초과해 늦으면 부팅 시 또는 운영 중 따라잡기를 시작한다. 정확히 같은 값이나 더 작은 지연에는 기존 턴 실행을 유지한다.
- 기본 속도는 2배속이다. 관리자는 진행 중 2배속 또는 4배속만 선택할 수 있다.
- 따라잡기 중 세계 경계 간 현실 간격은 `tickSeconds / multiplier`이다. 장수 개인 턴은 각 예약 시각을 같은 배속 시간축에 놓고 세계 경계보다 빠른 턴부터 처리한다. 세계 경계 내부의 월간 정산도 기존 개인 턴 드레인 뒤에 실행한다.
- `nextRunTime ≥ now`가 되면 일반 속도로 돌아가고 상단 안내를 숨긴다. 종료 사실을 공개 세계 사건에 한 번 기록한다.

## 예상 시각과 표시

현실 지연 `B = max(0, now − nextRunTime)`에 대한 남은 시간은 `B / (multiplier − 1)`이다. 예상 시각은 최소 매분 갱신하고 배속 전환 직후 다시 계산한다. 5분 턴이 20시간 밀린 경우 첫 예상 시간은 2배속에서 20시간, 4배속에서 6시간 40분이다.

모든 플레이어의 공통 게임 상단에 진행 배속과 한국 시간의 정상 속도 복귀 예상을 직접 표시한다. 작은 화면에서도 메뉴를 열지 않고 볼 수 있어야 한다. 관리자는 기존 pause/resume 근처에서 현재 지연, 회복한 지연, 배속, 남은 시간과 ETA를 보고 2/4배속을 전환한다.

## 게임 결과 불변식

배속은 실행의 현실 시각만 바꾼다. 예약 명령, 월경계, 게임 날짜, RNG 입력과 최종 게임 상태는 같은 시작 상태·입력에서 동일해야 한다. 운영용 따라잡기 상태는 게임 메타·config와 분리해 저장하며 골든 `world-state-sha256.txt`는 변경하지 않는다. 장애 재시작 뒤 저장된 진행 상태와 배속을 복구한다.
