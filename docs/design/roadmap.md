# 오픈삼국 공개 로드맵

> 마지막 검토: 2026-08-27
>
> 상태: 사용자 승인 기준선
> 일정 정책: 날짜를 약속하지 않고 단계별 출시 관문을 통과하는 즉시 다음 단계로 승격한다.

오픈삼국은 프로빈스 세계, 지속 이동과 보급, 작전, 인물과 통치, WEGO 전투를 하나의
캠페인으로 연결한다. 공개 알파는 기능을 뒤에서 채우는 선행 체험판이 아니다. 공개 알파를 열기 전에
모든 정규 커맨드와 사용자 화면, AI 경로, 도움말, 튜토리얼, replay가 구현되고 한 캠페인이 끝까지
진행되어야 한다.

## 공개 단계

| 단계 | 플레이어에게 보이는 결과 | 통과 관문 |
|---|---|---|
| 0. 규칙을 고정한다 | 아직 공개하지 않음 | 전체 커맨드 원장과 실행 계층, 대체 관계, 공개 알파 범위가 모순 없이 동결됨 |
| 1. 모든 명령이 같은 언어를 쓴다 | 명령의 조건·비용·결과·실패 이유가 일관됨 | 공통 registry, lifecycle, idempotency, replay, 도움말 연결 계약 완료 |
| 2. 세계가 보인다 | 프로빈스·현·군국·지형·세력·부대가 두 지도에서 읽힘 | 빈 육지·미소속·단절 프로빈스 0, 선택·확대·경계·범례 검증 |
| 3. 세계를 이동한다 | 이동·강행·발령·호송·수운·해운과 보급이 진행됨 | preview와 실제 경로 일치, 재시작 복구, AI 동일 topology 사용 |
| 4. 국가가 작전한다 | 출병·요격·지원·봉쇄·호송·퇴각·건설이 다턴 계획으로 진행됨 | 작전 시작부터 종료·점령·정산까지 관리자 개입 0 |
| 5. 사람과 국가가 통치한다 | 휘하 인물, 부곡, 회의, 관직, 조정, 도독부, 봉토와 봉신을 운용함 | 관련 커맨드·권한·AI·도움말·튜토리얼 전부 VERIFIED |
| 6. 전투를 지휘한다 | 야전·공성·해전에서 WEGO 명령을 계획하고 결과를 replay로 봄 | 계획→봉인→결정론적 해결→재생→캠페인 정산 완주 |
| 7. 한 판이 끝난다 | AI와 사람이 시작부터 통일·멸망까지 플레이함 | 장기 시뮬레이션, 저장·복구, 첫 30분·첫 작전·첫 전투 튜토리얼 통과 |
| 8. 공개 전 검증 | 주소는 비공개이며 관리자만 실제 배포 환경을 검증함 | 가입·로그인 비허용, 백업·복원·롤백, 최종 월드 초기화 완료 |
| 9. 공개 알파 | 누구나 가입해 전체 게임을 플레이함 | 계정 보존·월드 초기화 정책, 공지·FAQ·신고 경로 공개 |
| 10. 공개 베타 | 장기 시즌과 세이브 호환을 우선함 | 예고 없는 초기화 금지, 마이그레이션·복구·부하·운영 관문 통과 |

## 세계와 지도

- 한 번 구운 lossless RGB24 프로빈스 이미지가 모든 Han 시나리오의 영토 정본이다.
- 계층은 `raster cell → tactical province → county/direct territory → commandery/kingdom`이다.
- 모든 육지 셀은 정확히 한 프로빈스에 속하고, 모든 프로빈스는 이동·보급 topology에 참여한다.
- 산맥·대하·관문·나루·항구·정군산 같은 전략 지형과 사적은 필요하면 자체 프로빈스를 가진다.
- 전략 지도는 아이소메트릭, 빠른 대상 선택 지도는 평면 top-down으로 표시하되 같은 ID와 상태를 사용한다.
- 국가색은 영토와 별도 깃발 mask에만 적용하고 도시·요새·유적·지형 아이콘 본체에는 적용하지 않는다.
- 강은 흐름 방향을 가지며 상류·하류 비용, 수운, 도하를 서로 다른 규칙으로 계산한다.

## 휘하 인물과 부곡

`가신단`과 `부곡`을 하나로 취급하지 않는다. 화면의 상위 개념은 **휘하**다.

- 휘하 인물: 막료, 부장, 문객·측근처럼 이름과 관계·충성·역할·임무를 가진 인물이다.
- 부곡: 장수 개인에게 속한 사병 집단이며 병력·편제·훈련·사기·피로·군량을 가진다.
- 부장은 부곡의 지휘관으로 배정될 수 있지만 부곡 자체가 아니다.
- 국가군은 국가·도독부·주둔지 소속이며 개인 부곡과 별도다.

## 작전 목표와 교전

유리한 지형의 부대를 강제로 공격시키지 않는다. 교전이 없어도 도시 점령, 도로 확보, 보급로 차단,
통과, 봉쇄, 구원 같은 작전 목표는 실제 점유·통제와 보급 연결에 따라 진행된다.

```text
목표 선언 → WEGO 명령 봉인 → 이동·통제권·목표 진척
→ 요격·조우 → 접촉했을 때만 전투 → 점령·보급·기한 정산
```

- 방어자가 접촉을 피하면 병력을 보존하지만 도로·보급·주변 통제권을 내줄 수 있다.
- 공격자가 멈추면 작전 기한, 군량, 사기와 기회를 잃는다. 우회도 이동 지연과 길어진 보급선 비용을 낸다.
- 진지는 시간에 따라 상한까지 구축되지만 군량·피로·정찰 노출이 누적되고 통제 범위는 제한된다.
- 후퇴·재진입은 인공적인 대기 시간보다 이동력·응집도 손실과 추격 위험으로 비용을 낸다.
- 지형·접근 방향·진지·날씨·보급·목표는 병종 기본 데이터가 아니라 전장 환경으로 분리한다.
- 초기 검증 범위는 직접 지형 보정 ±20~25%, 모든 환경 효과의 실효 합산 ±35~40%이며 실제
  시뮬레이션과 플레이테스트로 조정한다.

## 커맨드 완결 규칙

공개 알파 전에 기존 개인턴·사령턴과 신규 이동·작전·정치·전술 커맨드를 모두 구현한다. 정규 커맨드의
완료 상태는 다음 파이프라인으로 관리한다.

```text
DOMAIN_READY → HANDLER_READY → UI_READY → AI_READY
→ HELP_READY → TUTORIAL_READY → REPLAY_READY → VERIFIED
```

별칭은 하나의 기준 명령으로 수렴한다. 폐기하는 명령도 조용히 사라지지 않고 대체 명령과 전환
정책을 가진다. registry에 없는 명령은 휴식이나 성공으로 떨어지지 않고 명시적으로 실패한다.

## 튜토리얼과 도움말

튜토리얼과 도움말은 출시 직전 문서 작업이 아니라 각 기능의 완료 조건이다.

- 명령 registry의 대상·비용·조건·실패 사유를 명령창, 도움말, 튜토리얼에서 재사용한다.
- 사람이 작성한 설명과 예시만 별도 콘텐츠로 유지한다.
- 각 기능은 contextual help, 검색 가능한 문서, 성공·실패 예시, 튜토리얼 단계 또는 명시적 N/A를 가진다.
- 공개 알파 전에는 가입→장수 생성→첫 명령→첫 건설→첫 작전→첫 전투 흐름을 실제 UI로 완주한다.

## 공개 알파 운영 정책

- 개장 전에는 주소를 공개하지 않고 전역 `allowJoin=false`, `allowLogin=false`를 사용한다.
- 관리자는 로그인 차단을 우회해 실제 배포 환경을 검증한다.
- 개장 직전 프리오픈 월드를 초기화하고 두 플래그를 연다.
- 공개 알파에서 치명적인 데이터 또는 밸런스 문제가 있으면 게임 월드는 초기화할 수 있다.
- 계정·닉네임·인증 정보는 월드 초기화와 무관하게 보존한다.
- 초기화 전 공지와 스냅샷을 남기고 종료 월드의 결과·통계·연대기를 열람 가능하게 보존한다.
- 공개 베타부터는 예고 없는 월드 초기화를 원칙적으로 금지한다.

## 다음 구현 이슈 선택 규칙

이슈는 중요도와 긴급도를 섞지 않는다.

1. 출시 관문이 더 앞선 이슈를 먼저 본다.
2. `critical-path` 차단 이슈를 먼저 본다.
3. 같은 관문이면 긴급도 `now → next → later` 순으로 본다.
4. 같은 긴급도이면 중요도 `critical → high → medium → low` 순으로 본다.
5. 선행 이슈가 끝나지 않은 항목은 중요해도 착수하지 않고 blocker를 먼저 해결한다.
6. 구현 이슈는 도움말·튜토리얼 완료 기준을 별도 후속으로 미루지 않는다.
