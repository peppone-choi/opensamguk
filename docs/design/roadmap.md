# 오픈삼국 공개 로드맵

> 마지막 검토: 2026-09-24
>
> 상태: 사용자 승인 기준선 — ADR-LITE-057·065 반영. 3단계 통과; 컷오버 A단계 문서 정리 진행 중. B단계 코드 교체와 pep 전환은 시작 전.
> 일정 정책: 날짜를 약속하지 않고 단계별 출시 관문을 통과하는 즉시 다음 단계로 승격한다.
> 정본 설계: [장수·휘하 캠페인 재설계](../superpowers/specs/2026-09-17-general-and-retinue-campaign-redesign.md)
> 실행 계획: [2026-09-17 포트폴리오 계획](../superpowers/plans/2026-09-17-general-retinue-portfolio-plan.md) — 단계별 GitHub·Jira 이슈 배치

오픈삼국은 장수 한 명이 주공을 섬기거나 스스로 주공이 되어 휘하(인물·부대·계책 카드)를 거느리고, 실제
지형 위에서 땅·창고·보급선을 다투며, 세력 안팎의 정치로 천하를 가르는 캠페인이다. 모든 플레이어는 장수로
시작하고 주공은 성장해서 된다. 삼모전 명령 체계는 새 입력 체계(장수 행동·배치·방침·공사·계책·조정 결정)로
교체하며 기존 명령은 동결 회귀 기준선으로만 남는다. 공개 알파는 기능을 뒤에서
채우는 선행 체험판이 아니다. 공개 알파를 열기 전에 1·2·3층(기반·정치·깊이)의 모든 입력과 사용자 화면, AI 경로,
도움말, 튜토리얼, replay가 구현되고 한 시즌이 끝까지 진행되어야 한다.

> 2026-09-17 이전 판의 공개 단계 0–7(규칙 고정 ~ 한 판이 끝난다), 「커맨드 완결 규칙」의 「기존 개인턴·사령턴 명령 전부
> 구현」 조건, 「작전 목표와 교전」의 동시 봉인 WEGO 순서도는 ADR-LITE-057 으로 대체됐다. 8–10단계(공개 전 검증·공개
> 알파·공개 베타) 관문과 운영 정책은 그대로다. 단계 번호는 정본 설계 §15.2 의 S0–S7 과 같다.

## 세계와 지도

- 한 번 구운 lossless RGB24 프로빈스 이미지가 모든 Han 시나리오의 영토 정본이다.
- 계층은 `raster cell → tactical province → county/direct territory → commandery/kingdom`이다.
- 모든 육지 셀은 정확히 한 프로빈스에 속하고, 모든 프로빈스는 이동·보급 topology에 참여한다.
- 산맥·대하·관문·나루·항구·정군산 같은 전략 지형과 사적은 필요하면 자체 프로빈스를 가진다.
- 전략 지도는 아이소메트릭, 빠른 대상 선택 지도는 평면 top-down으로 표시하되 같은 ID와 상태를 사용한다.
- 국가색은 영토와 별도 깃발 mask에만 적용하고 도시·요새·유적·지형 아이콘 본체에는 적용하지 않는다.
- 강은 흐름 방향을 가지며 상류·하류 비용, 수운, 도하를 서로 다른 규칙으로 계산한다.
- 화면의 정본은 야전 사령부(Concept A) 시안 19장이다 — `docs/design/ui-redesign-2026-09/`(ADR-LITE-049). 국가색은 깃발·초상 링·영토 tint 에만.
- 메인(작전실)은 **지도가 전면 스테이지**이고 「지난 순」·「명령 목록 12순」이 그 위 오버레이 레일이다(2026-09-08, 시안 03 아트보드의 3열 보드를 대체). 지도·명령 목록이 메인에 남는다는 규칙은 그대로다 — 바뀐 것은 지도가 폭 상한에 갇히지 않는다는 것뿐이다.

## 휘하

화면과 규칙의 상위 개념은 **휘하**다. 휘하는 장수가 거느린 인물·부대·계책·보물 카드 묶음이다(ADR-LITE-057).
모든 플레이어는 장수다. 주공은 거병·독립·봉신 계약으로 얻고 출사·하야·멸망으로 잃는 지위이며, 縣을 모두 잃은 주공은
방랑 주공이 된다. 봉신 계약으로 군주를 섬기는 주공도 주공이다. 휘하는 겹친다 — 장수 카드가 주공의 휘하에 들어가면 그 장수의 부곡·부장·보물도 함께
딸려 간다.

- 인물 카드: 이름과 결속·충성·역할·임무를 가진 인물이다. 역사 인물은 서버에 한 장뿐이고 무명 채용 인물은 공용 카드다.
- 부대 카드: 병력·편제·훈련·사기·피로·군량을 가진 병력 집단이다. 부곡은 부대 카드의 모집원 가운데 하나로, 장수 자기 병력·군량에서 편성한다.
- 인물 카드는 부대 카드의 지휘관으로 붙을 수 있지만 부대 자체가 아니다.
- 결속은 인물 결속(혈연·향당·은의·결의·명망)과 부대 결속(의종·항중) 일곱 가지다. 가문(혈연) 하나로 플레이 단위를 정하지 않는다.

## 작전 목표와 교전

유리한 지형의 부대를 강제로 공격시키지 않는다. 교전이 없어도 도시 점령, 도로 확보, 보급로 차단,
통과, 봉쇄, 구원 같은 작전 목표는 실제 점유·통제와 보급 연결에 따라 진행된다.

```text
목표 선언(작전·방침) → 장수 턴마다 이동·통제권·목표 진척
→ 요격·설치 계책·조우 → 접촉했을 때만 전투(공격 계획과 방어 대응 공개)
→ 점령 → 순 경계에서 보급·기한 정산
```

- 방어자가 접촉을 피하면 병력을 보존하지만 도로·보급·주변 통제권을 내줄 수 있다.
- 공격자가 멈추면 작전 기한, 군량, 사기와 기회를 잃는다. 우회도 이동 지연과 길어진 보급선 비용을 낸다.
- 진지는 시간에 따라 상한까지 구축되지만 군량·피로·정찰 노출이 누적되고 통제 범위는 제한된다.
- 후퇴·재진입은 인공적인 대기 시간보다 이동력·응집도 손실과 추격 위험으로 비용을 낸다.
- 지형·접근 방향·진지·날씨·보급·목표는 병종 기본 데이터가 아니라 전장 환경으로 분리한다.
- 초기 검증 범위는 직접 지형 보정 ±20~25%, 모든 환경 효과의 실효 합산 ±35~40%이며 실제
  시뮬레이션과 플레이테스트로 조정한다.

## 입력 완결 규칙

공개 알파 전에 1·2·3층의 모든 입력(장수 행동·배치·방침·공사·계책·조정 결정)을 구현한다. 기존 개인턴·사령턴
명령은 새 입력으로 대응되며(정본 설계 §12) 동결 회귀 기준선으로만 남는다. 정규 입력의 완료 상태는 다음
파이프라인으로 관리한다.

```text
DOMAIN_READY → HANDLER_READY → UI_READY → AI_READY
→ HELP_READY → TUTORIAL_READY → REPLAY_READY → VERIFIED
```

별칭은 하나의 기준 입력으로 수렴한다. 폐기하는 명령도 조용히 사라지지 않고 대체 입력과 전환
정책을 가진다. registry에 없는 입력은 휴식이나 성공으로 떨어지지 않고 명시적으로 실패한다.

## 튜토리얼과 도움말

튜토리얼과 도움말은 출시 직전 문서 작업이 아니라 각 기능의 완료 조건이다.

- 입력 registry의 대상·비용·조건·실패 사유를 명령창, 도움말, 튜토리얼에서 재사용한다.
- 사람이 작성한 설명과 예시만 별도 콘텐츠로 유지한다.
- 각 기능은 contextual help, 검색 가능한 문서, 성공·실패 예시, 튜토리얼 단계 또는 명시적 N/A를 가진다.
- 공개 알파 전에는 가입 → 장수 생성 → 첫 출사 → 첫 발령 → 첫 공사 → 첫 등용 → 첫 행군 → 첫 전투 흐름을 실제 UI로 완주한다(정본 설계 §15.2).

## 공개 알파 운영 정책

- 개장 전에는 주소를 공개하지 않고 전역 `allowJoin=false`, `allowLogin=false`를 사용한다.
- 관리자는 로그인 차단을 우회해 실제 배포 환경을 검증한다.
- 개장 직전 프리오픈 월드를 초기화하고 두 플래그를 연다.
- 공개 알파에서 치명적인 데이터 또는 밸런스 문제가 있으면 게임 월드는 초기화할 수 있다.
- 계정·닉네임·인증 정보는 월드 초기화와 무관하게 보존한다.
- 초기화 전 공지와 스냅샷을 남기고 종료 월드의 결과·통계·연대기를 열람 가능하게 보존한다.
- 공개 베타부터는 예고 없는 월드 초기화를 원칙적으로 금지한다.

## 다음 구현 이슈 선택 규칙

이슈는 중요도와 긴급도를 섞지 않는다.

1. 출시 관문이 더 앞선 이슈를 먼저 본다.
2. `critical-path` 차단 이슈를 먼저 본다.
3. 같은 관문이면 긴급도 `now → next → later` 순으로 본다.
4. 같은 긴급도이면 중요도 `critical → high → medium → low` 순으로 본다.
5. 선행 이슈가 끝나지 않은 항목은 중요해도 착수하지 않고 blocker를 먼저 해결한다.
6. 구현 이슈는 도움말·튜토리얼 완료 기준을 별도 후속으로 미루지 않는다.
