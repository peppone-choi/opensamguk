# 오픈삼국 기획 문서 지도

> 마지막 검토: 2026-08-20
> 적용 기준: 현재 저장소의 승인된 의사결정과 구현. 외부 레거시는 참고 자료다.

이 디렉터리는 “지금 되는 것”과 “앞으로 만들 것”을 구분해서 읽기 위한 기획 진입점이다. 플레이 방법은
[사용자 매뉴얼](../user/README.md), 운영 방법은 [관리자 매뉴얼](../admin/README.md)을 따른다.

## 정본 우선순위

서로 다른 문서가 충돌하면 다음 순서로 판단한다.

1. `.ai/decisions.md`의 승인된 최신 ADR-LITE
2. 명시적으로 승인되었고 supersede 관계가 기록된 `docs/superpowers/specs/`
3. 현재 코드와 실행 검증 결과
4. `docs/design/roadmap.md`와 실행 계획
5. GitHub 이슈와 Jira 티켓
6. `legacy/`, 외부 Gitea 문서, 과거 리뷰·리서치

티켓은 작업 추적 수단이지 제품 정본이 아니다. 특히 Jira는 2026-08-20 현재 이 세션에서 실시간 상태를
조회할 권한이 없어 상태를 `UNKNOWN`으로 유지한다.

## 2026-08-20 기준 전환

ADR-LITE-042에 따라 PHP `devsam/core`는 더 이상 새 기획의 절대 정본이 아니다. 기존 골든과 회귀 테스트는
동결된 기준선으로 보존하지만, 새 기능은 오픈삼국의 승인된 기획과 아키텍처를 따른다.

계속 지키는 불변식은 다음과 같다.

- 같은 입력과 seed에 대한 결정론적 재현
- `ChangeRecorder`에서 JDBC batch flush로 이어지는 단일 daemon write 경로
- 결과·테스트·근거를 만들었다고 가장하지 않는 검증 규율
- 명시적인 실행 순서와 삽입 순서 보존

PHP와 draw-for-draw, byte-for-byte로 일치해야 한다는 의무와 PHP UI를 그대로 복제해야 한다는 의무는
신규 기획 기준에서 해제되었다.

## 상태 표기

| 표기 | 의미 |
|---|---|
| `구현됨` | 현재 저장소에 사용자 또는 운영 표면과 실제 경로가 있다. |
| `승인됨` | 제품 결정은 끝났지만 구현 완료를 뜻하지 않는다. |
| `진행 중` | 추적 티켓이 열려 있거나 구현·검증이 덜 끝났다. |
| `제안` | 검토할 가치가 있으나 승인되지 않았다. |
| `동결 기준선` | 회귀 보호를 위해 남기되 신규 설계의 상한으로 삼지 않는다. |
| `UNKNOWN` | 현재 증거로 상태를 판정할 수 없다. |
