# 개인 이동 정책

2026-10-08 사용자 확정 정책이다. 개인 `action.move`와 `action.forcedMarch`에만
적용하며, 부임·군단·수송의 공통 이동 예산과 비용은 바꾸지 않는다. 귀환은 아래 후속 승인대로 한 이웃 이동으로 제한한다.
판정은 옵션 조회, 예약 접수, 개인 턴 실행에서 같은 `TravelRules`를 사용한다.

## 일반 이동

일반 이동은 현재 위치에서 실제로 통행 가능한 LAND/FORD/BRIDGE 간선 한 개를
지나 인접 지역으로 간다. 정상 통행·진입 조건이 충족되면 한 개인 순에 도착한다.
거리 예산을 크게 설정하는 근사 규칙이 아니다. 길의 방향, 건설·활성 상태,
계절, 봉쇄, 용량, 하천 장벽, 적대 길목을 기존 실행 그래프로 검사한다.
닫힌 직접 간선 대신 간접 우회를 선택하거나 FERRY·진단용 연결을 사용하지 않는다.

`PersonalMovePath`는 직접 경로를 고정하며 `TravelExecutor`는 이 간선의 남은
지형 비용을 한 순에 처리한다. 진입 상태를 확인할 수 없거나 조우하면 기존
중단 규칙을 따른다. 이후 통행이 열려 재개할 때도 한 간선 규칙을 적용한다.

## 개인 강행

승인 상한은 실제 경로 거리 260km와 예상 두 개인 순을 동시에 만족하는 것이다.
개인 강행의 내부 지형 비용 예산은 순당 370,000,000mm이다. 예상 순 수는 비용
합을 예산으로 나눈 정수 몫과 나머지를 사용해 올림한다. 덧셈 오버플로가 생길
수 있는 `(cost + budget - 1) / budget` 방식은 사용하지 않는다.

370은 개인 일반 이동을 거리 예산으로 해석한 배수가 아니다. 현재 선택 지도에서
직접 간선의 최대 실제 거리는 약257.974km, 최대 지형 비용은 약365.199km여서,
강행이 일반 직접 이동보다 느려지거나 인접 목적지를 거절하는 역전을 막도록
사용자가 승인했다. 이 수치는 구현·정책 근거이며 사용자 화면의 이동 속도로
표시하지 않는다. 화면은 서버의 예상 개인 순 수, 기존 피로·사기 비용과 도착 뒤
값을 사용하고, 실제 거리는 보조 정보로 표시할 수 있다.

최소 지형 비용 경로가 항상 거리 상한을 만족하지는 않는다. 예를 들어 직접
A-B가 실제240km·비용360km이고 우회 A-C-B가 실제270km·비용270km일 수 있다.
다른 저비용 우회가 닫히면 기존 최소 비용 탐색은 A-C-B를 반환하지만 이 경로는
강행 거리 상한을 넘는다. 정책은 최소 비용 경로와 통행 가능한 직접 경로를
각각 상한·비용으로 평가하고, 합법 경로 중 예상 순 수→비용→간선 ID 순으로
선택한다. 직접 A-B를 한 순에 선택할 수 있으며 260km 상한을 완화하지 않는다.
제한 경로 전체를 새 알고리즘으로 탐색하는 기능은 추가하지 않았다.

피로·사기 비용은 기존 실제 거리30km당 피로+10·사기−5 계산을 유지한다. 누적
거리의 정수 몫 차이를 지불하며 나머지를 다음 순과 다음 강행 명령에 이월한다.
지형 비용은 이동 시간에만 쓰고 개인 비용은 실제 거리로 계산한다. 피로 상한까지
남은 여유나 현재 사기보다 raw 비용이 크면 거절한다. 같으면 허용한다. 기존 순수
계산의100/0 clamp는 유지하지만 clamp 결과만 보고 비용 부족을 허용하지 않는다.
극소 거리에서 정수 비용이0인 경우에도 거리 나머지를 보존해 무제한 무료 강행을
허용하지 않는다. 일반 이동과 귀환에는 이 비용 검사를 확장하지 않는다.

목적지 API의 `forcedFatigueDelta`는0 이상, `forcedMoraleDelta`는0 이하이며
`afterFatigue`·`afterMorale`와 함께 전체 도착 예측이다. 실제 실행은 해당 순에
진행한 실제 거리 증분만 지불한다. 두 순으로 나눈 누적 계산과 전체 예측이
일치하는 회귀를 유지한다. 불가 목적지·일반 이동·귀환은 네 필드를 제공하지 않는다.
현재 조건을 요청마다 읽으며 원시 장수 metadata를 화면으로 전달하지 않는다.

## 진행 중 주문 전환

한 간선 일반 이동은 기존 위치·부분 비용·cursor·주문을 보존하면서 남은 비용을
한 순에 처리한다. 여러 간선의 기존 일반 이동은 자동 전진하지 않는다. 기존
강행도 고정 경로의 승인 거리·순 수와 남은 실제 비용·피로·사기 지불 조건을
실행 순에 다시 검사하며 정책에 맞지 않으면 원 주문을 보류한다.

보류는 기존 TravelState를 다시 쓰거나 없애지 않고 별도의 엄격한
`personalTravelPolicyHold` 표식과 최초 한 번의 개인 거절 기록을 남긴다.
현재 위치·고정 경로·cursor·부분 지불·원 주문 ID를 보존한다. 같은 순의 반복 실행은
비용이나 로그를 중복 처리하지 않는다. 전투·구금·출전 지휘·지도와 통행 authority의
기존 검사가 먼저 실행된다. 새 유효 주문이 실제 시작될 때만 보류 표식을 지운다.

보류 중 자동 이동을 막으면서도 이동하지 않은 개인 순의 기존 휴식 회복을
적용한다. 회복은 순별로 한 번이며 회복했다고 원 주문을 자동 재개하지 않는다.
실패한 새 예약은 원 주문과 보류를 유지한다. 시작되지 않은 과거 장거리 일반
이동 예약은 현재 위치에서 새 규칙으로 검사해 거절하며 움직이거나 비용을 쓰지 않는다.
소유권·발령 변경과 잘못된 상태의 기존 처리 규칙은 이 전환과 별개다.

## 원장과 회귀

`data/curated/han/march-tempo-targets-v1.json`의 `personalTravel`이 개인 정책 수치의
권위 원장이다. 기존 공통30km·지형 계수·군단·수송·공성·개인 비용 원장 값은
유지한다. `ForcedMarchTempo`는 개인 예산·상한과 기존 개인 비용을 읽는다.
원 파일에 개인 항목이 추가되어 exploratory simulator의 source hash는 달라질 수
있지만 공통 시뮬레이션 결과는 달라져서는 안 된다. 이 hash를 과거 clean revision의
증거로 재사용하지 않는다.

검증에는260km/740km 비용의 포함 경계와1mm 초과, 험지, 부분 폐쇄 직접 경로
대안, 비용 부족·정확 지불·누적·clamp, 한 순 재시도, 현재 상태 재검사, 보류·휴식·
새 주문 교체, API 예측과 실제 실행의 일치가 포함된다. 실제1608지역 지도 시험은
지원 간선 전체의 거리·비용을 승인260km/370km 상한과 비교한다. 앞으로 지도나
지형 비용이 상한을 넘으면 이 회귀가 실패해야 하며, 정책을 검토하고 사용자
결정을 받는다. 기대값이나 골든을 낮추거나 비용 상한을 조용히 넘기지 않는다.


## 2026-10-08 후속 승인: 귀환 한 이웃 이동

사용자가 귀환도 한 개인 순에 다음 이웃 한 곳으로 이동하고 멈추도록 승인했다.
서버는 현재 발령 근무성까지 기존 유효 경로를 판정한 다음 그 경로의 정확한 첫
LAND/FORD/BRIDGE edge를 pinned path로 저장한다. 거리·지형 비용 예산을 근사해서
늘리지 않고 한 edge 비용 전액으로 한 순에 처리한다. RETURN 인자는 계속 `{}`다.
예약·실행은 현재 발령과 권한·경로를 다시 판정하며 근무성 자체를 이번 목적지로
표시하지 않는다. owner API는 `workplace {provinceId,name,countyId}`와 이번 다음
도착지 하나의 `destinations`를 분리한다. 공용 명령 화면은 어댑터가 준 labeled
locations를 표시하며 inputId에 따른 제품 분기를 갖지 않는다.

유효 새 RETURN 시작은 strict `personalReturnStop {version,orderId,assignmentId}`를 저장한다.
완료 TravelState만 유지하면 패배/포로 settlement가 이를 지웠을 때 발령 자동 행군이
재개되므로 사용자 정지 의도를 별도 보존한다. marker는 assignment가 유효한 동안 빈 순 이동 단계를 소유하여
AssignmentMarchTurn의 부임 자동 행군으로 계속 이동하는 것을 막는다. 기존 휴식은
phase당 한 번 적용한다. 군단의 먼저 처리되는 이동 우선권은 그대로이며 발령이
바뀌면 기존 assignment guard를 따른다. 새 유효 개인 이동만 marker를 제거하거나 새 귀환 marker로 교체한다. 거절은
marker와 기존 이동 상태를 바꾸지 않는다. 첫 이동 phase에 기존 recovery timestamp를
기록해 이동한 같은 순에 휴식이 더해지지 않는다. 잘못된 marker는 자동 전진을
허용하지 않고 새 입력을 STATE_UNAVAILABLE로 거절한다. 새 유효 개인 이동이 완료 상태를 교체한다.
미완 구 RETURN은 원 경로·cursor·paid·order·현재 위치를 보존해 policy hold하며
빈 순에 자동 재개하지 않는다. 미완 새 RETURN도 자동 재개 없이 새 예약을 요구한다.
통행 폐쇄·조우의 기존 안전 판정은 유지한다. 귀환의 피로·사기 신규 비용은 없다.
강행 370/260/2와 부임·군단·수송 정책 및 지도·골든은 변경하지 않는다.
