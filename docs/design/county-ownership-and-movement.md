# 프로빈스 전선·현 행정권 기준

2026-09-06 결정: **전선·부대 위치·이동·군사 점유는 프로빈스, 내정·징세·인사는 현**으로 분리한다.

정본 설계는 [프로빈스 전선과 현치 함락 설계](../superpowers/specs/2026-09-06-province-front-and-county-capture-design.md)를 따른다.
게임 규칙은 사용자 승인 상태다. 후속 합의인 목표 중심 지속 명령과 거리·지형 기반 이동량도 정본 설계에 포함한다.
프로빈스 한 칸을 한 턴으로 계산하지 않는다. 구체 이동량·비용 수치는 밸런스 검증 대상이며 현재 게임에 구현됐다는 뜻은 아니다.

앞선 ‘현 전체가 하나의 이동·점령 단위’ 초안은 폐기한다. 같은 현의 다른 프로빈스가 목적지와 접한다는 이유로
부대가 경계를 건너뛰거나, 현치가 함락됐다는 이유로 적군이 지키는 프로빈스까지 자동 점령해서는 안 된다.

현재 구현 범위는 저장 기반이다. 명시적인 `han-world-v3` 월드에서 프로빈스 점유와 장수의 전략 노드 위치를
불변 메모리 상태로 보관하고, ChangeRecorder와 월드 fence·행 revision 검사를 거치는 JDBC flush로 저장한다.
재기동과 전용 읽기 경계는 같은 지형 revision·hash를 검증하며, 장수 삭제는 같은 월드의 위치 행도 제거한다.
위치·점유 행이 없으면 미확정 상태로 남고, 주변 도시나 현 소유권으로 추정하지 않는다. 기존 월드는 자동 보정하지 않는다.

이 저장 기반은 기존 지도·전투·보급·이동 명령을 전환하지 않는다. 활성화 전에는 미매핑 8개 도시를 포함한
완전한 초기 상태와 입장 검증, 현 행정권 저장, 함락 이벤트, 거리·지형 이동 비용과 진행 상태,
지속 명령 및 명령·화면 연결을 후속 구현·검증해야 한다. 현재 지도·이동 문제의 해결 완료나 배포를 뜻하지 않는다.
