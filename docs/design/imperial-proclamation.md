# 칭제·190 통일 판정 설계 초안

> 상태: **검토 초안**. 2026-09-25·26 사용자 결정인 통일의 필요조건만 확정이다. 아래 `제안`은 칭제 입력의 제품 규칙으로 아직 채택되지 않았다. C4·C6가 황실 정본을 맞추고 C0가 사용자에게 남은 규칙 선택을 모아 확인한 뒤 런타임에 배선한다.

## 확정된 통일 규칙과 자료 경계

한 세력이 **190년 시점에 유효한 漢 13州의 郡國 전부를 점유하고, 그 세력이 칭제한 상태**여야 통일이다. 두 조건은 `AND`다. 戶口 점유율·칭제 유지 기간은 조건이 아니며, 漢 郡國 밖의 취락·이민족 거점도 조건에 넣지 않는다. 이는 `2026-09-25-forward-decisions.md`와 `2026-09-29-next-features-requirements.md` 기능 6에 기록된 사용자 결정이다. 190년 1월 인물·郡 지배의 사료 원장(`reports/opensamguk/tasks/artifacts/2026-09-25-scenario-190/`)은 조사 대장이고, 대부분의 소속·소재가 `UNKNOWN`이므로 그것만으로 런타임 郡國 도메인이나 시드의 역사적 정확성을 선언할 수 없다.

도메인 원장은 고정한 지도 핀의 parent ID 전부를 한 번씩 열거하고 각 행에 `ACTIVE_CITED`, `INACTIVE_CITED`, `OUTSIDE_HAN`, `UNKNOWN` 중 하나, 漢 州 귀속, 책·권·구절, 판정 사유를 기록한다. 유효성·州 귀속·실효 지배가 `UNKNOWN`이면 통일은 실패한다. 원장 또는 지도 핀이 없거나 달라져도 실패한다. 이 실패 닫힘은 09-29 요구사항의 **설계 규칙**이지 09-25·26 사용자 결정의 추가 수치가 아니다. 제품 지도 레지스트리의 郡 개수나 후대 郡治 수를 190년 유효 郡國 분모로 재사용하지 않는다.

`점유`의 계산 단위는 **미확정**이다. 현재 권장안은 해당 郡國에 속하는 모든 육지 省의 실효 지배자가 동일 세력인 경우다. 郡治 城 한 곳의 소유 또는 州 관직만으로 郡國 전체를 점유한 것으로 보지 않는다. 수역·무인 省, 省/郡 경계가 맞지 않는 지도 칸의 처리는 도메인 validator와 함께 결정한다.

## 기존 황실 모델과 접점

`docs/design/imperial-succession.md`와 `logic/.../imperial/ImperialWorldState.kt`는 국가 군주와 황제를 분리하고, 한 세계에 여러 `ACTIVE` 황통을 허용한다. `ImperialHouse.holderGeneralId`는 황제이고 `courtNationId`는 조정 보호 세력이다. 둘을 국가 군주 ID나 영토 점유자로 대입하지 않는다. `ImperialWorldCodec`는 `world_state.meta.imperialWorld` 스키마 1을 읽고 쓰며, 키 부재는 황실 미시드, 손상은 오류다. `ImperialTransition`에는 `requestId`, 황통 코드, `FOUNDATION` 등 전이 종류, 행위자, 연월, 사유가 있다.

현행 `changeSovereign(..., FOUNDATION, ...)`는 **이미 houses 목록에 있는 비활성 황통**만 활성화한다. 새 황통을 목록에 더하는 생성 함수가 아니며, 동일 `requestId` 재호출은 예외다. 따라서 칭제 입력을 `FOUNDATION` 한 줄 호출로 구현할 수 없다. 신규 황통 생성, 또는 시드된 비활성 황통의 활성화 경로를 구분하고, 입력 접수·세계 상태 flush·전이 이력·사건을 원자적으로 지속해야 한다. 같은 입력/월 재시도의 처리 결과는 같은 상태와 단일 사건이어야 한다. `ImperialHouse.legitimacy`는 0–100의 필수값이라 초기값 또는 산식의 선택도 필요하다. 기존 `NationRank.peerageOf`는 규모만으로 `HWANGJE`를 주지 않는다. 황제 표시와 국가 작위·정통성 축의 연결 방식은 별도로 정해야 한다.

`2026-08-19-nation-rank-three-axis.md`의 `holdsEmperor` 설명은 세계 전체에서 최대 한 세력이라고 쓰지만, 현재 황통 정본은 복수 `ACTIVE`를 허용한다. 칭제 이후의 `holdsEmperor`를 단일 세계 불리언으로 유지할지, 황통별 조정 보호와 별개로 볼지 C6와 함께 정리해야 한다. 황제 보유와 칭제한 세력이 동일하다는 가정은 하지 않는다.

## 칭제 입력의 검토안 (K8-15)

| 항목 | 권장안·검토 이유 | 아직 결정할 점 |
|---|---|---|
| 행위자 | 현재 국가 군주가 자기 세력 명의로 선언. 섭정·황제 보유는 자동 자격이 아님 | 사람 주공과 NPC 주공에 같은 자격을 적용할지, 국가 군주 외 명시적 대리인을 허용할지 |
| 입력 | 별도 칭제 입력 ID를 원장에 추가하고 접수·실행에서 같은 자격 검사를 사용 | 정확한 ID·턴 단계·예약/즉시 처리·철회 가능 시점 |
| 자격 | 살아 있는 행위자와 실재·존속 세력, 중복 칭제가 아님, 황통/시드 상태가 유효해야 함 | 영토·왕작·명망·인장 같은 추가 문턱을 둘지. **수치·기간 미확정** |
| 기존 漢 황통 | 기존 황제·황통을 자동 종료하거나 폐위하지 않음. 병립 황통으로 기록 | 칭제가 `PRETENDER`/`SELF_STYLED`로 바뀌는 범위, 漢 조정이 이미 같은 세력을 보호할 때의 처리 |
| 새 황통 | `ImperialHouse`와 `FOUNDATION` 이력을 같은 세계 상태 변경으로 생성하는 경로를 제안 | 황통 코드·이름 선택 주체, 황제 보유자(군주 본인/별도 후보), 초기 정통성·조정 城 |
| 효과 | 황실 관계·국가 등급·공개 사건의 변경을 한 사건에서 파생 | 외교·명망·官爵 효과와 수치. 직접 전쟁/복속을 자동 발생시킬지 |
| NPC | 사람과 같은 검사를 통과할 때만 정책으로 선택, RNG가 아니라 기록된 상태·정렬 키에 따라 결정 | 시작 시점, 선호 조건, 무인 시즌 교착 방지 정책 |
| 실패 | `NOT_RULER`, `NATION_UNAVAILABLE`, `IMPERIAL_STATE_UNAVAILABLE`, `ALREADY_PROCLAIMED`, `LINE_CONFLICT`, `STALE_WORLD`를 **후보 코드**로 제안 | 원장의 실제 이름·기존 실패 코드 재사용·사용자에게 보일 회복 조언 |

도움말 초안: “칭제는 내 세력이 새 황통을 세우겠다고 선언하는 일입니다. 이미 있는 황제를 곧바로 없애지는 않습니다. 통일에는 190년 漢 13州의 유효 郡國 전부를 한 세력이 차지한 상태도 필요합니다.” 자격이 확정되기 전에는 이 문구에 왕작·인장·기간을 덧붙이지 않는다.

## 통일·시즌 처리 계약 초안 (K8-13/14)

월 경계에서 동일 지도 핀과 190 도메인 원장, 실효 지배 투영, 지속된 황실 상태를 한 스냅숏으로 읽는다. 郡國 하나라도 다른 세력/중립/누락/UNKNOWN이면 실패한다. 州 13개만 충족하거나 郡國만 충족한 경우도 실패한다. 해당 **동일 세력의 유효한 칭제 상태**가 없으면 실패한다. 양성 판정 때만 `isunited=2`와 시즌 결과, 연감 스냅숏, typed 통일·시즌 종료 사건을 멱등으로 기록한다. 기존 `RaiseInvaderMessageHandler`가 `isunited`에 의존하는 경로의 처분을 새 writer PR에서 먼저 명시한다. 유효 시즌 기한과 `EXPIRED` 처리 시점은 아직 확정되지 않았다.

K8-13 `GET /api/unification`의 규칙·집계 시각·세력별 점유·완료 州·칭제 표시는 이 판정과 같은 스냅숏에서 파생한다. K8 Q8(시야 밖 세력의 진행 공개)은 미결정이다. 권장안은 **규칙과 최종 결과를 공개하고 진행 수치는 관찰자의 시야에 따라 마지막으로 알려진 값과 `asOf`를 표시**하는 것이다. 현재 계약판의 무조건 공개 `nations[]`와 충돌하므로 Q8 결정 뒤 계약을 수정한다.

K8-14 `GET /api/season`은 종료 사유 `UNIFIED|EXPIRED`, 결정 시각, 승자, 연감 스냅숏을 읽는다. `notablePeople` 선정은 사건 원천과 동률 순서가 정해지기 전까지 구현하지 않는다. 권장안은 기록된 시즌 기여 사건만으로 정렬하고 근거 사건이 없으면 빈 목록을 내는 것이다. 명예의 전당은 두지 않는다.

## 리뷰에서 결정할 질문

1. **C4·C6 → C0/사용자:** 칭제 행위자는 국가 군주로 제한할까? 왕작·영토·명망·인장 같은 추가 자격을 둘까? 권장: 군주만 허용하고 추가 수치 문턱은 두지 않아 무인 시즌에서 자의적인 막힘을 피한다.
2. **C4·C6 → C0/사용자:** 새 황통의 황제는 선언 군주 본인인가, 별도 지명 인물도 가능한가? 권장: 첫 런타임에서는 본인만 허용해 상태·권한을 명확히 하고, 별도 황제 지명은 후속 제위 전이로 다룬다.
3. **C4·C6 → C0/사용자:** 칭제가 기존 황통과 국가의 관계·명망·작위에 어떤 효과를 주는가? 권장: 기존 황통은 자동 종료하지 않고, 새 `ACTIVE` 황통/명시적 경쟁 관계만 만든다. 명망·외교의 양적 효과는 별도 결정 전 적용하지 않는다.
4. **C4 → C0/사용자:** 郡國 점유를 “모든 육지 省 실효 지배”로 확정할까? 권장: 그렇다. 郡治만 점유해 나머지 영토가 타국인 경우를 통일로 읽지 않는다.
5. **C4 → C0/K8:** 통일 진행의 공개 범위를 어떻게 할까? 권장: 규칙·종료 결과 공개, 시야 밖 진행은 마지막으로 알려진 값과 시각.

이 선택이 확정되기 전에는 API·입력 원장·`EventKind`·Flyway·월말 훅을 변경하지 않는다. C0 공유 자원 예약과 C6 정본 합의 뒤 각각의 런타임 PR에서 구현한다.
