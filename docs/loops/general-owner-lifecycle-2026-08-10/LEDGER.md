# General owner lifecycle loop ledger

## Scope

Fix the released/dead general lifecycle so an obsolete `general_owner` claim cannot prevent a user from creating or possessing a new general. This task covers the daemon `ChangeRecorder -> FlushPayload -> JdbcFlushExecutor` path, typed `TurnGeneral.userId` cleanup, and the API classifier/admission recovery for a replacement live general.

## Oracle and invariant

- PHP `legacy/devsam-core/hwe/sammo/TurnExecutionHelper.php:185-204`: a possession release sets legacy owner fields to their released values; the non-release branch calls `kill()`.
- PHP `legacy/devsam-core/hwe/sammo/General.php:583-594`: `kill()` removes the live general and its turn/rank/access-log records.
- Kotlin invariant: only a current live general may resolve as the user’s owner. A released or deleted general must leave no durable `general_owner` row, and release clears `TurnGeneral.userId` as well as the legacy metadata owner.
