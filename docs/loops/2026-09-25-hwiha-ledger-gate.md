# 휘하 원장 대응 게이트 회귀 복구

작업 기준: `origin/main` 57c0e13. R-FIX-A-1의 70개 기존 명령 대응 프로브와 사령턴 kind 표를 복구한다.

## 변경

- 실제 원장의 70개 메뉴 슬롯을 하나씩 변형하여 특정 명령의 모든 역참조를 제거하면 미대응 결과가 정확히 그 명령 하나인지 검사한다. 중복된 `휴식` 슬롯은 두 번 시험한다.
- 직접 행동 판정은 본 검사와 변형 프로브가 같은 함수 `missingDirectActions`를 사용한다.
- 사령턴의 비휴식·비폐지 21개 명령 전체를 고정하고, 발령·포상을 조정 결정에 포함한다.
- 옛 `che_기술연구`는 장수 메뉴 소속인지 별도로 단언한다. 새 설계의 대응 행은 3층 `court.institution`이라는 점도 고정한다. 옛 메뉴 출처와 새 입력 kind는 서로 다른 분류다.

## 검증

- `HwihaInputRegistryTest` 32개 통과.
- 적색 프로브 3개: 실제 `court.dispatch`의 발령 역참조 제거, `action.farm`의 농지개간 역참조 제거, 직접 행동 판정 조건 반전. 세 경우 모두 지정 시험 실패를 확인하고 원본을 복원했다.
- 복원 뒤 같은 테스트 통과, `git diff --check` 통과.
