# 회원·게임 관리

> 상태: 현재 관리자 route/API 기준
> 마지막 검토: 2026-08-20

## Gateway 회원 관리

`/admin`의 `회원 관리`는 회원 목록과 전역 가입/로그인 허용 상태를 보여 줍니다. 현재 API는 다음 범주를
지원합니다.

- 가입 허용·로그인 허용 토글
- 탈퇴 예정 회원·장기 미접속 회원 정리
- 회원 삭제, 임시 비밀번호, 차단·해제, 등급 변경
- 이메일 영구 차단

자기 자신과 다른 ADMIN을 변경하지 못하도록 서버에서 self/peer 보호를 적용합니다. 계정 정리는 실제 회원
데이터를 삭제할 수 있으므로 대상 수, 기준 시각, 백업과 승인을 확인한 뒤 실행합니다.

## Gateway 게시판 관리

`/admin`에는 `게시판 관리` 탭이 있습니다. 다만 공지 고정, 작성자/ADMIN soft-delete와 전체 관리자 UX의 완료
기준은 [OPENSAM-81/#223](https://github.com/peppone-choi/opensamguk/issues/223)에서 아직 추적 중입니다.
현재 화면에 없는 기능을 API 호출로 우회하지 않습니다.

## Gateway 게임 환경

`게임 환경` 탭은 shared env와 서버별 env를 읽고 허용된 항목을 수정합니다. 다음 규칙을 지킵니다.

- 실제 `.env` 파일 전체나 비밀값을 문서·채팅·로그에 출력하지 않습니다.
- 허용 목록에 있는 키만 변경합니다.
- shared와 server env의 책임을 섞지 않습니다.
- 변경 전 값과 대상 서버를 기록하고 한 번에 한 목적만 적용합니다.
- 변경 뒤 관련 서비스 health, auth, world ID와 scenario를 확인합니다.

## 게임 관리자 화면

| 경로 | 화면 | 성격 |
|---|---|---|
| `/game/admin1` | 게임 관리 | 공지, 시작 시각, 장수·국가 상한, 시작 연도, 턴 간격 등 허용된 설정 변경 |
| `/game/admin2` | 회원/장수 관리 | 블록, 강제 사망, 접속 제한, 명령 설정, 메시지 전달 등 선택 장수 조치 |
| `/game/admin5` | 일제 정보 | 국가 통계 정렬·조회 |
| `/game/admin7` | 로그 정보 | 개인 기록, 전투 기록, 장수 열전, 전투 결과 조회 |
| `/game/admin8` | 외교 정보 | 전 국가 외교 관계 read-only 조회 |
| `/game/tournament-admin` | 토너먼트 관리 | 상태·대진·참가자 조회, 권한이 있으면 시작·초기화 |

버튼이 disabled라면 단순 UI 미완성일 수도 있지만, 서버가 해당 write를 명시적으로 막은 것일 수도 있습니다.
사유를 확인하지 않고 직접 DB를 수정하지 않습니다.

## 조치 전후 기록

회원·장수 조치를 수행할 때는 최소한 다음을 감사 기록에 남깁니다.

- 실행 시각과 작업자
- 서버/world와 대상 ID
- 조치 종류와 사유
- 변경 전·후 상태
- 요청 ID와 terminal 결과
- 실패·재시도 여부

비밀번호, 인증 토큰, 이메일 원문과 불필요한 개인정보는 기록하지 않습니다.
