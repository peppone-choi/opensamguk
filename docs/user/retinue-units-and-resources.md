# 부곡 지휘와 물자 표시

휘하 편성의 부곡 카드에서 부장을 지정하지 않은 부곡은 **본인 지휘 — 출병 조건 확인**으로 표시합니다.
부장 미지정은 이동 불가를 뜻하지 않습니다. 출병 명령 화면에서 직접 지휘할 부곡과 목적지를 고르고,
현재 병력·소유권·위치·경로 등 실제 가능 여부와 거절 사유를 확인하세요. 부장을 지정한 부곡은
현재 개인 출병 입력에서 선택할 수 없습니다. 접수 뒤 실행 턴에도 조건을 다시 검사하므로
카드의 안내나 예약 접수만으로 출병 완료를 뜻하지 않습니다.

부장이 지정돼 있지만 조회된 명부에서 그 이름을 확인할 수 없으면 **지휘 인물 확인 필요**로 표시합니다.
이 상태를 본인 지휘로 간주하거나 부장 이름을 추정하지 않습니다.

조정 선택지의 물자는 금·쌀·철·목재·말로 표시합니다. 확인할 수 없는 물자 코드는
**알 수 없는 물자**로 안내하며, 대상 이름과 서버가 지정한 입력 값·가능 여부·거절 사유는 유지합니다.
이 표시 규칙은 아직 연결되지 않은 몰수나 물자 지원 기능의 사용 가능 또는 처리 완료를 뜻하지 않습니다.
