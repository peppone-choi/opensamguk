# 게임플레이 가이드

> 상태: 현재 구현된 규칙과 화면 기준
> 마지막 검토: 2026-08-20

## 게임 시간과 턴

오픈삼국의 현재 날짜 체계는 한 달을 상순·중순·하순으로 나누며 1년은 36순입니다. 실제 한 순의 간격은 서버
설정에 따라 다르므로 고정 시간으로 외우지 말고 메인 화면의 다음 턴 시각을 확인합니다.

월 경계에는 수입, 외교·전쟁 기간, 도시·국가 상태, 이벤트와 기록이 정해진 순서로 처리됩니다. 월말에
가능했던 명령이 월초에는 자원이나 관계 변화로 실패할 수 있습니다.

## 예턴과 즉시 명령

- 예턴 명령: 목록에 저장된 뒤 해당 장수나 국가의 실행 시점에 다시 검사하고 실행됩니다.
- 즉시 명령: 요청을 durable intake로 접수하고 daemon 결과를 기다립니다.
- 읽기 기능: 상태를 보여줄 뿐 게임 상태를 바꾸지 않습니다.

화면의 `접수됨`은 성공과 같지 않습니다. 성공, 거절, 실패 사유가 있는 terminal 결과와 그 뒤의 권위 read를
함께 확인합니다.

## 명령 상태

| 표시 | 의미 |
|---|---|
| 사용 가능 | 현재 알려진 조건은 만족하지만 실행 시 다시 검사합니다. |
| 대상 필요 | 도시, 장수, 국가, 병종 또는 수량을 골라야 판정할 수 있습니다. |
| 사용 불가 | 현재 확정된 조건을 만족하지 않으며 이유가 표시됩니다. |
| 정보 부족 | 화면의 정보만으로 완전 판정할 수 없습니다. 성공을 보장하지 않습니다. |

## 장수 행동

### 재야·방랑

임관, 무작위 임관, 거병, 건국과 같은 신분·소속 행동을 검토합니다. 시작 직후의 보호 기간, 국가별 인원,
건국 가능한 도시와 서버 가입 정책이 제한할 수 있습니다.

한나라 지도에서 NPC 방랑군은 건국 가능한 공백지에 도착하면 먼저 건국을 시도합니다. 수비병 돌파에
필요한 병력이 부족하면 비용·주민·민심·병종 조건을 만족하는 징병 또는 모병으로 병력을 준비합니다.
수하 장수가 아직 없으면 비용을 감당할 수 있는 동안 인재를 탐색합니다. 탐색으로 발견한 장수는 재야로
등장하므로 별도의 임관이 필요하며, 건국이 보장되지는 않습니다. 준비할 수 있는 행동이 없으면 기존의
이동·해산 판단을 따릅니다.

### 국가 소속

농지·상업·치안·수비·성벽·정착·기술 같은 내정과 헌납, 징병, 훈련, 사기, 이동을 사용합니다. 소속 도시가
실제로 우리 국가 도시인지, 보급 가능한지, 최대치에 도달하지 않았는지, 비용을 감당하는지 확인합니다.

### 전쟁

출병과 전투 관련 명령은 병력·군량·병종뿐 아니라 대상 도시, 이동 가능 경로, 외교 상태와 보호 기간을 다시
검사합니다. 여러 턴 뒤 실행된다면 앞선 예턴이 병력이나 위치를 바꾸는지도 확인합니다.

## 국가 운영과 직책

국가에 소속됐다고 모든 국가 기능을 사용할 수 있는 것은 아닙니다. 군주와 직책에 따라 국가 예턴, 인사,
재정·전략 설정과 비밀 정보 접근이 달라집니다. URL을 직접 입력해도 서버의 권한 검사를 우회할 수 없습니다.

대표 국가 행동은 다음과 같습니다.

- 포상, 발령, 몰수, 원조와 인구 이동
- 국호·국기 변경, 천도, 증축·감축
- 선전포고, 종전·불가침·파기 제안과 수락
- 의병 모집, 허보, 급습, 수몰, 초토화 등 전략 명령
- 시나리오가 허용한 특수 병종 연구

외교 제안과 상대의 수락은 서로 다른 단계입니다. 제안 뒤 국가가 멸망하거나 직책·관계가 바뀌면 수락할 수
없습니다.

## 승리와 시즌 종료

현재 v1에서 활동 국가가 정확히 하나이고 그 국가가 시나리오의 모든 도시를 소유하면 전토 통일이 확정됩니다.
이때 시스템은 최종 통계와 통일 기록을 남기고, 진행 중인 유니크 경매를 닫고, 통일 국가의 대상 장수에게
상속 포인트를 반영한 뒤 천하통일 상태로 전환합니다. 국가사와 전체 역사 로그에서 통일 결과를 확인할 수
있습니다.

천하통일 상태에서는 일반 턴 진행이 멈춥니다. 침략자 이벤트가 활성화된 시나리오는 이민족 소탕 또는
이민족의 전 도시 장악으로 별도 엔딩 로그와 종료 상태가 기록될 수 있습니다.

통일 뒤 다음 기수 개설, 계정·장수·기록의 이관 범위와 재개 시점은 현재 공통 자동 절차로 검증되지 않았습니다.
따라서 화면이나 운영 공지에 없는 reset·재가입 일정을 추측하지 말고 운영자의 시즌 종료 공지를 따르세요.
이 부분은 현재 `UNKNOWN`이며 서버마다 다를 수 있습니다.

## 실패했을 때

1. 최근 행동 로그와 terminal 실패 사유를 읽습니다.
2. 금·쌀·병력, 현재 도시, 직책, 대상, 외교 상태를 다시 확인합니다.
3. 앞선 예턴이 필요한 상태를 먼저 소모하거나 바꾸는지 봅니다.
4. 화면을 새로 불러와 최신 revision과 대상 목록을 받습니다.
5. 수정한 한 요청만 다시 보냅니다.

동일한 실패를 무작정 반복하면 자원·예턴·운영 로그만 복잡해질 수 있습니다. 사유가 화면과 맞지 않으면
재현 시각, 서버, 장수, 명령, 화면에 보인 사유를 함께 운영자에게 전달하세요. 비밀번호나 인증 쿠키는 보내지
않습니다.

## 장판 전장

후한 지도에서 장판은 도시와 별개로 부대가 진입해 싸우는 장소입니다. 당양에 있는 장수가 병력을 보유한 상태에서 지도 오른쪽의 **장판 전장 선택**을 누르고 **전장 진입 예약**을 선택합니다. 예약 접수는 이동 완료가 아니며, 개인 턴에 실행됩니다.

전장에 교전 중인 적 부대가 있으면 조우 전투를 치릅니다. 적을 모두 물리치면 주둔하고, 진입에 실패하면 당양에 남습니다. 패퇴한 수비대는 귀환합니다. 전장 승패는 당양의 소유권이나 성벽을 바꾸지 않습니다. 결과와 병력 손실은 참여 장수의 개인 기록에 남습니다.

주둔 중에는 도시 내정이나 도시 수비에 참여하지 않습니다. **귀환 예약**으로 당양에 돌아온 뒤 도시 명령을 실행할 수 있습니다. 전장에서의 휴식은 대기이며 도시 치료 효과를 받지 않습니다. 위치 정보가 바뀌었다는 안내가 나오면 지도를 새로 불러와 예약하세요.

장판의 표시는 사료와 현대 비정을 바탕으로 한 대략적 대표 위치입니다. 고대 전장의 경계나 다리의 정확한 위치를 복원한 표시는 아닙니다. 현재 이동 가능한 전장은 장판과 관도이며, 적벽 수전과 다른 역사 전장은 별도 적용이 필요합니다.

### 관도 전장

관도는 원무에 있는 부대가 지도에서 선택해 진입을 예약할 수 있는 독립 전장입니다. 진입·조우·귀환은 장판과 같은 규칙을 사용하며, 예약 접수 후 개인 턴이 처리되어야 실제 위치가 바뀝니다.

표시는 문헌 지명의 대략적 현대 위치입니다. 원무를 통한 접근은 현재 게임 지도에서 연결된 평지 경로를 기준으로 재구성했으며, 고대 도로나 관도의 역사적 행정 소속을 확정한 것은 아닙니다. 장판의 기존 접근 방식은 유지됩니다.
