# 게임플레이 가이드

> 상태: 휘하 제품 규칙과 현재 연결된 화면 기준
> 마지막 검토: 2026-09-24

## 게임 시간과 개인 턴

한 달은 상순·중순·하순으로 나뉘고 한 해는 36순입니다. 실제 한 순의 간격은 서버 설정을
확인하세요. 작전실은 개인 행동을 최대 12순까지 예약합니다. 접수된 입력은 그 장수의 개인 턴에
현재 조건을 다시 확인한 뒤 실행되므로, 예약 접수만으로 성공한 것은 아닙니다.

장수 본인이 하는 직접 행동은 한 개인 턴에 하나입니다. 배치·방침·공사는 맡겨 둔 지속 입력이며
개인 12순 칸을 쓰지 않습니다. 이 입력도 적용 시점에 조건을 다시 확인합니다. 현재 제공되는
입력과 미구현 범위는 [기능 안내](./features.md)를 보세요.

## 작전실과 직접 행동

[작전실](/game/hwiha/war-room)에서 지도, 현재 장수, 최근 결과와 12순 목록을 확인합니다.
현재 원장에서 처리 준비가 된 직접 행동은 출사, 출병, 첩보, 강공, 항복 권고입니다.
출사는 세력 지정·무작위·주공 장수 지정 방식으로 예약할 수 있습니다. 출병은 이동할 郡國과
목적을 확인하고, 첩보는 현재 서 있는 郡國과 맞닿은 郡國을 대상으로 합니다.
강공과 항복 권고는 관여한 공성에서만 선택할 수 있습니다.

이 다섯 행동 밖에 기획된 직접 행동은 입력 원장과 실행 핸들러가 준비되기 전까지 제품에서
실행 가능한 명령으로 표시하지 않습니다. 예약이 거절되면 표시된 사유를 확인하고 위치·대상·
자원·관계를 갱신한 뒤 다시 선택하세요.

기존 장수 직접 행동 34개 중 원장에 대응되지 않은 29개는 [#892](https://github.com/peppone-choi/opensamguk/issues/892)의 구현 공백입니다.

| 범주 | 아직 연결되지 않은 행동 |
|---|---|
| 내정 7 | 농지개간·상업투자·수비강화·성벽보수·치안강화·정착장려·주민선정 |
| 군사 6 | 징병·모병·훈련·사기진작·집합·소집해제 |
| 인사 5 | 이동·강행·귀환·인재탐색·등용 |
| 개인 4 | 견문·단련·요양·은퇴 |
| 국가 7 | 증여·헌납·하야·거병·건국·선양·해산 |

새 체계의 순행·결의·포로 설득·독립도 아직 입력 원장 행이 없습니다.

## 휘하와 국가 운영

휘하 편성에서는 인물과 부곡을 확인합니다. 배치·방침·공사는 자리, 지역 운영과 건설을
계속 처리하는 입력입니다. 조정 결정에서는 발령과 상사를 처리합니다. 조정 화면은
관직·외교·천도 구상과 현재 수도를 보여 주지만 해당 입력은 아직 없습니다(2·3층, #208·#210).
보급망은 창고와 연결 상태를 보여 줍니다.

군단이 적의 縣에 도착해 포위하면 [공성](/game/hwiha/siege)에서 포위 상태와 군량·사기·
방비를 확인합니다. 포위 지휘관만 강공이나 항복 권고를 예약할 수 있습니다. 접수 뒤 실제
결과는 다음 개인 턴의 기록에서 확인하세요.

지도는 현재 군단과 郡國 단위 시야를 서버 투영에 따라 표시합니다. 첩보했던 곳은 그때 본
정보와 지난 순 수를 보여 줍니다. 읽기에 실패하면 해당 레이어를 비우고 지형 지도를 유지합니다.

## 소통과 기록

게시판과 서신은 계속 사용할 수 있습니다. 개인 서신의 수신자는 발송 전에 표시된 이름과
ID를 확인하세요. 연감·월드 기록·랭킹은 읽기 화면이며, 월단평에서는 명망 변화를 확인합니다.

## 실패했을 때

1. 요청의 최종 처리 결과와 지난 순 기록에 표시된 사유를 읽습니다.
2. 위치, 대상, 소속, 자원과 외교 관계를 새로 불러옵니다.
3. 같은 입력을 연속 제출하지 말고 현재 조건으로 다시 예약합니다.
4. 화면과 사유가 맞지 않으면 서버·장수·시각·입력과 보인 메시지를 운영자에게 전달합니다.

비밀번호나 인증 쿠키는 전달하지 마세요. 전체 지도 역사 시나리오와 그 지명·거점은
후속 단계의 범위이며, 현재 기본 시나리오의 이용 가능 범위로 가정하지 않습니다.
