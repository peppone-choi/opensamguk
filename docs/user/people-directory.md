# 인물 일람

이름·초상·소속과 다섯 능력·네 적성은 다른 세력 인물도 조회할 수 있습니다. 능력 자료가 없거나 올바르지 않으면 값이 표시되지 않습니다. 주공 관계·부 신분·소재지·인연은 본인과 직접 가신 범위에서만 조회합니다.

이름은 부분 검색과 초성 검색을 지원합니다. 전체·소속 세력·직접 휘하 범위를 선택하고 이름, 소속 이름, 다섯 능력, 능력 합, 네 적성, 나이로 오름차순·내림차순 조회할 수 있습니다. 같은 값은 인물 ID 순이며 값이 없는 인물은 마지막에 옵니다. 정렬은 전체 검색 결과에 적용됩니다. 조회 중 인물 자료가 바뀌면 첫 페이지부터 다시 조회해야 합니다.

주공·가신·재야라는 부 신분은 관직이나 군단의 자리와 별개입니다. 자리 표시는 해당 임명·배치 원장이 연결된 이후 제공됩니다.
