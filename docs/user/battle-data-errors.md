# 전투 자료를 읽을 수 없을 때

전투 방에 들어온 뒤 서버가 보낸 자료를 확인하지 못하면 **전투 자료를 읽을 수 없습니다**가 표시됩니다. 확인되지 않은 자료로 부곡 배치나 전투 명령을 보내지 않습니다.

**다시 시도**를 누르면 새 접속으로 전투 자료를 다시 읽습니다. 오류가 계속되면 **전투 · 부재 대비로**를 눌러 목록으로 돌아갈 수 있습니다. 재시도나 목록 복귀가 전투 명령을 제출하지는 않습니다.

이 메시지는 전투 자료를 확인하지 못했다는 뜻입니다. 전투가 없거나 서버가 준비 중이라고 판단한 결과가 아닙니다. 이 안내만으로 전투 진행이나 명령 제공 여부를 확인할 수는 없습니다.

서버의 참가 대기 자료를 확인하면 **전투 참가 대기** 화면에서 내 지휘권에 속하는 실제 부곡의 병력과 위치를 볼 수 있습니다. 목록이나 판에서 부곡을 고르는 것은 조회 동작입니다. 이 화면은 배치 변경과 전투 명령을 보내지 않습니다. 사기와 장수 정보는 이 참가 대기 자료에 포함되지 않아 표시하지 않습니다.

참가 대기 화면을 확인했다는 사실만으로 진행 중 전투나 명령 접수·적용이 제공된다고 판단할 수 없습니다.
