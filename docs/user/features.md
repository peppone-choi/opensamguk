# 기능 안내

> 상태: route와 현재 구현을 기준으로 한 기능 지도
> 마지막 검토: 2026-09-08

## 정보와 기록

| 기능 | 경로 | 설명 |
|---|---|---|
| 내 정보 | `/game/my` | 내 장수 상태와 개인 정보 |
| 국가·도시·장수 | `/game/nation`, `/game/city`, `/game/generals` | 현재 월드의 기본 정보 |
| 내 국가·도시·장수 | `/game/my-nation`, `/game/my-cities`, `/game/my-generals` | 소속 관점의 정보와 권한 기능 |
| 지도 | 게임 메인, `/game/map` | 메인은 현재 도시를 중앙에 확대해 시작하고, 독립된 `내 위치` 표시로 현재 지점을 구분 |
| 랭킹 | `/game/rankings/*` | 장수, 국가, NPC, 황제, 명예의 전당, 트래픽 |
| 기록 | `/game/history`, `/game/world-log` | 과거 기록과 월드 로그 |

기록 화면은 메인 화면과 갱신 시점이 다를 수 있습니다. 월 정산·시즌 종료 직후에는 화면의 상태 시각을 함께
확인합니다.

게임 메인 지도의 `내 위치`는 선택 상태와 별개입니다. 수동으로 이동하거나 확대·축소한 뒤에는 사용자가 본 시점을
유지합니다. 운영체제의 `동작 줄이기` 설정이 켜져 있으면 위치 표시는 깜빡이지 않고 정적으로 표시됩니다.

새 Han V3 지도는 검토된 호수·연안을 별도 수역 레이어로 표시합니다. 현재는 팽려·파양호와
瓊州海峽 연안 두 구역만 있으며, 검토된 항구나 수운 연결은 없습니다. 수역 목록에서 구역을 선택해
확대할 수 있습니다. 수역 색·무늬와 육지 국가색은 서로 다른 정보입니다.

일반 사용자에게 통제 정보는 비공개입니다. 관리자가 보는 `확인되지 않음`은 통제 행이 없는 상태이고,
`봉쇄 없음`도 통행 허가를 뜻하지 않습니다. 데이터 버전이 맞지 않거나 조회에 실패하면 수역 표시를
중단하고 사유를 보여주되 육상 지도는 유지합니다. 과거 지도에는 현재 수역 통제를 덧씌우지 않습니다.

## 휘하 인물과 부곡

내 정보의 휘하 인물 구획에서 기존 NPC 장수를 골라 서약할 수 있습니다. 같은 국가 또는 재야인 미소유 NPC 중 군주와 이미 다른 주인을 섬기는 장수는 제외됩니다. 직접 선택이 기본이며, `무작위 서약`도 같은 후보 목록에서 한 명을 뽑습니다. 표시된 비용·상한은 현재 서버 규칙이며, 실제 처리 시 후보 상태를 다시 확인합니다.

서약한 장수는 원래 이름·초상·능력·병력을 유지하고 계속 스스로 행동합니다. 개인 가신 관계가 국가 소속을 바꾸지는 않으며 서약 뒤 소속이 바뀌어도 자동 전향하지 않습니다. 해제하면 가신 관계만 끝나고 장수는 남습니다. 충성이 0이면 기존 월 정산 규칙에 따라 떠납니다. 가신인 동안에는 다른 플레이어가 그 NPC에 빙의할 수 없습니다.

기존 NPC 가신은 월 가신 유지비를 내지 않습니다. 이전 방식으로 생성된 가신은 계속 관리할 수 있으며 기존 금·쌀 유지비 규칙을 따릅니다. 부곡은 내 병력에서 편성하는 별도 사병이고, 가신 서약만으로 새 병력이나 부곡이 생기지 않습니다.

## 장수·휘하 규칙의 출사 — 개발 중

새 규칙의 출사 입력 화면을 연결하고 있습니다. 실제 브라우저 검증과 플레이 가능한 시나리오는 아직 준비 중입니다. 출사 예약과 실행에 연결된 규칙은 다음과 같습니다.

- 재야 장수는 세력을 지정하거나, 출사를 받는 세력 중 무작위로 선택하거나, 장수를 지정해 그 장수의 주공에게 출사할 수 있습니다.
- 주공이 출사를 받아야 하며 명망 수용량에 여유가 있어야 합니다. 인물 비용은 다섯 능력치 합을 50으로 나누어 올림한 값이며 최소 1입니다.
- 예약은 최대 12순이며, 현재는 각 순에 개별 예약합니다. 일괄 예약·밀기·복사는 아직 제공하지 않습니다. 자기 턴에 현재 조건을 다시 확인합니다. 접수됐어도 그 사이 주공의 상태나 명망 여유가 바뀌면 사유와 함께 거절될 수 있습니다.
- 성공하면 자신과 개인 휘하의 소속이 바뀌고 자신은 주공의 휘하에 들어갑니다. 현재 위치·보유 자원·부곡은 그대로입니다. 플레이어 장수를 직접 휘하에 두고 있다면 출사할 수 없습니다.
- 한 세계 순에 예약 하나만 처리합니다. 지연된 예약을 한꺼번에 실행하지 않으며, 실행 거절도 해당 순의 행동으로 셉니다.
- 시작할 때 예약 칸은 비어 있습니다. 일반 재야 NPC는 소유자·주공 지위·휘하 소속·명시 예약이 없고 유효한 세력이 있을 때 같은 출사 규칙을 사용합니다. 특수 NPC와 사람의 명령은 자동으로 대체하지 않습니다.

## 소통

- Gateway 게시판: `/board`
- 게임 게시판: `/game/board`
- 개인 서신: `/game/mailbox`

공개 글, 국가 범위 글, 개인 서신은 공개 범위가 다릅니다. 민감한 외교·국가 정보를 공개 게시판에 올리지
마세요. 개인 서신은 발송 전에 연락처에서 수신 장수를 검색·선택하고 표시된 이름과 ID를 확인해야 합니다.
자기 자신을 개인 서신 수신자로 지정할 수 없습니다. 운영자의 공지 고정·soft-delete 전체 기능은
[OPENSAM-81/#223](https://github.com/peppone-choi/opensamguk/issues/223)에서 추적 중이므로 구현 완료로
가정하지 않습니다.

## 부대·전투·외교

- 부대: `/game/troop`
- 전투 본부: `/game/battle-center`
- 국가 외교: `/game/diplomacy`
- 전역 외교 현황: `/game/global-diplomacy`
- 전투 시뮬레이터: `/game/simulator`

시뮬레이터 결과는 실제 월드 상태를 바꾸는 전투와 동일한 운영 행위가 아닙니다. 실제 출병은 예턴, 경로,
외교와 daemon 결과를 따릅니다.

## 기간형·부가 기능

| 기능 | 경로 | 확인할 상태 |
|---|---|---|
| 경매 | `/game/auction` | 열림, 입찰, 마감, 정산 |
| 일반 베팅 | `/game/betting` | 후보, 기간, 마감 |
| 국가 베팅 | `/game/nation-betting` | 이벤트가 연 서버인지, 마감 상태 |
| 투표 | `/game/vote` | 열린 안건, 참여 여부, 종료 |
| 유산 | `/game/inherit` | 보유 포인트와 사용 조건 |
| 토너먼트 | `/game/tournament` | 등록, 조별/본선 진행, 결과와 보상 |
| 장수 선택 | `/game/select-pool` | 현재 선택 가능 장수와 terminal 결과 |

메뉴가 있다고 항상 이벤트가 열린 것은 아닙니다. 시나리오와 서버 설정이 기능을 열지 않았다면 빈 상태 또는
사용 불가가 정상입니다.

## 내부 실험 화면

`/game/v2-lab/*`은 garrison, ledger, space, transport 같은 신규 계약을 검증하는 내부 실험 경로입니다.
경로 이름은 기술 식별자일 뿐 사용자용 버전명이 아닙니다. 일반 시즌의 완성 기능이나 운영 약속으로 보지
않으며 제품 방향은 [현재 로드맵](../design/roadmap.md)을 따릅니다.

수송 실험 화면은 제출 직전에 서버에서 경로와 자원·호위 조건을 확인합니다. 새 Han V3 지도에서는
확인한 경로 해시와 위상 버전을 보내고 실행 시 다시 검증합니다. 경로가 바뀌었거나 통과할 수 없으면
사유를 표시하며, 접수 응답만으로 수송 완료를 표시하지 않습니다. 현재 즉시 수송은 자국 간 단일 육로만
지원하며, 다턴 수운·봉쇄·수전·상륙은 아직 활성화되지 않았습니다.

서버가 확인한 경로는 수송 화면의 지도에도 표시됩니다. 입력·서버·세계가 바뀌면 이전 경로를 폐기하며,
미리보기의 세계 ID와 제출 대상이 다르면 예약하지 않습니다. 비용을 임의의 이동 턴수로 표시하지 않습니다.

수역의 통제와 육지의 소유권은 서로 다릅니다. 강이나 호수 옆 현을 점령했다고 수역을 자동 장악하지
않으며, 수역에 봉쇄가 없더라도 항구·연결 경로·자국 통제·수송 용량 조건이 없으면 보급로가 되지 않습니다.

## 장수·휘하 규칙의 발령 — 개발 중

발령의 서버 처리 경로를 연결하고 있습니다. 발령 화면과 부임 행군은 아직 준비 중입니다.

- 주공은 직접 거느린 사람 장수를 아군 현의 빈 자리로 발령할 수 있습니다. 대기 발령은 주공당 한 건이며 다음 주공 턴에 처리됩니다.
- 대상 장수는 개인 행동을 쓰지 않고 수락하거나 거절합니다. 기본 응답 기한은 발령 뒤 12순이며, 기한이 지나면 수락합니다.
- 기한 전 거절은 충성 5와 명망 상한 1을 줄입니다. 수락은 부임 목표를 저장하며 즉시 이동하지 않습니다.
- 발령 실행이나 기한 만료 전에 소속·휘하 관계·현 소유권이 바뀌면 다시 확인합니다. 만료 때 유효하지 않은 발령은 벌점 없이 취소됩니다.
- 접수되었다는 안내는 실행 성공을 뜻하지 않습니다. 실제 실행 결과를 확인해야 합니다.

일반 NPC 주공은 자기 턴에 아직 발령받지 않은 직속 사람 장수 한 명을 아군 현의 빈 자리로 발령합니다. 거절하거나 취소된 첫 발령을 자동으로 반복하지 않으며, 발령 이유는 대상 장수의 개인 행동 기록에 남깁니다.
