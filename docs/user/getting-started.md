# 첫 시작

> 상태: 현재 Gateway·게임 route 기준
> 마지막 검토: 2026-09-24

## 1. 가입과 로그인

- 가입: `/join`
- 로그인: `/login`
- 계정 설정: `/account`

인증 정보는 브라우저 JavaScript가 읽지 못하는 httpOnly 쿠키에 저장됩니다. 로그인 화면에서 받은 토큰을
복사하거나 game-api를 직접 호출할 필요가 없습니다.

가입 시 정한 닉네임은 게시판, 랭킹, 서신 등에 표시됩니다. `/account`에서 2~20자의
고유한 닉네임으로 변경할 수 있으며, 성공하면 현재 브라우저 세션과 상단 표시가 즉시 갱신됩니다.
계정 설정에서 비밀번호 변경, 전콘 관리, 계정 탈퇴도 할 수 있습니다.

### 전콘의 얼굴 위치 조절

계정 설정에서 jpg·png·webp 원본을 선택하면 히어로·카드·아이콘의 구도를 각각 조절할 수 있습니다.
이미지를 끌어 위치를 옮기고 확대·축소 슬라이더, 마우스 휠 또는 두 손가락을 사용하세요.
좌우·상하 슬라이더는 키보드로도 조절할 수 있습니다. 세 미리보기를 확인한 뒤 **업로드**를 누르면 함께 저장됩니다.
얼굴 위치는 자동 인식하지 않습니다. 세 종류마다 원하는 위치를 직접 정합니다.

원본은 8MB 이하, 가로·세로 64~8192px, 총 2,400만 화소 이하여야 합니다. 움직이는 이미지는 지원하지 않습니다.
원본은 본인 계정에 보관되며 **보관된 원본으로 다시 편집**으로 불러올 수 있습니다.
하루 한 번 변경 제한이 적용되며 저장 실패 시 기존 전콘과 편집 중인 구도를 유지합니다.
이전에 올린 단일 이미지 전콘은 계속 표시되지만, 원본 보관 전콘으로 바꾸려면 원본을 새로 선택해야 합니다.

## 2. 로비에서 서버 선택

로그인 뒤 `/lobby`에서 서버를 선택합니다. 서버가 하나도 없다면 오류가 아니라 운영자가 아직 게임 서버를
열지 않은 상태일 수 있습니다. 서버 목록 위의 필터(전체 · 참가 중 · 참가 가능 · 종료)는 내 장수가 있는지와
서버가 끝났는지로 행을 거릅니다. 현황을 받지 못한 서버는 숨기지 않고 「- 폐 쇄 중 -」으로 남깁니다.
목록 아래에는 선택한 서버의 지도, 세력 현황(국가별 성·장수 수), 최근 전황이 보이고, 오른쪽에는 운영 공지가
있습니다. 공지는 로그인 화면에서도 같은 내용을 보여 줍니다. 서버마다 다음 값이 다를 수 있습니다.

- 시나리오와 지도
- 시작 연도와 현재 게임 날짜
- 턴 간격
- 가입·장수 생성 정책
- NPC 선택과 장수 생성 정책

입장 버튼은 선택한 서버를 쿠키에 기록한 뒤 `/game`으로 이동합니다.

## 3. 게임 입구와 출사

로비의 「장수 만들기」는 `/game/<서버>` 입구를 엽니다. 장수가 없으면 직접 만들기와 역사 인물로
시작하는 두 길이 보입니다. `/create`와 `/create/historical`은 현재 서버 준비 중이며 장수를 생성하거나
역사 인물을 점유하지 않습니다. 이름 규칙·본관·후보·생성 정책은 서버에서 전달된 뒤 제공됩니다.
`/game/register?server=<서버>`도 게임 입구로 안내합니다.

장수가 있는 사람은 작전실로 들어갑니다. 재야 장수는 `/game/<서버>/join`에서 출사할 주공을 고릅니다.
세력·장수·무작위 묶음의 실제 후보와 불가 사유를 확인하고, 12순 가운데 출사할 순을 고른 뒤 「출사 예약」을
누르세요. 각 순에는 서버가 준 연·월·순과 실행 시각(HH:MM)이 보이며, 서버가 값을 주지 않으면 비워 둡니다.
처음에는 첫 빈 순이 골라져 있고, 그 순이 그 사이 채워져도 다른 순으로 옮기지 않고 예약을 막습니다. 명령이 있는
순도 목록에 보이지만 덮어쓰지 않으며, 예약 직전에 12순을 다시 읽어 그 사이 채워진 순이나 바뀐 순 시각이 있으면
예약하지 않습니다. 로그인 만료 또는 본인 장수가 아닌 경우에는 예약할 수 없습니다. 이미 소속된 장수는 작전실로 돌아갑니다.
접수와 예약·실행 완료는 다릅니다. 처리 결과를 아직 확인하지 못했거나, 다시 읽은 12순에서 고른 순·후보의 출사
명령을 찾지 못하면 성공으로 표시하지 않습니다. 결과를 모르는 동안에는 같은 화면에서 다시 예약하지 않으니
작전실 12순에서 확인하세요.
주공 위치와 세력 목록처럼 서버가 아직 주지 않는 정보는 「서버 대기」로 표시합니다.

## 4. 메인 화면 읽기

`/game`에서 먼저 다음을 확인합니다.

- 현재 장수의 이름, 소속 국가와 도시
- 금·쌀·병력·훈련·사기 등 행동에 필요한 상태
- 현재 연·월·상/중/하순과 다음 턴 시각
- 개인 12순 행동과 맡겨 둔 배치·방침·공사
- 최근 행동·전투·역사 로그
- 지금 사용할 수 있는 명령과 사용할 수 없는 이유

## 5. 첫 예턴 넣기

1. 작전실에서 현재 제공되는 직접 행동을 고릅니다.
2. 대상 郡國·城·인물이나 수량이 필요하면 폼을 모두 채웁니다.
3. 예약 뒤 12순 목록의 입력과 대상을 확인합니다.
4. 실제 개인 턴이 지난 뒤 지난 순 기록과 자원·위치 변화를 확인합니다.

예약 시점에는 가능했어도 실행 전 국가, 도시, 자원, 직책, 외교 관계가 바뀌면 실패할 수 있습니다. 자세한
판정 방식은 [게임플레이 가이드](./gameplay-guide.md)를 보세요.

## 자주 막히는 경우

| 증상 | 확인할 것 |
|---|---|
| 서버가 보이지 않음 | 운영 공지, 로그인 상태, 로비 새로고침 |
| 장수 생성이 거절됨 | 서버의 생성 제한, 닉네임/장수명, 이미 가진 장수 |
| 명령이 비활성 | 불가 사유, 소속·직책·자원·대상·보호 기간 |
| 저장했는데 결과가 없음 | 예턴인지 즉시 명령인지, 다음 턴 시각, terminal 결과, 최근 로그 |
| 다른 탭의 변경이 사라짐 | 최신 예턴을 다시 불러온 뒤 한 탭에서 수정 |
| 로그인 화면으로 돌아감 | access 갱신 실패 여부, 다시 로그인, 운영 장애 공지 |

## 모바일에서 지도와 메뉴 사용

작전실·전체 지도와 로비의 2D 지도는 한 손가락으로 끌어 이동하고, 두 손가락을 벌리거나 모아 확대·축소합니다.
두 손가락 중 하나를 떼면 남은 손가락으로 계속 이동할 수 있습니다. 지도를 끈 직후에는 도시가 선택되지 않습니다.
`+`·`−` 버튼으로도 확대·축소할 수 있고, **전체**를 누르면 현재 화면 크기에 맞춰 지도를 다시 보여 줍니다.
화면을 회전한 뒤 전체 지도가 필요할 때도 **전체**를 누르세요.

작은 화면에서는 로비 상단 메뉴가 두 줄로 배치됩니다. 게임 하단의 **더보기**를 누르면 부서 메뉴가 열립니다.
메뉴가 열린 동안 배경 게임 화면은 스크롤되지 않으며, 메뉴 안을 스크롤하거나 상단 **닫기**로 돌아갈 수 있습니다.
