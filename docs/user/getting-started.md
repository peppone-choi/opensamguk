# 첫 시작

> 상태: 현재 Gateway·게임 route 기준
> 마지막 검토: 2026-08-21

## 1. 가입과 로그인

- 가입: `/join`
- 로그인: `/login`
- 계정 설정: `/account`

인증 정보는 브라우저 JavaScript가 읽지 못하는 httpOnly 쿠키에 저장됩니다. 로그인 화면에서 받은 토큰을
복사하거나 game-api를 직접 호출할 필요가 없습니다.

가입 시 정한 닉네임은 게시판, 랭킹, 서신 등에 표시됩니다. `/account`에서 2~20자의
고유한 닉네임으로 변경할 수 있으며, 성공하면 현재 브라우저 세션과 상단 표시가 즉시 갱신됩니다.
계정 설정에서 비밀번호 변경, 전콘 관리, 계정 탈퇴도 할 수 있습니다.

## 2. 로비에서 서버 선택

로그인 뒤 `/lobby`에서 서버를 선택합니다. 서버가 하나도 없다면 오류가 아니라 운영자가 아직 게임 서버를
열지 않은 상태일 수 있습니다. 서버 목록 위의 필터(전체 · 참가 중 · 참가 가능 · 종료)는 내 장수가 있는지와
서버가 끝났는지로 행을 거릅니다. 현황을 받지 못한 서버는 숨기지 않고 「- 폐 쇄 중 -」으로 남깁니다.
목록 아래에는 선택한 서버의 지도, 세력 현황(국가별 성·장수 수), 최근 전황이 보이고, 오른쪽에는 운영 공지가
있습니다. 공지는 로그인 화면에서도 같은 내용을 보여 줍니다. 서버마다 다음 값이 다를 수 있습니다.

- 시나리오와 지도
- 시작 연도와 현재 게임 날짜
- 턴 간격
- 가입·장수 생성 정책
- NPC, 토너먼트와 이벤트 사용 여부

입장 버튼은 선택한 서버를 쿠키에 기록한 뒤 `/game`으로 이동합니다.

## 3. 장수 생성 또는 점유

게임 서버에 내 장수가 없으면 `/game/join` 또는 `/game/register` 흐름이 나타납니다.

- 새 장수 생성: 이름과 화면이 요구하는 능력·설정을 입력합니다.
- 기존 장수 선택: `/game/select-pool`에서 현재 선택 가능한 장수를 고릅니다.
- 서버 정책에 따라 생성, 랜덤 임관, 기존 장수 점유 중 일부만 허용될 수 있습니다.

요청이 접수됐다는 표시와 실제 완료는 다릅니다. 요청 ID의 terminal 결과가 성공한 뒤 메인 화면에서 장수가
보이는지 확인합니다. 실패 사유가 있으면 같은 요청을 연타하지 말고 화면을 새로 불러온 뒤 조건을 고칩니다.

## 4. 메인 화면 읽기

`/game`에서 먼저 다음을 확인합니다.

- 현재 장수의 이름, 소속 국가와 도시
- 금·쌀·병력·훈련·사기 등 행동에 필요한 상태
- 현재 연·월·상/중/하순과 다음 턴 시각
- 장수 예턴과 국가 예턴
- 최근 행동·전투·역사 로그
- 지금 사용할 수 있는 명령과 사용할 수 없는 이유

## 5. 첫 예턴 넣기

1. 비용과 대상이 단순한 내정 또는 휴식 명령을 고릅니다.
2. 대상 도시·장수·국가나 수량이 필요하면 폼을 모두 채웁니다.
3. 저장 뒤 예턴 목록의 action과 요약이 의도대로인지 확인합니다.
4. 실제 턴이 지난 뒤 로그와 자원·도시 수치가 변했는지 확인합니다.

예약 시점에는 가능했어도 실행 전 국가, 도시, 자원, 직책, 외교 관계가 바뀌면 실패할 수 있습니다. 자세한
판정 방식은 [게임플레이 가이드](./gameplay-guide.md)를 보세요.

## 자주 막히는 경우

| 증상 | 확인할 것 |
|---|---|
| 서버가 보이지 않음 | 운영 공지, 로그인 상태, 로비 새로고침 |
| 장수 생성이 거절됨 | 서버의 생성 제한, 닉네임/장수명, 이미 가진 장수 |
| 명령이 비활성 | 불가 사유, 소속·직책·자원·대상·보호 기간 |
| 저장했는데 결과가 없음 | 예턴인지 즉시 명령인지, 다음 턴 시각, terminal 결과, 최근 로그 |
| 다른 탭의 변경이 사라짐 | 최신 예턴을 다시 불러온 뒤 한 탭에서 수정 |
| 로그인 화면으로 돌아감 | access 갱신 실패 여부, 다시 로그인, 운영 장애 공지 |
