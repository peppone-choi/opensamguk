# 現 수입 전망

현 목록의 금·곡 수입은 현재 호구·상업·농업·개발 상한·보급으로 계산한 **한 달의 총생산 전망**입니다. 순마다 받는 양이나 이미 창고에 들어온 확정 세입, 지출을 뺀 순수익을 뜻하지 않습니다. 실제 적립은 월 경계에 한 번 처리합니다.

본인 세력의 행정 縣만 조회하며, 현재 시야가 FULL일 때 수입을 제공합니다. 시야 밖이거나 자료가 손상돼 확인할 수 없으면 미상으로 표시합니다. 창고가 없는 縣은 수입 0입니다. 다음 정산까지의 개발·소유·보급 변화나 재고 넘침에 따라 실제 적립량이 달라질 수 있습니다.

현 목록 화면의 전체 지표·공사·관직·경고 연결은 후속 개발 범위입니다. 이 수입 읽기 추가만으로 화면 연결이나 운영 반영이 완료된 것은 아닙니다.
