# 이동 목적지 고르기

이동·강행·출병의 목적지 목록은 서버가 가능하다고 판정한 곳 중 경로 거리 기준 가까운 20곳부터 보여 줍니다. 지명이나 구역 번호를 검색하면 먼 목적지도 전체 후보에서 찾습니다. 모든 목적지를 고르면 50곳씩 더 볼 수 있고, 가능만을 끄면 현재 위치나 통행 불가 목적지의 사유도 확인할 수 있습니다. 가까운 20곳은 화면 표시 범위이며, 통행 가능 여부는 서버 판정으로 확인합니다.

거리순·도착 예상순·이름순으로 정렬하거나 이번 턴 도착·다턴 이동을 골라 볼 수 있습니다. 거리를 확인하지 못한 경우에는 이를 안내하고 20곳까지 먼저 표시하며, 가까운 곳이나 도착 순을 추정하지 않습니다.

목적지를 검색하거나 정렬해도 이미 고른 목적지는 유지됩니다. 불가 목적지는 서버 사유를 표시하며 예약할 수 없습니다. 서버가 허용한 강행·출병의 다턴 이동은 선택할 수 있습니다. 목록을 고르는 것만으로 이동을 제출하지 않으며, 지정 순에 예약하는 단추를 눌러야 합니다.

목록에는 서버의 예상 도착 순을 먼저 보입니다. 강행에는 서버가 계산한 피로·사기 비용과 도착 후 상태가 함께 나옵니다. 경로 거리는 보조 정보이며, 지도에서 눈으로 가까워 보이는 거리만으로 도착 순이나 통행 가능 여부를 판단하지 않습니다. 고른 목적지 아래의 도착 예상·비용·거리 보기에서 정밀한 경로 거리를 확인할 수 있습니다. 내부 지형 비용을 장수의 속도로 표시하지 않습니다.

일반 이동은 통행 가능한 직접 연결 이웃 한 곳에 한 개인 순으로 도착합니다. 강행은 서버가 확인한 경로 거리 260km 이하이고 예상 소요가 2순 이하인 목적지를 고를 수 있습니다. 실제 강행 거리의 비용이 누적되며 피로·사기 비용을 지불할 수 없으면 강행할 수 없습니다. 경로 폐쇄, 조우, 권한이나 상태 변화는 실행 때 다시 확인합니다. 조회 뒤 고른 목적지가 불가하거나 목록에서 없어지면 해당 정보를 표시하며 그대로 예약할 수 없습니다.

이름을 확인하지 못했을 때는 구역 번호에 이름 미확인 표시를 붙이며 다른 현의 이름을 추정하지 않습니다.

귀환은 목적지를 직접 고르는 명령이 아닙니다. 현재 발령된 근무성으로 향하는 유효 경로의 다음 이웃을 서버가 고릅니다. 화면의 **이번 도착지**는 이번 한 개인 순에 이동할 이웃이고, **근무성**은 궁극적인 발령지입니다. 어떤 거리나 지형 비용도 한 이웃에 한 개인 순으로 이동한 뒤 멈추며, 다음 빈 순에 자동으로 이어 가지 않습니다. 계속 귀환하려면 다시 예약합니다. 이미 근무성에 있거나 발령이 없거나 통행 경로가 없거나 실행 권한이 바뀌면 서버 사유를 안내하고 위치·자원·이동 상태를 바꾸지 않습니다.
