# /os-start-task — 작업 시작 (계획까지만, 코드 수정 없음)

$ARGUMENTS: 작업 설명 (비우면 `.ai/task.md`의 현재 계약을 대상으로 한다)

절차:
1. `.ai/task.md` 확인 — 없거나 이번 작업과 다르면 **구현하지 말고** 사람에게 계약 갱신을 요청.
2. `docs/agent/README.md` 라우터로 이번 작업 유형에 필요한 문서만 선택해 읽기.
3. `.ai/ownership.md` 확인 — 대상 파일이 타 에이전트 소유면 중단·보고.
4. 관련 파일·유사 구현·테스트 탐색(코드 수정 금지), 계획 작성: 단계 / 변경 파일 / 검증 명령 / 승인 필요 지점.
5. 계획에 사람 승인이 필요한 항목(`.ai/task.md` Human approval checkpoints)이 있으면 명시하고 멈춘다.

결과 저장: 계획을 응답으로 제시하고, 채택되면 `.ai/current-state.md`에 요약 기록.
완료 조건: 승인 가능한 계획 1개. 중단 조건: 계약 부재/모호, ownership 충돌.
